The module adds a report from your app to the **Reports** of a Crowdin Enterprise organization. In [Permission granularity mode](/enterprise/permissions-granularity-mode/), the report also appears in the **Reports** of each group.

The module is available only in Crowdin Enterprise. To add a report to a project, use the [Reports module](/developer/crowdin-apps-module-project-reports/).

## Access

You can grant access to this module to one of the following user categories:

* Only admins
* Admins, managers and developers / translation requestors
* Custom Access

Within the chosen category, organization admins see the report in the organization and in every group, and group managers see it in the groups they manage.

## Structure

```json title="manifest.json"
{
  "modules": {
    "group-reports": [
      {
        "key": "your-module-key",
        "name": "Module name",
        "description": "Module description",
        "logo": "/logo.png",
        "url": "/reports-page"
      }
    ]
  }
}
```

## Organization and Group Levels

Crowdin Enterprise opens the same module `url` for the organization and for its groups. When the report is opened in a group, the context includes `group_id` (the ID of that group) in both the [JWT token payload](/developer/crowdin-apps-security/#token-payload) and the [AP.getContext()](/developer/crowdin-apps-js/#get-context) response. Without `group_id`, the report is opened in the organization's **Reports**.

Crowdin Enterprise adds `group_id` to the token after it checks the user's access to that group, so use the token value to decide which data the report shows.
