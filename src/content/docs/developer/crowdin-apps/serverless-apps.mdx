The Crowdin Serverless Apps SDK is a TypeScript toolkit for building apps that run on Crowdin infrastructure. You write the UI and register the modules the app appears in, and the CLI builds, previews, and publishes the app. It ships a UI kit built from [Crowdin UI Registry](https://github.com/crowdin/ui-registry), Crowdin's set of shadcn components, an i18n runtime for the app's own translations, and an API client that calls Crowdin as the person using the app, with no tokens to manage.

## What You Can Build

With the Crowdin Serverless Apps SDK you can build an app around Crowdin's UI modules:

* **Project modules**: Dashboards, tools, reports, and menu items inside a project.
* **Editor modules**: Panels beside the translation editor.
* **Organization and profile modules**: Pages in the organization and profile menus.
* **Dialogs**: Modals, context menus, and chat panels.

## Building a Serverless App

An AI coding agent can [build the app for you](/developer/crowdin-apps-about/), or you can run the CLI yourself. The CLI scaffolds the app, runs it locally, and publishes it.

```bash
npm install --global @crowdin/serverless-apps-cli
crowdin-serverless-apps login
crowdin-serverless-apps create my-app
crowdin-serverless-apps dev
crowdin-serverless-apps preview
crowdin-serverless-apps publish
```

Crowdin hosts and runs the published app, so there is no server of your own to deploy or maintain.

## Sharing a Serverless App

The CLI packs the app into one app file (`.crowdinapp`) that contains the app's manifest and build. `crowdin-serverless-apps build` writes the file to `dist/<app-slug>.crowdinapp`, and `crowdin-serverless-apps publish` builds the app and uploads the app file to Crowdin, which then serves the app from it. An app file can be up to 5 MB (50 MB unpacked) and contain up to 10,000 files.

To use the app in another Crowdin account or Crowdin Enterprise organization, share the app file. The recipient installs it with **Install Private App** and updates it with **Update file**.

## When to Build a Self-Hosted App Instead

Serverless apps cover the UI side of Crowdin. When your app needs server-side logic (for example, file processing, AI providers, custom MT engines, or webhook handling), build it as a self-hosted app. The same applies when your app combines an interface with server-side logic: self-hosted apps can include UI modules as well.

A self-hosted app also works with the Crowdin API differently: it makes calls as the account that installed it, not as the person using it.
