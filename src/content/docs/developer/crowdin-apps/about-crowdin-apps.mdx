Build a Crowdin app with your AI coding agent:

```text wrap
Help me build a Crowdin app. Do the following:
1. Install the Crowdin plugin with npx plugins add crowdin/skills.
2. Ask me what the app should do, then use the create-app skill to scaffold, develop, and publish it.
3. After publishing, open a preview so I can see the app inside Crowdin.
```

To an end user, an installed app appears as a fully integrated part of Crowdin, with its features delivered straight to the UI.

## Examples of Crowdin Apps

Start from a template instead of an empty project:

* [Serverless Apps Starter Kit](https://github.com/crowdin-community/serverless-apps-starter-kit): The templates the serverless CLI scaffolds, and a complete serverless app to read end to end.
* [Crowdin AI Provider Template](https://github.com/crowdin-community/crowdin-ai-provider-template): A self-hosted app that adds a custom AI provider, built with the Crowdin Apps SDK.
* [Crowdin Custom MT Template](https://github.com/crowdin-community/crowdin-custom-mt-template): A self-hosted app that adds a custom machine translation engine.
* [Crowdin Custom File Format Boilerplate](https://github.com/crowdin-community/crowdin-file-format-template): A file processing app that adds INI, CONF, and CFG support, with a preview for translators.
