Use labels in your project to easily organize resources (e.g., screenshots, strings, etc.) by specific topics. Once you add labels, you can filter items by those labels. If you already use labels for your source strings, you can use the same labels for screenshots.

## Managing Project Labels

To create a project label, follow these steps:

<Steps>
  1. Open your project **Settings** and navigate to the **Labels** section.
  1. At the upper right, click **Create label**.
</Steps>

To edit or remove a label, click <Icon name="mdi:dots-vertical" class="inline-icon" /> (or right-click) on the label you want to edit or remove and select the appropriate action. To remove several labels at once, select their checkboxes and click <Icon name="mdi:delete" class="inline-icon" /> at the upper right of the list. Use the **Search** field above the label list to quickly find specific labels.

<Aside type="caution">
  Labels are case insensitive (e.g., `Label` and `label` are treated as identical).
</Aside>

## Shared Labels

When a client assigns a label to a string that a vendor's workflow step holds, that label is shared with the vendor's project. Shared labels carry the **Shared** badge in the **Labels** section and are read-only. The client project owns them and keeps them up to date.

Vendors can filter by shared labels in the **Sources** section, when creating tasks, and in reports. They can also create their own project labels to use alongside the shared ones.

<Aside>
  Labels are shared automatically and appear in the vendor's project shortly after they are assigned.
</Aside>
