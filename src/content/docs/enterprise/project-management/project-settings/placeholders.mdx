In the **Placeholders** section, you choose which placeholder types Crowdin Enterprise recognizes in your project. The Editor highlights the recognized placeholders in source strings, and the [**Placeholders**](/enterprise/project-settings/qa-checks/#qa-check-parameters) QA check compares them between the source string and the translation. Clearing the types your project doesn't use keeps text that matches only their syntax from being highlighted or reported as a mismatch.

## Configure Placeholders

By default, Crowdin Enterprise recognizes every system placeholder type in the list. To choose the placeholder types for your project, follow these steps:

<Steps>
  1. Open your project and go to **Settings > Placeholders**.
  2. Select the checkboxes of the placeholder types you want Crowdin Enterprise to recognize, and clear the ones your project doesn't use.
  3. Click **Save**.
</Steps>

Saving re-runs the **Placeholders** check for the project's existing translations in the background, so the reported issues match the updated list. On large projects, this can take a while.

System placeholder types come with examples of their syntax and a short description of where they're used, and custom placeholders show their expression. To find a placeholder, search by its name, description, or example in the field above the list, and filter the list by type (system or custom) and by status (enabled or disabled). The checkbox in the table header selects or clears all the placeholders currently shown.

The **Unified placeholder** check runs regardless of the placeholders selected in this section.

## Custom Placeholders

The list also includes the [custom placeholders](/enterprise/custom-placeholders/) created in the organization settings. To use a custom placeholder in the project, select its checkbox and click **Save**.

To configure how a custom placeholder applies in the project, follow these steps:

<Steps>
  1. Click <Icon name="mdi:cog" class="inline-icon" /> on the custom placeholder's row.
  2. In the dialog that opens, set the options:
     * **Order**: The order in which this placeholder is executed among the project's custom placeholders.
     * **Allow saving translations without a placeholder**: Translators can save a translation that doesn't contain this placeholder.
     * **Execute before default placeholders**: This placeholder is matched before the default placeholders.
     * **Assign to specified formats**: This placeholder applies only to the file formats selected in **Formats**.
  3. Click **Done**, and then click **Save**.
</Steps>

Changes to these options apply within a few minutes.
