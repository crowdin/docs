In the **Notifications** section of the project **Settings** tab, you can enable notifications that keep project members informed about new content and progress, which helps you avoid creating a separate task for each update.

## New Strings

Choose who gets notified whenever new content for translation is added to the project:

* **Notify translation team**: Translators, proofreaders, and language coordinators.
* **Notify management team**: The project owner, managers, and Developers / Translation Requestors.

## Language Completion

Choose who gets notified when a target language is fully translated or proofread:

* **Notify management team**: The project owner, managers, and Developers / Translation Requestors.

Each recipient gets these notifications through the channels enabled in their own notification settings.
