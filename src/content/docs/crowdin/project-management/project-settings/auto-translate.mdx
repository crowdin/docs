In the **Auto-Translate** section of the Project Settings, you can configure the automatic auto-translation of new content uploaded to the project. You can choose to use Translation Memory, Machine Translation engines, or AI to auto-translate the content.

The methods you enable under **Auto-Translate New Content Automatically** translate new content as files are uploaded, updated, or their settings change. To auto-translate content that's already in the project (for example, after you add a target language or change these settings), use [manual auto-translation](/auto-translation/#manual-auto-translation).

Select the methods you want to use, configure them, and click **Save**.

<Aside>
  If multiple auto-translation methods are enabled, they execute in the following order: TM, MT, and AI.
</Aside>

## TM Auto-Translate

Enable and configure automatic auto-translation via TM. When enabled, the system applies translations from your TM to new content.

* Match ratio: Select the match type of TM suggestions to apply during automatic auto-translation:
  * 100% match
  * Perfect match
* **Approve added translations**: Select whether to approve new translations. Further configure it with the following options:
  * With perfect match: Approves only Perfect match translations.
  * With perfect match (approved previously): Approves Perfect match translations that were previously approved.
  * All (skip auto-substituted suggestions): Approves all translations except auto-substituted ones.
  * All: Approves all new translations added during auto-translation.

## MT Auto-Translate

Enable and configure automatic auto-translation via MT. When enabled, the system applies translations provided by the selected MT engine to new content.

The MT engine configuration has the following columns:

* **MT Engine**: The MT engines configured in the project owner's account and available in this project. To add or set up engines, click **Configure MT Engines** at the top of the page.
* **Languages**: The project languages each engine auto-translates. You can choose from the languages the engine supports, and all of them are selected by default.

## AI Auto-Translate

Enable and configure automatic auto-translation via AI. When enabled, the system applies translations provided by the selected AI model to new content.

Each AI prompt configuration has the following fields:

* **AI Prompt**: Select an [Auto-Translation & AI Suggestion](/crowdin-ai/#configuring-ai-prompts) prompt available in this project. To create or edit prompts, click **Configure AI Prompts** at the top of the page.
* **Languages**: Select the project languages the prompt auto-translates.

To use other prompts for other languages, click <Icon name="mdi:plus" class="inline-icon" /> to add another AI prompt configuration. To remove a configuration, click <Icon name="mdi:minus" class="inline-icon" /> next to it.

When an AI prompt is [deleted](/crowdin-ai/#deleting-ai-prompts), its [AI provider is disabled](/crowdin-ai/#disabling-ai-providers), or the prompt is no longer available in this project, the prompt is removed from the AI Auto-Translate settings.
