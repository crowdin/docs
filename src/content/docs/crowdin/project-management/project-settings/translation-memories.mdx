The project TM is automatically created for each project. By default, every approved or last added translation is saved to the project TM. This behavior can be customized to save only approved translations.

* **Enable Auto-Substitution**: Substitutes the non-translatable elements (such as tags, HTML entities, placeholders, numbers, and more) in TM translation suggestions with the ones used in the source text. The feature improves the TM suggestions applied during auto-translation and those shown as translation suggestions in the Editor. Improved suggestions are included in the Translation Costs report, and improvable ones are included in the Costs Estimation report.
* **TM Suggestions for Dialects**: Shows and uses TM suggestions from the primary language for dialects when no dialect-specific suggestions are available.
* **Use global Translation Memory**: Gives translators access to the Global Translation Memory, where all translations from the projects with this feature enabled are stored.
  <Aside>
    Once this option is enabled, translations made in this project will also be added to the Global Translation Memory, which anyone can access at Crowdin.
  </Aside>
* **Save only approved suggestion to Translation Memory**: Saves translations to the project default TM only after they are approved. This option is especially useful for public or crowdsourced projects where you want to ensure only reviewed translations are stored in the TM.
* **Perfect Match (101%) Context Rules**: Defines what Crowdin considers as string context when suggesting Perfect (101%) match TM suggestions. You can choose between the following options:
  * **Identifier (key) and Context**: The system considers both the key and context of strings for suggesting Perfect match TM suggestions. This mode is particularly useful for key-value file formats.
  * **Auto**: The system uses **Identifier (key) and Context** for key-value file formats and **Previous and Next Segment** for other file formats.
  * **Previous and Next Segment**: The system considers the segments immediately preceding and following the current segment for context. Most applicable to HTML-based and other formats without a defined key-value structure.
  <Aside type="caution" title="Limitations">
    This option is available for [file-based](/creating-project/#file-based-project) projects only.
  </Aside>

## Match Penalties {#penalties}

In the **Match Penalties** section, you can configure penalties that decrease the match percentage of TM suggestions based on specific conditions. This feature helps when you want to fine-tune the relevance of TM suggestions to your specific requirements.

For each of the following conditions, you can set a penalty in percent:

* **Auto-substitution applied**: Penalize TM suggestions to which an auto-substitution was applied.
* **Multiple identical TM matches**: Penalize TM suggestions where multiple identical TM matches are found.
* **TM priority less than**: Penalize TM suggestions that originate from a TM with a priority lower than a specified value. Besides a penalty value, you can also set the preferred TM priority threshold.
* **TM suggestion last modified more than**: Penalize TM suggestions that were last modified more than a specified number of months ago. Besides a penalty value, you can also set the threshold in months.
* **TM suggestion last used more than**: Penalize TM suggestions that were last used more than a specified number of months ago. Besides a penalty value, you can also set the threshold in months.

To apply the penalties, click **Save** in the **Match Penalties** section.

## Assigning TM

To assign a TM to your project, in the **Assigned Translation Memories** section, select the needed TMs from the list. The project's default TM is always assigned.

<Aside>
  Some TMs apply to all projects and cannot be disabled directly from the project settings. To exclude one from your project, the account owner can click **Manage Translation Memories**, edit the TM, choose **Selected**, and select every project that should keep using it. Read more about [Sharing TMs](/translation-memory/#sharing-tms).
</Aside>

## Prioritizing TM

When you assign a few TMs to the project, you can set the needed priority for each of them. As a result, TM suggestions from the TM with the higher priority will be displayed in the first place.

The default TM priority value is set to 1. A higher number has a higher priority (for example, 5 has a higher priority than 1). For example, if you assigned four TMs to your project, you can set the priority of 4 to the most important TM, the one that should be used in the first place. And respectively set lower priorities to other TMs.

To set the priority for TMs, in the **Assigned Translation Memories** section, set the preferred priority for each assigned TM from the drop-down list in the **Priority** column.

## Changing Default TM

To change your project's default TM, in the **Assigned Translation Memories** section, click the <Icon name="mdi:star-outline" class="inline-icon" /> icon next to the needed TM in the list.
