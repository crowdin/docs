You can configure project settings according to your needs in the **Settings** tab.

In the **General** section, you can edit the project details, set up a custom domain, share the localization progress with status badges, choose the layout of the project's language pages, and delete the project.

## Project Details {#name}

In the **Project Details** section, you can change the project name and description, and upload a project logo.

### Project Logo

Use the project logo to customize the appearance of your project's main page. To add or replace it, click **Upload** under **Logo**. To remove the current logo, click **Delete Current Logo**.

<Aside>
  Only *.jpg, *.png and *.gif file formats are supported. The newly uploaded image will replace the current logo.
</Aside>

## Custom Domain

The custom domain feature lets you point your own domain to your Crowdin project. When visitors open your custom domain, they are redirected to your project's page on Crowdin.

To set up a custom domain, follow these steps:

<Steps>
  1. Create a necessary domain in the domain name registrar.
  2. Create a CNAME DNS record for this domain name pointing to `cname.crowdin.com` in your hosting service.
  3. Open your Crowdin project and go to **Settings > General**.
  4. In the **Custom Domain** section, enter the created domain name into the **Domain Name** field and click **Update**.
</Steps>

<Aside type="tip">
  Not the person responsible for creating custom domains? [Invite a developer](/inviting-people/).
</Aside>

## Status Badges {#badges}

With status badges, you can share the localization progress of your Crowdin project by embedding them into your website or README.

To embed badges, follow these steps:

<Steps>
  1. Open your Crowdin project and go to **Settings > General**.
  2. In the **Status Badges** section, select **Share project progress publicly via a badge image**.
  3. Under **Embed Code**, select **Markdown**, **HTML**, or **Image URL** and copy the badge code.
  4. Paste the badge code on your website or README.
</Steps>

## Language Page Layout {#project-language-page-view}

In this section, you choose how translators interact with the content on your project's language page.

- **Files only**: This option is useful if your project focuses on file-based translation without the need for visual context. It's an easy setup for projects where the text is self-explanatory or where screenshots aren't necessary.
- **Files and screenshots**: Displaying both files and tagged screenshots allows translators to reference visual context alongside the text. This option is useful for projects where the meaning of the text can be influenced by its visual environment, improving translation accuracy.
- **Screenshots only**: Select this option if every string in your project is associated with a screenshot. By providing visual context for all text, you can significantly improve the quality of translations. This method is considered best practice, especially for projects with complex interfaces or where understanding depends on visual elements. However, it requires effort to maintain the accuracy and relevance of the screenshots.

In string-based projects, the first two options are **Do not show language page**, which skips the language page and opens the Editor directly, and **Show branches and tagged screenshots**, which displays both branches and screenshots.

<Aside title="Prerequisites">
  The **Files and screenshots** and **Screenshots only** options will only work if your [source strings have been tagged](/screenshots/#tag-strings) on the screenshots.
</Aside>

## Project Type

The **Project Type** section shows whether your project is [file-based](/creating-project/#file-based-project) or [string-based](/creating-project/#string-based-project). The project type is set at creation and defines how your content is stored and which API you use.

## Delete Project

This option is accessible exclusively to the project owner. You can delete your Crowdin project with all the translations and related localization resources if necessary.

To delete a project, follow these steps:

<Steps>
  1. Open your project and go to **Settings > General**.
  2. In the **Delete Project** section, click **Delete Project**.
  3. In the dialog that opens, review the project summary: source words, languages, members, and when the project was created and last active.
  4. Select **I understand that this action is irreversible and all project data will be lost.**
  5. Click **Delete project**.
</Steps>

<Aside type="danger">
  Deleting the project will permanently delete all the resources associated with the project, including uploaded files, translations, approvals, etc. Deleted projects cannot be restored!
</Aside>
