In the **Placeholders** section, you choose which placeholder types Crowdin recognizes in your project. The Editor highlights the recognized placeholders in source strings, and the [**Placeholders mismatch**](/project-settings/qa-checks/#qa-check-parameters) QA check compares them between the source string and the translation. Clearing the types your project doesn't use keeps text that matches only their syntax from being highlighted or reported as a mismatch.

## Configure Placeholders

By default, Crowdin recognizes every placeholder type in the list. To choose the placeholder types for your project, follow these steps:

<Steps>
  1. Open your project and go to **Settings > Placeholders**.
  2. Select the checkboxes of the placeholder types you want Crowdin to recognize, and clear the ones your project doesn't use.
  3. Click **Save**.
</Steps>

Saving re-runs the **Placeholders mismatch** check for the project's existing translations in the background, so the reported issues match the updated list. On large projects, this can take a while.

Each placeholder type comes with examples of its syntax and a short description of where it's used. To find a type, search by its name, description, or example in the field above the list. To narrow the list down, select **Enabled**, **Disabled**, or **Unsaved changes** in the status filter next to the search field. The checkbox in the table header selects or clears all the types currently shown.

The **Unified placeholder mismatch** check runs regardless of the types selected in this section.
