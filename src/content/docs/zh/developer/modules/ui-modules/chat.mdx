聊天模块允许在 Crowdin 或 Crowdin Enterprise 界面的右侧面板中创建聊天对话框。面板通过标题栏中的按钮打开和关闭。

## 工作原理

每个带有聊天模块的应用都会在标题栏中获得自己的按钮，带有应用的徽标。当安装了两个以上的聊天模块（包括 Crowdin Assistant（前身为 Copilot）中的模块）时，除 Crowdin Assistant 外的所有应用共享一个打开菜单的按钮。 Crowdin Assistant 按钮始终保持独立并排在最后。

用户可以通过拖动面板的左边缘来调整面板大小。最小宽度为 420 像素，因此请将应用的页面设计为在该宽度下工作。所选宽度会在浏览器中记住。

## 访问权限

您可以将此模块的访问权限授予以下用户类别之一：

对于 Crowdin：

* 仅限我自己（即项目所有者）
* 所有项目成员
* 选定用户

对于 Crowdin 企业版：

* 仅限组织管理员
* 组织项目中的所有用户
* 选定用户

## 结构

```json title="manifest.json"
{
  "modules": {
    "chat": [
      {
        "key": "your-module-key",
        "name": "Module name",
        "description": "Module description",
        "url": "/chat-page"
      }
    ]
  }
}
```
