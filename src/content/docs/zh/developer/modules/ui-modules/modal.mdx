此模块允许您创建一个新的模态对话框。应用从另一个模块打开它，例如[上下文菜单模块](/developer/crowdin-apps-module-context-menu/)或[编辑器按钮模块](/developer/crowdin-apps-module-editor-button/)，或者使用 [AP.editor.openModal](/developer/crowdin-apps-js/#editor-open-modal) 方法。

## 访问权限

您可以将此模块的访问权限授予以下用户类别之一：

对于 Crowdin：

* 仅限我自己（即项目所有者）
* 本人、项目管理员和开发者
* 所有项目成员
* 选定用户

对于 Crowdin 企业版：

* 仅限组织管理员
* 组织管理员、项目管理员和开发者
* 组织项目中的所有用户
* 选定用户

## 结构

```json title="manifest.json"
{
  "modules": {
    "modal": [
      {
        "key": "your-module-key",
        "name": "Module name",
        "url": "/module-url"
      }
    ]
  }
}
```
