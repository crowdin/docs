Crowdin 技能是教 AI 编码代理如何使用 Crowdin 的指令包。安装后，代理了解 Crowdin CLI 命令、配置文件格式、API 客户端和查询语言，因此你可以用纯语言描述本地化任务，而无需自己查找语法。

技能本身不会将代理连接到你的 Crowdin 账户。它们在你的开发环境中、源代码旁边工作，这与 [Crowdin MCP 服务器](/developer/crowdin-mcp-server/)不同。一些技能依赖 MCP 服务器来读取和更改项目数据，Crowdin 插件已包含它。

## 可用技能

**找到正确的方法**

* **`how-to-crowdin`** &ndash; 通过将本地化问题映射到已解决该问题的最低成本方案来回答“在 Crowdin 中如何做 X”：内置功能、对项目数据的一些操作、[Crowdin 商店](https://store.crowdin.com)中的应用或自定义应用。然后详细信息会转到涵盖该路线的技能。

**设置本地化**

* **`i18n-setup`** &ndash; 将项目从硬编码字符串转变为持续翻译，或连接已经国际化的项目。它还准备译员上下文、起始词汇表和截图，并将持续同步交给 `github-action` 技能处理。

**同步内容**

* **`crowdin-cli`** &ndash; 使用 Crowdin CLI 在你的项目和 Crowdin 之间同步源文件和翻译，包括 `crowdin.yml` 配置、自动翻译和从 CLI v4 迁移。
* **`github-action`** &ndash; 在 GitHub 工作流中设置和调试 `crowdin/github-action` 步骤。
* **`integration-sync`** &ndash; 在 Crowdin 与通过已安装的 Crowdin 集成应用连接的平台（如 Webflow、HubSpot、Contentful 或 Zendesk Guide）之间同步内容。它将内容导入 Crowdin、跟踪任务、推送翻译回去，并读取或更改自动同步计划。它通过 Crowdin MCP 服务器或 Crowdin CLI 工作，并在发送前显示每个更改。

**为译员准备内容**

* **`context-extraction`** &ndash; 为需要上下文的源字符串编写上下文，使用 `crowdin context` 命令下载和上传回去。
* **`glossary-terms-extraction`** &ndash; 从你的源字符串和你提供的其他内容（如文档或网站）构建或扩展词汇表。术语仅在你审核后添加，品牌名称标记为不可翻译。
* **`glossary-term-translations`** &ndash; 根据你的项目已经翻译术语的方式填写术语翻译。翻译作为草稿添加供你审核，没有明确对应项的语言保持为空。需要 Crowdin MCP 服务器。
* **`generate-screenshots`** &ndash; 截取你运行的 Web、移动或桌面应用的截图并上传到 Crowdin，标记它们显示的字符串，以便译员看到每个字符串出现的位置。首先找到没有截图的字符串，捕获定义保留在你的仓库中供下次发布使用。

**翻译内容**

* **`translate`** &ndash; 将应用的字符串翻译草稿写入项目的资源文件，并作为供审核的建议上传到 Crowdin。

**处理项目数据**

* **`crowdin-api-client`** &ndash; 使用 JavaScript 和 TypeScript API 客户端，包括分页、上传和错误处理。
* **`croql`** &ndash; 为字符串、翻译、TM 段和词汇表术语编写和优化 CroQL 表达式。
* **`graphql`** &ndash; 针对实际模式编写和调试 Crowdin GraphQL 查询。

**构建应用**

* **`create-app`** &ndash; 搭建、开发和发布 Crowdin 应用。

**发送反馈**

* **`feedback`** &ndash; 起草关于 Crowdin 或其开发者工具的反馈，并在你批准草稿后作为公开 GitHub 问题发送给 Crowdin 团队。

## 安装

技能可与 Claude Code、Claude Cowork、Cursor、OpenAI Codex、Gemini CLI、GitHub Copilot、OpenCode、Cline、Windsurf 和其他 AI 编码代理配合使用。每个客户端以自己的方式添加它们，因此请遵循仓库中的安装说明。

<LinkButton href="https://github.com/crowdin/skills#installation" icon="external" target="_blank">安装 Crowdin 技能</LinkButton>

安装后，当你在使用 Crowdin 的项目中工作或提及它们涵盖的内容时，技能会自动可用。你也可以在请求中直接让你的代理指向它们。

## 技能与 MCP 服务器

技能和 Crowdin MCP 服务器都在不同地方帮助 AI 代理使用 Crowdin。

* **Crowdin 技能**教代理 Crowdin 开发者工具如何工作。代理在你的仓库中针对你的源代码和 `crowdin.yml` 应用这些知识。
* **Crowdin MCP 服务器**将代理连接到你的 Crowdin 账户，以便它可以直接读取和更改项目数据。

你可以同时使用两者：技能在你的仓库中运行正确的命令，MCP 服务器在你的项目中检查结果。当你将 Crowdin 技能作为插件安装时，MCP 服务器会随之而来。 `how-to-crowdin` 技能围绕这种组合构建 &ndash; 它将每个步骤描述为对你的字符串、文件或报告的操作，然后代理可以通过 MCP 服务器执行。
