Crowdin Apps SDK 是一个用于构建自托管应用的 Node.js 框架。你在配置对象中描述应用，SDK 围绕它构建 Express 应用程序，Crowdin 调用的端点已经就位。它还会将应用登录到 Crowdin 并验证 Crowdin 发送的请求，因此你只需编写应用的功能，而不是周围的连接逻辑。

## 你可以构建什么

使用 Crowdin Apps SDK，你可以围绕 Crowdin 支持的任何模块类型构建应用：

* **UI 模块**：Crowdin 内的面板、仪表板、菜单和对话框。
* **AI 模块**：自定义 AI 提供商和提示提供商。
* **文件处理模块**：自定义文件格式，以及导入和导出前后的处理。
* **其他模块**：自定义机器翻译引擎、Webhook、工作流步骤和 QA 检查。

## 构建自托管应用

安装包：

```bash
npm install @crowdin/app-project-module
```

对于应用自身的界面，请基于 [Crowdin UI Registry](https://github.com/crowdin/ui-registry) 构建，这是一个提供 Crowdin 设计令牌和组件的 shadcn 注册表。

使用 Crowdin Apps SDK 构建的应用可以托管在任何运行 Node.js 的地方（例如 Vercel、AWS Lambda 或 Cloudflare Workers）。

## 何时改为构建无服务器应用

如果你的应用完全是界面（仪表板、编辑器面板、菜单扩展），你可以将其构建为无服务器应用：Crowdin 托管并运行它，无需部署或维护服务器。
