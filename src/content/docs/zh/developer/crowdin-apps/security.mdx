当你构建一个处理 Crowdin 数据的自托管应用时，它通过 [`crowdin_app`](/developer/crowdin-apps-app-descriptor/#authentication) 进行身份验证，并在 Crowdin 向其发送的每个请求中收到一个已签名的 JWT 令牌。验证该令牌是应用区分真实请求与其他请求的方式。

两个 SDK 都会为你处理这一点：[Crowdin Apps SDK](/developer/crowdin-apps-sdk/) 会验证令牌并提取上下文，而[无服务器应用](/developer/crowdin-apps-serverless/)根本不会收到令牌。以下内容适用于自行验证请求的应用，例如用其他语言编写的应用。

<Aside>
  带有[工作流步骤类型](/developer/crowdin-apps-module-workflow-step-type/#authentication)模块的应用使用 `crowdin_agent` 身份验证类型，而不是 `crowdin_app`。
</Aside>

## Crowdin 发送的内容

Crowdin 打开模块页面时，会在查询字符串中带上令牌及其上下文：

```shell wrap
https://example.com/app-module?jwtToken=eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJhdWQiOiJCcjRhMmhwUW……MX0.yt-lbv3Z8JyIGX4jG405mjZvX8lwc1q0EfWdTtm9GCc&origin=https://{domain}.crowdin.com&clientId=your-client-id
```

查询参数：

<table>
  <tbody>
  <tr>
    <td><code>jwtToken</code></td>
    <td>
      <p><strong>类型：</strong> <code>string</code></p>
      <p><strong>描述：</strong> 用于授权的 JWT 令牌。</p>
    </td>
  </tr>
  <tr>
    <td><code>origin</code></td>
    <td>
      <p><strong>类型：</strong> <code>string (url)</code></p>
      <p><strong>描述：</strong> 用于打开模块页面的主机。</p>
    </td>
  </tr>
  <tr>
    <td><code>clientId</code></td>
    <td>
      <p><strong>类型：</strong> <code>string</code></p>
      <p><strong>描述：</strong>用于授权的 OAuth 客户端的 ID。</p>
    </td>
  </tr>
  </tbody>
</table>

令牌使用 OAuth 客户端密钥签名，只有 Crowdin 和你的应用知道该密钥，因此有效的签名可以证明请求的来源。验证应用收到的每个令牌的签名和有效期，例如在代码其余部分之前运行的中间件中进行验证。任何[现有的库](https://jwt.io/)都可以为你完成这项工作。

## 令牌载荷

```json
{
  "aud": "Br4a2hpQiNW96anuuO4a",
  "sub": "1",
  "domain": null,
  "context": {},
  "iat": 1600000000,
  "exp": 1600000900
}
```

参数：

<table>
  <tbody>
  <tr>
    <td><code>aud</code></td>
    <td>
      <p><strong>类型：</strong> <code>string</code></p>
      <p><strong>描述：</strong>发布令牌的 OAuth 客户端的 ID。</p>
    </td>
  </tr>
  <tr>
    <td><code>sub</code></td>
    <td>
      <p><strong>类型：</strong> <code>string</code></p>
      <p><strong>描述：</strong>正在向 Crowdin 应用程序发出请求的用户的标识符。</p>
    </td>
  </tr>
  <tr>
    <td><code>domain</code></td>
    <td>
      <p><strong>类型：</strong> <code>string|null</code></p>
      <p><strong>描述：</strong> 访问应用所在的组织。始终存在，且在 Crowdin 中始终为 <code>null</code>。</p>
    </td>
  </tr>
  <tr>
    <td><code class="whitespace-nowrap">context</code></td>
    <td>
      <p><strong>类型：</strong> <code>object</code></p>
      <p><strong>描述：</strong> 打开模块时所处的环境，例如项目、区域设置和用户时区。</p>
    </td>
  </tr>
  <tr>
    <td><code>iat</code></td>
    <td>
      <p><strong>类型：</strong> <code>integer</code></p>
      <p><strong>描述：</strong> 标识令牌的签发时间。</p>
    </td>
  </tr>
  <tr>
    <td><code>exp</code></td>
    <td>
      <p><strong>类型：</strong> <code>integer</code></p>
      <p><strong>描述：</strong> 标识令牌的过期时间。</p>
    </td>
  </tr>
  </tbody>
</table>
