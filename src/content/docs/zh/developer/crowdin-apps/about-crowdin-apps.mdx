使用你的 AI 编码代理构建 Crowdin 应用：

```text wrap
帮我构建一个 Crowdin 应用。请执行以下操作：
1. 使用 npx plugins add crowdin/skills 安装 Crowdin 插件。
2. 询问我应用应该做什么，然后使用 create-app 技能来搭建、开发和发布它。
3. 发布后，打开预览，以便我在 Crowdin 中查看该应用。
```

代理会在你的浏览器中登录 Crowdin，并在其于你的组织中注册应用之前请你确认。发布的应用会安装到你的账户中，清单设置还有谁可以使用它。你之后可以在 [Crowdin 应用权限配置](/developer/crowdin-apps-installation/#crowdin-apps-permission-configuration)中更改。

对最终用户来说，已安装的应用看起来是 Crowdin 完全集成的一部分，其功能直接交付到 UI 中。

## 选择构建方式

有两种方式构建 Crowdin 应用。无服务器应用运行在 Crowdin 基础设施上：你编写 UI，Crowdin 托管并运行应用。自托管应用运行在你操作的服务器上，这使它们可以使用所有模块类型，包括具有服务器端逻辑的模块。两种方式并不互相替代。选择与你的应用功能相匹配的方式。

<CardGrid>
  <Card title="无服务器应用" icon="rocket">
    构建运行在 Crowdin 基础设施上的仪表板、面板和其他 UI 模块。你从 CLI 搭建、预览和发布应用，无需部署或维护服务器。

    当你的应用完全是界面时选择此路径：它显示数据、扩展 Crowdin UI，并代表使用它的人调用 Crowdin API。

    [开始使用无服务器应用 SDK](/developer/crowdin-apps-serverless/)
  </Card>
  <Card title="自托管应用" icon="setting">
    使用任何语言和框架构建由你自己的服务器支持的应用。此路径支持所有模块类型，包括文件处理、AI 提供商和自定义 MT 引擎。

    当你的应用需要服务器端逻辑时选择此路径：它处理文件、响应 Webhook、连接外部服务，或以安装它的账户的权限执行操作。

    [开始使用 Crowdin Apps SDK](/developer/crowdin-apps-sdk/)
  </Card>
</CardGrid>

|        | 无服务器应用                                 | 自托管应用        |
| ------ | -------------------------------------- | ------------ |
| 托管     | Crowdin 运行你的应用                         | 你部署并运行你的应用   |
| 模块     | UI 模块                                  | 所有模块类型       |
| API 调用 | 以在应用内工作的用户身份发起                         | 以安装应用的账户身份发起 |
| 技术栈    | TypeScript，预配置了 React 和 Crowdin UI 工具包 | 任何语言和框架      |

如果你的应用结合了界面和服务器端逻辑，请将其构建为自托管应用。自托管应用也可以包含 UI 模块。

要使用 JavaScript 或 TypeScript 之外的语言构建自托管应用，请参阅[应用描述符](/developer/crowdin-apps-app-descriptor/)和 [Crowdin 应用安全性](/developer/crowdin-apps-security/)参考。

## Crowdin 应用程序示例

从模板开始，而不是从空项目开始：

* [无服务器应用入门套件](https://github.com/crowdin-community/serverless-apps-starter-kit)：无服务器 CLI 搭建的模板，以及一个可从头到尾阅读的完整无服务器应用。
* [Crowdin AI 提供商模板](https://github.com/crowdin-community/crowdin-ai-provider-template)：一个添加自定义 AI 提供商的自托管应用，使用 Crowdin Apps SDK 构建。
* [Crowdin 自定义 MT 模板](https://github.com/crowdin-community/crowdin-custom-mt-template)：一个添加自定义机器翻译引擎的自托管应用。
* [Crowdin 自定义文件格式样板](https://github.com/crowdin-community/crowdin-file-format-template)：一个添加 INI、CONF 和 CFG 支持的文件处理应用，并为译员提供预览。
