Crowdin Serverless Apps SDK 是一个 TypeScript 工具包，用于构建在 Crowdin 基础设施上运行的应用。你编写 UI 并注册应用出现的模块，CLI 构建、预览并发布包。它附带一个 UI 工具包，基于 [Crowdin UI Registry](https://github.com/crowdin/ui-registry)（Crowdin 的 shadcn 组件集）构建，还包含用于应用自身翻译的 i18n 运行时，以及以使用应用的人的身份调用 Crowdin 的 API 客户端，无需管理令牌。

## 你可以构建什么

使用 Crowdin Serverless Apps SDK，你可以围绕 Crowdin 的 UI 模块构建应用：

* **项目模块**：项目内的仪表板、工具、报告和菜单项。
* **编辑器模块**：翻译编辑器旁边的面板。
* **组织和配置文件模块**：组织和配置文件菜单中的页面。
* **对话框**：模态框、上下文菜单和聊天面板。

## 构建无服务器应用

AI 编码代理可以[为你构建应用](/developer/crowdin-apps-about/)，或者你可以自己运行 CLI。 CLI 搭建应用、在本地运行并发布它。

```bash
npm install --global @crowdin/serverless-apps-cli
crowdin-serverless-apps login
crowdin-serverless-apps create my-app
crowdin-serverless-apps dev
crowdin-serverless-apps preview
crowdin-serverless-apps publish
```

Crowdin 托管并运行已发布的应用，因此你无需部署或维护自己的服务器。

## 何时改为构建自托管应用

无服务器应用覆盖 Crowdin 的 UI 方面。当你的应用需要服务器端逻辑（例如文件处理、AI 提供商、自定义 MT 引擎或 Webhook 处理）时，请将其构建为自托管应用。当你的应用结合界面和服务器端逻辑时同样如此：自托管应用也可以包含 UI 模块。

自托管应用与 Crowdin API 的交互方式也不同：它以安装它的账户身份进行调用，而不是以使用它的人的身份。
