当你的应用准备好后，你发布它以便其他人可以安装和使用。这取决于应用运行的位置。

## 发布自托管应用

自托管应用经历两个阶段：

* 设置和部署生产环境
* 在 [Crowdin 商店](https://store.crowdin.com/) 上分发它

### 配置生产环境

在发布之前，设置单独的生产和开发环境，原因有两个：

* **稳定性**：你测试更改而不会冒停机或生产数据丢失的风险。
* **安全性**：只有需要客户数据的人才能访问它。

每个环境都需要自己的 OAuth 客户端、数据库和凭据。

<Aside>
  如果你的应用同时在 Crowdin 和 Crowdin Enterprise 中运行，[联系支持团队](https://crowdin.com/contacts)，我们将使你的 OAuth 客户端全局化，这样你就不需要为每个环境单独设置客户端。
</Aside>

### 部署 Crowdin 应用

自托管应用运行在你控制的基础设施上，因此你可以将其托管在任何通过 HTTPS 提供服务的平台上。 Crowdin 通过应用描述符中的 `baseUrl` 访问应用，因此一旦应用安装，该 URL 必须保持稳定。

使用 Crowdin Apps SDK 构建的应用像任何其他 Node.js 应用程序一样部署。 SDK 文档涵盖了它支持的平台。

<ReadMore>
  阅读更多关于[部署使用 Crowdin Apps SDK 构建的应用](https://crowdin.github.io/app-project-module/deployment/)的内容。
</ReadMore>

#### 在 Crowdin 服务器上托管您的 Crowdin 应用程序

Crowdin 也可以为你托管自托管应用。这与无服务器应用是分开的安排，无服务器应用按设计运行在 Crowdin 基础设施上。提交应用的源代码，一旦我们的团队审核并批准，Crowdin 就会托管该应用。

每种托管安排都有其自己的协议。由 Crowdin 托管的应用还带有一个 <Badge text="Verified by Crowdin" variant="success" /> 徽章。

详情请[联系支持团队](https://crowdin.com/contacts)。

## 发布无服务器应用

无服务器应用不需要你准备自己的基础设施。 Serverless Apps SDK CLI 构建应用并发布包，此后由 Crowdin 提供服务。在你开发应用时，CLI 会将 Crowdin 指向本地服务器，因此相同的模块会在你的机器上运行。

发布会将应用安装到你自己的账户中。要与其他 Crowdin 用户分享，请将其提交到 Crowdin 商店。

<ReadMore>
  阅读更多关于[无服务器应用 SDK](/developer/crowdin-apps-serverless/)的内容。
</ReadMore>

## 在 Crowdin 商店上分发

要在 [Crowdin 商店](https://store.crowdin.com) 上发布，请[联系支持团队](https://crowdin.com/contacts)获取开发者账户。该账户允许你发布应用并查看统计信息，例如安装数量和应用评分。

<ReadMore>
  了解更多关于[发布您的应用程序](/zh/developer/crowdin-apps-publishing/)的信息。
</ReadMore>
