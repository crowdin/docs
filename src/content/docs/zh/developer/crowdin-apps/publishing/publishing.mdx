当您准备好分享您的应用时，可以将其提交至 [Crowdin 商店](https://store.crowdin.com)。发布后，其他 Crowdin 用户即可安装和使用您的应用。但在发布应用之前，你需要在 [Crowdin 商店 CMS](https://developers.app.crowdin.net/admin) 中获取作者账户。为此，请[联系我们的客户成功服务](https://crowdin.com/contacts)并按照提供的说明操作。

## 创建作者页面

每位在 Crowdin 商店发布应用的开发者都将拥有一个个人作者页面。

以下是作者页面示例：[Crowdin](https://store.crowdin.com/author/5)。

获取作者账户后，您可以继续创建作者页面。为此，请导航到[作者](https://developers.app.crowdin.net/admin/collections/authors)集合，然后点击**新建**。您需要为您的作者页面提供一些信息。我们建议在开始发布流程之前完成此操作。

在下表中，您可以查看作者页面需要填写的字段。

| 字段     | 描述                                                                               | 是否必填 |
| ------ | -------------------------------------------------------------------------------- | ---- |
| 名称     | 作者的显示名称（例如公司或开发者名称）。                                                             | 是    |
| 别名     | 在作者页面 URL 中使用的唯一作者标识符。使用描述性的、SEO 友好的小写关键词——不超过 2-3 个词。避免以后更改它，因为这会破坏现有的 URL 和引用。 | 是    |
| 描述     | 显示在作者页面上的简短简介。争取 1-3 句话。                                                         | 是    |
| 电子邮件   | 作者的联系邮箱。它是私有的，仅对已身份验证的用户可见。                                                      | 是    |
| URL    | 可以是企业网站的链接。                                                                      | 否    |
| 支持 URL | 可以是支持页面的链接。                                                                      | 是    |
| 徽标     | 作者的徽标。我们建议使用透明背景的 .png 图片。确保徽标在产品界面的正方形和圆形中都能完美呈现。推荐尺寸：400×400 像素。               | 是    |
| 已验证    | 定义作者是否已通过 Crowdin 团队的验证。在作者页面添加**已验证作者**徽章。只能由 Crowdin 团队设置。                     | 否    |

完成后，点击**保存草稿**。你的作者页面将保持草稿状态，直到 Crowdin 团队审核并发布它——参见[应用审核流程](#app-review-process)。页面发布后，你可以使用侧边栏中的**在商店中打开**按钮在 Crowdin 商店中查看它。

## 准备应用页面

在 Crowdin 商店发布的每个应用都将拥有其专属应用页面。这使其他 Crowdin 用户能够找到并安装您的应用。要开始创建应用页面，请导航到[项目](https://developers.app.crowdin.net/admin/collections/items)集合，然后点击**新建**。您需要为您的应用页面提供一些信息。我们建议在开始发布流程之前完成此操作。

应用页面字段分为几个选项卡。在下面的表格中，你可以查看应用页面需要填写的字段。

### 详细信息选项卡

| 字段     | 描述                                                                                              | 是否必填   |
| ------ | ----------------------------------------------------------------------------------------------- | ------ |
| 类型     | 应用类型。参见[完整的应用类型列表](#app-types)。下面的一些字段仅针对特定应用类型显示。                                              | 是      |
| 名称     | 为你的应用指定名称。可以是描述性名称，也可以有点创意。用户可以使用此名称搜索你的应用，但你也可以使用标签添加相关关键词。                                    | 是      |
| 别名     | 在应用页面 URL 中使用的唯一应用标识符。使用描述性的、SEO 友好的小写关键词——不超过 2-3 个词。确保你的应用别名与应用的 `manifest.json` 文件中的应用标识符匹配。 | 是      |
| 标语     | 推文大小的应用描述。使其引人注目。                                                                               | 是      |
| 徽标     | 应用的徽标。确保它适合产品 UI 中的方形和圆形形状。推荐：透明背景的 400×400 像素 .png 图片。                                         | 是      |
| 作者     | 应用的作者。选择[在上一步中创建的作者](#creating-author-page)。                                                    | 否      |
| 产品     | 产品兼容性。定义应用是否与特定产品兼容。请谨慎选择。允许多选。                                                                 | 是      |
| 类别     | 选择最适合你的应用的类别。你可以选择多个类别。                                                                         | 是      |
| 标签     | 标签允许按关键词对应用进行分组和过滤。                                                                             | 是      |
| 清单 URL | 应用 `manifest.json` 文件的 URL。仅对应用类型显示和必需。                                                         | 在某些情况下 |
| 清单标识符  | 如果你的别名不同，请指定你的应用清单标识符。仅对应用类型显示。                                                                 | 否      |
| 代码     | 用你的 QA 检查代码填写。仅对 QA 检查类型显示和必需。                                                                  | 在某些情况下 |
| 配置     | 位于**高级**部分。其他应用页面选项：**向导** - 显示安装向导，**推荐** - 在 Crowdin 商店中将应用标记为推荐。                             | 否      |
| 定价     | 位于**高级**部分。描述应用页面上显示的应用定价计划。对于免费应用，留空。参见[应用定价](#app-pricing)以查看可能的配置。                           | 否      |

### 内容选项卡

| 字段 | 描述                                                                                                                 | 是否必填 |
| -- | ------------------------------------------------------------------------------------------------------------------ | ---- |
| 内容 | 应用描述放在这里。描述应用的工作原理以及 Crowdin 用户如何从中受益。使用 80-240 个单词。支持 Markdown 语法。此外，你可以添加应用的截图。有关提示，请参见[应用描述](#app-description)。 | 是    |

### 链接选项卡

| 字段             | 描述                                                  | 是否必填   |
| -------------- | --------------------------------------------------- | ------ |
| URL            | 指向与应用相关资源的外部链接。对于指南条目为必填项。可选地，可以为任何其他类型的项目指定。       | 在某些情况下 |
| Enterprise URL | 与 URL 字段类似。主要区别在于此 URL 将显示在 Crowdin Enterprise 商店中。 | 在某些情况下 |
| 资源             | 应用页面上显示的其他链接（例如文档、教程）。每个资源由 URL、标题和适用的产品组成。         | 否      |

### 营销选项卡

| 字段       | 描述                             | 是否必填 |
| -------- | ------------------------------ | ---- |
| 元标题      | 用于搜索引擎和社交分享的页面标题（最多 60 个字符）。   | 否    |
| 元描述      | 搜索结果中显示的摘要（最多 160 个字符）。        | 否    |
| 规范 URL   | 应用页面的自定义规范 URL。                | 否    |
| Robots 元 | 应用页面的 robots 指令（例如 `noindex`）。 | 否    |
| CTA 部分   | 启用项目描述底部的 CTA 部分。              | 否    |
| 相关应用     | 在应用页面上显示为相关应用的其他 Crowdin 商店项目。 | 否    |

### 侧边栏选项

除了选项卡之外，应用页面编辑器的侧边栏中还有一些选项：

| 字段       | 描述                                                        | 是否必填 |
| -------- | --------------------------------------------------------- | ---- |
| Beta     | 定义应用的生命周期状态。测试阶段通常在应用功能完整但可能包含若干已知或未知缺陷时开始。在应用页面上添加相应的标签。 | 否    |
| 在新选项卡中打开 | Crowdin 商店中没有自己页面的一种特殊项目。它只是一个在新选项卡中打开的外部链接。如果启用，则需要 URL。 | 否    |
| 排序       | 用于手动排序的分数。较高的值会使项目排名更高。只能由 Crowdin 团队设置。                  | 否    |

<Aside type="tip">
  侧边栏还包含你应用的快速链接：**在商店中打开**和**在 Crowdin 中打开**分别打开 Crowdin 商店和 crowdin.com 上的应用页面，**打开清单**打开应用的清单文件。
</Aside>

### 应用类型

应用类型列表：

| 类型    | 描述                                                                                                              |
| ----- | --------------------------------------------------------------------------------------------------------------- |
| 应用    | 常规 Crowdin 应用（例如项目集成、编辑器面板、自定义文件格式、资源或报告应用）。应具有清单。                                                              |
| 指南    | 描述某种集成或功能的条目。通常包含外部链接。                                                                                          |
| QA 检查 | 自定义 QA 检查。仅在 Crowdin Enterprise 中可用。要查看示例，请访问 Crowdin 商店上的 [QA 检查部分](https://store.crowdin.com/types/qa-check)。 |
| 系统    | 原生 Crowdin 集成或文件扩展名。                                                                                            |

### 应用描述

**内容**字段对于帮助用户了解您的应用价值至关重要。以下是一些创作引人注目的应用描述以将访客转化为用户的技巧。

#### 构建内容结构

结构清晰的描述有助于用户快速了解您的应用功能：

1. **以价值为先** - 从您的应用提供的主要优势开始
2. **说明工作原理** - 描述关键功能和工作流程
3. **包含使用场景** - 帮助用户设想如何使用您的应用
4. **添加视觉内容** - 截图使您的应用更加直观

#### 使用告示块

您可以在应用描述中使用告示块来突出显示重要信息。支持以下告示块类型：

```md
:::note
使用注释提供额外的上下文或阐明有关应用功能的重要细节。
:::

:::tip[专业提示]
提示非常适合分享最佳实践或建议使用应用的最佳方式。
:::

:::info
使用信息块突出显示关键功能或兼容性信息。
:::

:::warning
警告帮助用户了解安装前应注意的限制、先决条件或潜在问题。
:::

:::danger
谨慎使用危险提示来突出显示关键信息，例如无法撤销的操作或潜在的数据丢失场景。
:::
```

### 应用定价

**定价**字段（详细信息选项卡 → **高级**）描述应用的定价计划。它仅用于在应用页面上渲染定价信息。您还应在应用中实现相应的行为。

<ReadMore>
  阅读更多关于 [Crowdin 应用变现](/zh/developer/crowdin-apps-monetization/)的内容。
</ReadMore>

如果你的应用是免费的，只需将定价列表留空。如果你的应用是付费的，点击**添加计划**并使用以下字段配置计划：

| 字段 <div class="w-28" /> | 描述                                                               |
| ----------------------- | ---------------------------------------------------------------- |
| 计划类型                    | 应用计划的类型。可能的值：**定期**和**免费**。                                      |
| 价格                      | 定期计划的应用价格。指定**每月**或/和**每年**费用并选择货币（USD 或 EUR）。                   |
| 免费试用                    | 定义应用程序是否有试用期。默认情况下，crowdin.com 为 14 天，Crowdin Enterprise 为 30 天。 |

## 应用审核流程

应用程序在 Crowdin 将其列入 Crowdin 商店之前，需要经过审核流程。审核流程包括审查 Crowdin 商店各自页面上的作者和应用描述。

审核已内置到发布工作流中：

1. 新的作者和应用页面始终保存为**草稿**。草稿仅对你和 Crowdin 团队可见——它不会出现在 Crowdin 商店中。
2. Crowdin 团队审核你的页面并首次发布它。
3. 首次发布后，你后续的编辑会立即生效——无需重新批准。

要将已发布的页面从 Crowdin 商店中移除，请取消发布——页面会恢复为草稿并从商店中隐藏而不被删除，因此你以后可以再次发布它。

### 作者验证

您可以为您的组织申请作者验证。**已验证作者**徽章是显示在 Crowdin 商店中作者账户名称旁边的标记，表示 Crowdin 已确认该作者账户是其所代表的公司或个人的真实存在。

要申请作者验证，请[联系我们的客户成功服务](https://crowdin.com/contacts)，我们将就后续步骤达成一致。
