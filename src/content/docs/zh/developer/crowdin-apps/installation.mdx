你可以从 [Crowdin 商店](https://store.crowdin.com) 或手动安装 Crowdin 应用，具体取决于应用是否已经发布。

## 在 Crowdin 中安装

要安装已在 Crowdin 商店上发布的应用，请按照以下步骤操作：

<Steps>
  1. 打开您的个人资料主页，然后在左侧栏中选择**商店**。
  2. 在所需的应用程序上点击 <Icon name="mdi:download" class="inline-icon" />**安装**。 <Image src={storeInstall} alt="商店" />
  3. 在弹出的对话框中，配置首选权限，然后点击**安装**。
</Steps>

要安装私有应用程序，请按照以下步骤操作：

<Steps>
  1. 前往**账户设置 > 应用程序**，然后点击**安装私有应用程序**。
  2. 选择你希望如何安装应用，然后点击**安装**：
     * **从清单 URL** &ndash; 用于在你自己的服务器上运行的自托管应用。粘贴应用的**清单 URL**。
     * **从清单文件** &ndash; 用于 Crowdin 托管的[无服务器应用](/developer/crowdin-apps-serverless/)。上传应用的清单文件（`.json`）。
  3. 配置首选权限。如果你选择了**从清单文件**，还需选择**应用源**：
     * **生产包** &ndash; 将应用的构建作为 `.zip` 包上传。 Crowdin 托管它并将其提供给你的用户。
     * **开发 URL** &ndash; 在开发时从 URL 加载应用，例如从本地开发服务器。
  4. 单击 **安装**。
</Steps>

## Crowdin 应用程序权限配置

在安装期间为每个应用配置首选权限。在此步骤中，你定义谁可以跨模块访问和使用应用，以及可以在你的 Crowdin 账户（对于 Crowdin）或 Crowdin 组织（对于 Crowdin Enterprise）的哪些项目中使用它。

如果你使用**选定的项目**选项限制对某些项目的访问，则应用无法通过 API 与该列表之外的项目通信。应用也仅在选定项目的 UI 中显示。

你可以在安装期间配置这些访问权限，或随时为已安装的应用调整它们：转到**账户设置 > 应用**（对于 Crowdin）或**组织设置 > 应用**（对于 Crowdin Enterprise），然后在应用上选择**编辑**。

### 用户访问类别

你可以定义哪些用户类别可以使用该应用。为每个应用模块单独配置此设置，因此一个模块可以与其他模块具有不同的访问权限。

<Aside>
  模块提供的选项取决于其类型，因此应用可能只显示其中一些。
</Aside>

Crowdin 的可用选项：

* 仅我 &ndash; 安装应用的用户。
* 我、项目经理和开发者 / 翻译请求者
* 所有项目成员
* 所有用户，包括访客（未身份验证的用户）
* 自定义访问 &ndash; 你通过**选择用户**挑选的用户。一旦你选择用户，模块会自动切换到此选项。

<Aside>
  项目所有者始终可以访问应用的所有模块。
</Aside>

Crowdin 企业版的可用选项：

* 仅管理员
* 管理员、经理和开发者 / 翻译请求者
* 所有项目成员
* 所有用户，包括访客（未身份验证的用户）
* 自定义访问 &ndash; 你通过**选择用户**挑选的用户。一旦你选择用户，模块会自动切换到此选项。

<Aside>
  组织所有者始终可以访问应用的所有模块。
</Aside>

### 项目访问配置

你还可以指定可以使用应用的项目（这些设置适用于所有应用模块）。

项目访问选项：

* 我有权访问的所有项目（对于 Crowdin）或所有项目（对于 Crowdin Enterprise）
* 已选项目

## 安装事件通信流

此流程适用于自托管应用，它们在其应用描述符中注册 `installed` 事件。

在账户设置中安装 Crowdin 应用时，会发生授权流程，在此期间 Crowdin 和 Crowdin 应用交换授权数据（授权码交换为访问令牌）。下图显示了此过程中的事件。

<Image src={communicationFlow} alt="Crowdin 与 Crowdin 应用程序之间的通信" />

<Aside>
  已安装事件用于 `crowdin_app` 和 `crowdin_agent` 身份验证类型。对于 `crowdin_agent`，载荷还包含 `agentId` 属性。
</Aside>

让我们详细检查图中的每个步骤：

<Steps>
  1. 安装清单 URL - 用户在**账户设置 > 应用**中粘贴清单 URL 并点击**安装**。
  2. 从清单 URL 获取内容 - 请求被发送到 Crowdin 应用。
  3. 响应：清单 JSON - Crowdin 应用返回包含应用数据的清单 JSON。
  4. 清单数据验证 - 根据清单 JSON 的结构和数据验证收到的内容。
  5. 安装提示 - Crowdin 向用户显示有关 Crowdin 应用的信息、权限列表和**安装**按钮。
  6. 确认安装 - 用户确认安装 Crowdin 应用程序。
  7. 已安装事件 - Crowdin 向 Crowdin 应用发送带有授权码的已安装事件，以便其生成 API 令牌。
  8. 令牌请求 - Crowdin 应用发送请求以获取 API 令牌：
     ```
     POST https://accounts.crowdin.com/oauth/token
     ```
  9. 访问令牌 - 授权服务返回 API 访问令牌和刷新令牌。
  10. 成功代码响应 - Crowdin 应用返回成功状态码（2xx），确认应用安装已完成。如果状态码不同，应用将从 Crowdin 账户中移除。
</Steps>
