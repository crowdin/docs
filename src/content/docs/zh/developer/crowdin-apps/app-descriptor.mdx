应用描述符是一个 JSON 文件，通常为 `manifest.json`，用于告知 Crowdin 该应用是什么以及它添加了哪些模块。

<Image src={integratingCrowdinApps} alt="Crowdin 应用集成" class="no-shadow" />

<Aside type="tip" title="有意开发 Crowdin 应用？">
  从其中一个 SDK 开始：[无服务器应用 SDK](/developer/crowdin-apps-serverless/) 或 [Crowdin Apps SDK](/developer/crowdin-apps-sdk/)。
</Aside>

## 应用描述符结构

应用描述符是一个 JSON 对象。自托管应用从自己的服务器提供它，而无服务器应用将其保留在项目中并通过 CLI 推送到 Crowdin。

### 自托管应用

```json title="manifest.json"
{
  "identifier": "your-application-identifier",
  "name": "Your Application",
  "description": "Application description",
  "logo": "/assets/logos/app-logo.png",
  "baseUrl": "https://example.com",
  "authentication": {
    "type": "crowdin_app",
    "clientId": "your-client-id"
  },
  "events": {
    "installed": "/hooks/installed"
  },
  "scopes": [
    "project"
  ],
  "modules": {
    "project-integrations": [
      {
        "key": "your-module-key",
        "name": "Module Name",
        "description": "Module description",
        "logo": "/assets/logos/module-logo.png",
        "url": "/page/integration",
        "environments": [
          "crowdin", "crowdin-enterprise"
        ]
      }
    ]
  }
}
```

### 无服务器应用

无服务器描述符没有 `baseUrl`，声明 UI 模块时不带 `url`，并省略 `events`，因为 `events` 指向你自己服务器上的 URL。

```json title="manifest.json"
{
  "identifier": "your-application-identifier",
  "name": "Your Application",
  "description": "Application description",
  "bundle": {
    "mode": "internal"
  },
  "scopes": [
    "project"
  ],
  "modules": {
    "project-menu": [
      {
        "key": "your-module-key",
        "name": "Module name"
      }
    ]
  }
}
```

<Aside>
  每个应用必须具有唯一的 `baseUrl`。如果您希望从同一主机提供多个应用，请考虑在 `baseUrl` 中添加路径前缀。
</Aside>

`baseUrl` 必须以 `https://` 开头，并且在应用安装后，如果不先卸载应用，就无法更改，因此在将应用公开之前请先选择好。

清单中的所有其他 URL，例如 `logo`、`events` 和模块 URL，都相对于 `baseUrl`。每个都以 `/` 开头。 Crowdin 会移除 `baseUrl` 末尾的 `/`，因此 `https://example.com/` 和 `https://example.com` 效果相同。

## 身份验证

指定 Crowdin 在签署发往应用的请求时使用的身份验证类型：

* **`crowdin_app`**：通过 OAuth 应用。当应用需要自行随时调用 Crowdin API 时使用。
* **`none`**：不使用 OAuth 应用。应用仍可访问 API，但仅在其在用户端运行时，例如其 iframe 打开时。无服务器应用使用此类型。
* **`crowdin_agent`**：通过 Crowdin 在安装应用时创建的专用机器人用户，这样应用之后可以在项目中继续工作，例如在自定义工作流步骤上。应用的 API 调用以该用户身份进行身份验证。[工作流步骤类型](/developer/crowdin-apps-module-workflow-step-type/#authentication)模块需要此类型。

<ReadMore>
  阅读更多关于 [Crowdin 应用安全性](/developer/crowdin-apps-security/)的内容。
</ReadMore>

示例：

```json title="manifest.json"
{
  "authentication": {
    "type": "crowdin_app",
    "clientId": "your-client-id"
  }
}
```

| 字段         | 类型       | 描述                                                     |
| ---------- | -------- | ------------------------------------------------------ |
| `type`     | `string` | 要使用的身份验证类型：`none`（默认）、`crowdin_app` 或 `crowdin_agent`。 |
| `clientId` | `string` | 通过 `crowdin_app` 类型进行授权的 OAuth 客户端 ID。                 |

## 模块

模块是应用扩展 Crowdin 的方式。每种类型声明应用在界面中出现的位置或其处理的内容：

* **UI 模块**：Crowdin 内的面板、仪表板、菜单和对话框。
* **AI 模块**：自定义 AI 提供商、提示提供商和 AI 请求处理器。
* **文件处理模块**：自定义文件格式，以及导入和导出前后的处理。
* **其他模块**：自定义机器翻译引擎、Webhook、工作流步骤、QA 检查和拼写检查器。

<ReadMore>
  阅读更多关于 [UI 模块](/developer/crowdin-apps-modules-ui/)、[AI 模块](/developer/crowdin-apps-modules-ai/)和[文件处理模块](/developer/crowdin-apps-modules-file-processing/)的内容。
</ReadMore>

## 事件

自托管应用为工作区中发生的事件注册回调。此对象中的每个属性都是相对于应用 `baseUrl` 的 URL，当事件触发时，Crowdin 会向其发送 POST 请求。 `installed` 回调是安装过程本身的一部分，其余回调的行为类似于 Webhook。

示例：

```json title="manifest.json"
{
  "events": {
    "installed": "/hooks/installed",
    "uninstall": "/hooks/uninstall"
  }
}
```

| 事件          | 类型       | 描述                                                                                        |
| ----------- | -------- | ----------------------------------------------------------------------------------------- |
| `installed` | `string` | 在用户在 Crowdin 中安装应用后发送给应用。在 `crowdin_app` 和 `crowdin_agent` [身份验证](#authentication)类型下为必需。 |
| `uninstall` | `string` | 在应用从 Crowdin 卸载之前发送给应用。                                                                   |

### 已安装事件载荷

当用户安装应用时，Crowdin 会向应用发送 `installed` 事件。载荷描述应用安装到的工作区或配置文件、应用本身，以及应用获取 API 令牌所需的凭据。

<ReadMore>
  了解更多关于[已安装事件流程](/zh/developer/crowdin-apps-installation/#已安装事件通信流程)的信息。
</ReadMore>

载荷示例：

```json
{
  "appId": "your-application-identifier",
  "appSecret": "dbfg....asdffgg",
  "clientId": "your-client-id",
  "userId": 1,
  "organizationId": 1,
  "domain": null,
  "baseUrl": "https://crowdin.com"
}
```

```json
{
  "appId": "your-application-identifier",
  "appSecret": "dbfg....asdffgg",
  "clientId": "your-client-id",
  "userId": 1,
  "organizationId": 1,
  "domain": "{domain}",
  "baseUrl": "https://{domain}.crowdin.com"
}
```

参数：

| 字段               | 类型        | 描述                                                                      |
| ---------------- | --------- | ----------------------------------------------------------------------- |
| `appId`          | `string`  | 在应用描述符文件中声明的应用标识符。                                                      |
| `appSecret`      | `string`  | 用于授权你的 Crowdin 应用的唯一密钥。                                                 |
| `clientId`       | `string`  | 在应用描述符文件中声明的 OAuth 客户端标识符。                                              |
| `userId`         | `integer` | 安装应用的用户的数字标识符。                                                          |
| `organizationId` | `integer` | 应用安装到的组织的数字标识符。                                                         |
| `domain`         | `string`  | 应用安装到的 Crowdin 企业版组织的名称。在 Crowdin 中该值始终为 `null`。                        |
| `baseUrl`        | `string`  | 应用安装到的 Crowdin 企业版组织的 `baseUrl`。在 Crowdin 中该值始终为 `https://crowdin.com`。 |
| `agentId`        | `integer` | 为应用创建的代理用户的数字标识符。仅针对使用 `crowdin_agent` 身份验证类型的应用发送。                     |

### 卸载事件载荷

在应用被移除之前，Crowdin 会向应用发送 `uninstall` 事件。与 `installed` 事件类似，载荷描述应用安装到的工作区或账户以及应用本身。使用它来删除你为该工作区或账户存储的数据。

载荷示例：

```json
{
  "appId": "your-application-identifier",
  "clientId": "your-client-id",
  "organizationId": 1,
  "domain": null,
  "baseUrl": "https://crowdin.com"
}
```

```json
{
  "appId": "your-application-identifier",
  "clientId": "your-client-id",
  "organizationId": 1,
  "domain": "{domain}",
  "baseUrl": "https://{domain}.crowdin.com"
}
```

参数：

| 字段               | 类型        | 描述                                                                              |
| ---------------- | --------- | ------------------------------------------------------------------------------- |
| `appId`          | `string`  | 在应用描述符文件中声明的应用标识符。                                                              |
| `clientId`       | `string`  | 在应用描述符文件中声明的 OAuth 客户端标识符。                                                      |
| `organizationId` | `integer` | 应用卸载自的组织的数字标识符。                                                                 |
| `domain`         | `string`  | 应用卸载自的 Crowdin 企业版组织的名称。在 Crowdin 中该值始终为 `null`。                                |
| `baseUrl`        | `string`  | 应用卸载自的 Crowdin Enterprise 组织的 `baseUrl`。在 Crowdin 中该值始终为 `https://crowdin.com`。 |
