与 Crowdin Enterprise 集成的机器翻译引擎提供来自 Google Translate 和 AutoML Translation、Microsoft Translator 等服务的译文建议。

机器翻译建议会按照引擎配置日期的顺序显示在编辑器的**自动建议**部分中。如需优先显示特定引擎的建议，请先配置该引擎。

此外，您还可以使用机器翻译引擎执行[自动翻译](/zh/enterprise/auto-translation/)。

<Image src={machineTranslationSuggestions} alt="在编辑器中的机器翻译建议" />

<LinkCard title="添加更多机器翻译引擎" description="从 Crowdin Store 安装更多机器翻译引擎。" href="https://store.crowdin.com/tags/machine-translation" target="_blank" />

默认情况下，每个项目都启用机器翻译，但需要先配置翻译引擎，然后项目成员才能使用。如果您想为特定项目禁用此选项，请清除[项目设置](/zh/enterprise/project-settings/machine-translation/)中的**显示机器翻译建议**。

## 配置机器翻译引擎

要配置机器翻译引擎，请遵循以下步骤：

<Steps>
  1. 打开您组织的**工作区**，然后选择左侧边栏上的**机器翻译**。
  2. 在右下角，单击 <Icon name="mdi:plus" class="inline-icon" />**添加机器翻译引擎**。
  3. 在出现的对话框中，从**引擎**下拉列表中选择一个引擎。
  4. *（可选）* 编辑机器翻译引擎的**名称**。
  5. 输入所需凭据。
  6. *（可选）* 在**适用语言**字段中，选择机器翻译引擎应为其提供译文的语言。或者，留空以访问所有语言。
  7. *（可选）* 在**在选定项目中启用**字段中，选择你希望使用机器翻译引擎的项目。或者，留空以对所有组织项目启用该引擎。
  8. 单击 **创建**。
</Steps>

### Crowdin Translate

Crowdin Translate 是 Crowdin 自己的机器翻译引擎，因此无需 API 密钥或第三方账户即可使用。

配置 Crowdin Translate 时，你可以调整以下设置：

* **多个译文**：为每个字符串生成四个译文建议，而不是一个。

  目前仅适用于特定语言对。

### 微软翻译器

前往 [Windows Azure](https://portal.azure.com/#blade/HubsExtension/BrowseAll) 获取您的微软翻译 API 订阅密钥。 Translator Text API 可以免费提供 200 万个翻译字符。

配置 Microsoft Translator 时，你可以调整以下设置：

* **模型**：使用你自己的 Microsoft Translator 模型而非通用模型生成译文。输入模型标识符。
* **资源位置**：设置与你的 API 密钥关联的区域。当位置不是 `global` 时指定它。

<LinkCard title="在 Azure 中创建翻译器资源" href="https://learn.microsoft.com/azure/ai-services/translator/how-to/create-translator-resource" target="_blank" />

### DeepL 翻译器

DeepL API 可通过 [DeepL API 套餐](https://www.deepl.com/pro#developer)访问，该套餐与 Web 和桌面应用的 DeepL Translator 套餐是分开的。导航到你的 [DeepL 账号](https://app.deepl.com/your-account/keys) 以获取 API 密钥。

#### DeepL 翻译设置

配置 DeepL Translator 时，你可以调整以下设置：

* **语气**：设置 DeepL 使用的正式程度。仅适用于支持正式程度的语言。
* **模型类型**：选择用于翻译的 DeepL 模型。**延迟优化**是最快的。**优先质量优化**和**质量优化**使用下一代模型，速度较慢且覆盖的语言较少。对于这些模型不覆盖的语言对，你仍然可以从经典模型获得译文。
* **标签处理**：定义 DeepL 如何处理源文本中的标记。选择 **XML** 或 **HTML** 以匹配你的源文件。详细了解[内联标签和机器翻译](#inline-tags-and-machine-translation)。
* **标签处理版本**：控制 DeepL 在译文中放置标签的方式。**版本 2** 改进了标签放置。
* **使用上下文**：向 DeepL 发送额外的上下文（如文件或字符串上下文），以改进产品名称、文章标题或 UI 元素等短文本的翻译。
* **风格规则**：应用在你的 DeepL 账户中定义的写作风格。仅当目标语言与风格规则的语言匹配时才有效。
* **翻译记忆库**：对匹配的片段复用 DeepL 翻译记忆库中先前批准的译文。
* **翻译记忆库匹配阈值（%）**：设置片段必须达到的最低匹配百分比才能被复用，范围为 0 到 100。默认为 75。
* **自定义指令**：使用你自己的指导来引导翻译，例如*保持品牌名称不翻译*。每行输入一条指令，最多 10 条指令，每条 300 个字符。适用于以下目标语言：德语、英语、西班牙语、法语、意大利语、日语、韩语和中文。

<Aside type="note">
  选择**优先质量优化**或**质量优化**模型类型后，会出现**标签处理版本**、**风格规则**、**翻译记忆库**和**自定义指令**选项。风格规则、翻译记忆库和自定义指令还需要 DeepL API Pro 密钥，并且仅适用于下一代模型覆盖的语言对。回退到经典模型的译文不使用它们。
</Aside>

#### DeepL 资源配置

DeepL Translator 可以使用你连接的 DeepL 账户中的术语表、风格规则和翻译记忆库，以保持术语和译文的一致性。在 Crowdin Enterprise 中，你可以为每种类型配置多个资源，并为每个资源分配特定的语言或语言对。

<Aside type="tip">
  要将 Crowdin 术语表中的术语与 DeepL 配合使用，请使用 [DeepL Glossary Sync 应用](https://store.crowdin.com/deepl-glossary-sync)将它们同步到你的 DeepL 账号。
</Aside>

要配置 DeepL 资源，请按照以下步骤操作：

<Steps>
  1. 从相应的下拉菜单中选择术语表、风格规则或翻译记忆库。这些列表会自动从你连接的 DeepL 账户中填充。
  2. 从旁边的下拉菜单中，选择所选资源应适用的语言或语言对。
  3. *（可选）* 要配置同一类型的另一个资源，请点击 <Icon name="mdi:plus-circle" class="inline-icon" /> 并重复上述步骤。要移除资源配置，请点击 <Icon name="mdi:bin" class="inline-icon" />。
  4. 单击 **创建**。
</Steps>

<Aside type="tip" title="语言变体映射">
  Crowdin Enterprise 允许您映射不同的语言变体。例如，如果您在 DeepL 中的术语库使用的是通用源语言（如“英语”），您可以将其映射到 Crowdin Enterprise 项目中的特定变体，例如“英语（美国）”。这样可确保即使您项目的源语言是特定方言（例如，加拿大英语；墨西哥西班牙语），术语库也能正确应用。
</Aside>

### ModernMT 翻译

ModernMT 实时翻译 API 可通过实时或人机交互订阅计划访问。前往 [ModernMT 仪表板](https://www.modernmt.com/dashboard/)获取您的许可证密钥。如果您订阅了其他订阅计划，您可以通过[管理计划](https://www.modernmt.com/dashboard/manage-plan)页面切换到实时计划或人机交互计划。

### Amazon 翻译

Amazon 翻译的免费版本可使用 12 个月。在此之后，您将需要为翻译的字符数付费。 Crowdin 使用 Amazon 翻译提供的标准文本翻译类型。详细了解[可用的 Amazon 翻译定价选项](https://aws.amazon.com/translate/pricing/)。

详细了解如何[获取 Amazon 翻译集成所需的访问密钥](https://docs.aws.amazon.com/general/latest/gr/aws-sec-cred-types.html#access-keys-and-secret-access-keys)。

配置 Amazon Translate 时，你可以调整以下设置：

* **区域**：设置你的 Amazon Translate 资源的区域（例如 `us-east-2`）。请先指定它以加载你的术语。
* **术语**：将你的[自定义术语](https://docs.aws.amazon.com/translate/latest/dg/how-custom-terminology.html)应用于译文。选择术语，然后选择其适用的**语言**。要配置另一个术语，请点击 <Icon name="mdi:plus-circle" class="inline-icon" />。

<QuestionAnswer title="在 Crowdin Enterprise 中设置要使用的 Amazon Translate 所需的 IAM 用户最低权限范围是什么？">
  所需的最低 IAM 权限范围取决于您是否使用术语：

  **不使用术语：**

  ```json
  {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Effect": "Allow",
        "Action": "translate:TranslateText",
        "Resource": "*"
      }
    ]
  }
  ```

  **使用术语：**

  ```json
  {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Effect": "Allow",
        "Action": [
          "translate:TranslateText",
          "translate:GetTerminology",
          "translate:ListTerminologies"
        ],
        "Resource": "*"
      }
    ]
  }
  ```

  或者，您可以使用 [AWS 托管策略：TranslateReadOnly](https://docs.aws.amazon.com/translate/latest/dg/security-iam-awsmanpol.html#security-iam-awsmanpol-TranslateReadOnly)，该策略提供对 Amazon 翻译的必要只读访问权限。

  <Aside>`"Resource": "*"` 允许访问所有资源。为了更严格的安全性，如果适用，请考虑将其限制为特定的 AWS 区域或资源。</Aside>
</QuestionAnswer>

### Google 翻译

要使用 Google 翻译，您应拥有一个具有有效结算资料的 Google Cloud 账户。云翻译根据使用情况按月定价。[了解更多](https://cloud.google.com/translate/pricing)。

要获取集成所需的 API 密钥，请按照以下步骤操作：

<Steps>
  1. 前往 [Google Cloud Console](https://console.cloud.google.com/)。登录到现有的 Google Cloud 账户或设置一个新账户。
  2. 选择现有项目或使用**新建项目**添加项目。
  3. 前往 [API 和服务 > 库](https://console.cloud.google.com/apis/library)并搜索 *Cloud Translation API*。
  4. 单击**启用**。
  5. 前往 [API 和服务 > 凭据](https://console.cloud.google.com/apis/credentials/)并单击**创建凭据 > API 密钥**。
  6. 复制 API 密钥并单击**关闭**。
</Steps>

### Google Cloud AutoML 翻译

要使用 AutoML 翻译，您应拥有一个具有有效结算资料的 Google Cloud 账户。 Google AutoML 翻译每月根据您发送以供翻译的字符数定价。[了解更多](https://cloud.google.com/translate/automl/pricing#translation_costs)。

要创建服务账户密钥并获取集成所需的凭据，请执行以下步骤：

<Steps>
  1. 前往 [Google Cloud Console](https://console.cloud.google.com/)。登录到现有的 Google Cloud 账户或设置一个新账户。
  2. 选择现有项目或使用**新建项目**添加项目。
  3. 前往 [API 和服务 > 库](https://console.cloud.google.com/apis/library)并搜索 *Cloud AutoML API*。
  4. 单击**启用**。
  5. 下一步是创建服务账户私钥对。服务账户由 Crowdin 使用。应用程序使用服务账户进行授权 API 调用。
</Steps>

要设置身份验证并创建您的私钥，请执行以下步骤：

<Steps>
  1. 前往 [API 和服务 > 凭据](https://console.cloud.google.com/apis/credentials/)。
  2. 单击**创建凭据 > 服务账户**。
  3. 在*服务账户名称*字段中，输入一个描述此服务账户功能的名称。
  4. 单击**创建并继续**。
  5. 从*角色列表*中，选择*项目* > *Cloud Translation API 编辑器*，然后单击**继续**。
  6. 单击**完成**。
  7. 在 [API 和服务 > 凭据](https://console.cloud.google.com/apis/credentials/)中，单击已创建的服务账户。
  8. 切换到**密钥**选项卡。
  9. 单击**添加密钥 > 创建新密钥**。
  10. 选择 **JSON** 并点击**创建**。包含密钥的 JSON 文件将下载到您的计算机。
</Steps>

#### Google Cloud AutoML 自定义术语库配置

Google Cloud AutoML 自定义术语库可让您以一致的方式翻译特定领域的术语。您一次只能使用一个 Google Cloud AutoML 自定义模型。如果您想在 Crowdin 企业版项目中使用多个自定义模型，请在您的 Crowdin 企业版账户下创建多个 Google Cloud AutoML 机器翻译引擎实例，并在每个机器翻译引擎的设置中指定不同的模型。在通过机器翻译进行自动翻译期间，您可以交替使用 Google Cloud AutoML 和所需的模型。

要配置您的 Google Cloud AutoML 自定义术语库，请按照以下步骤操作：

<Steps>
  1. 打开您组织的**工作区**，然后选择左侧边栏上的**机器翻译**。
  2. 在右下角，单击 <Icon name="mdi:plus" class="inline-icon" />**添加机器翻译引擎**。
  3. 在出现的对话框中，从**引擎**下拉列表中选择 **Google AutoML Translate**。
  4. 单击**选择文件**并上传您的 JSON 凭据。
  5. *（可选）* 指定你的**资源位置**（例如 us-central1）。一旦你的凭据和资源位置就绪，**自定义模型**和**术语表**下拉列表就会填充。
  6. *（可选）* 选择你的**自定义模型**。<Aside>如果在机器翻译引擎设置中未指定 Google Cloud AutoML 自定义模型，则将使用 Google NMT 模型代替。</Aside>
  7. *（可选）* 从相应的下拉列表中选择你的**术语表**。
  8. *（可选）* 将**自定义模型语言**映射到相应的 **Crowdin 语言**。
  9. *（可选）* 选择适用的语言。或者，留空以访问所有语言。
  10. *（可选）* 选择要使用该机器翻译引擎的项目。或者，留空以对所有组织项目启用该引擎。
  11. 单击 **创建**。
</Steps>

## 机器翻译引擎 ID

指定机器翻译引擎凭据后，系统会自动分配一个唯一的机器翻译引擎 ID。稍后，您可以在 API 请求中使用这些 ID 通过机器引擎进行自动翻译。

您可以在组织的**工作区 > 机器翻译**页面中找到机器翻译引擎 ID。或者，您也可以[通过 API 获取机器翻译引擎 ID](/developer/enterprise/api/v2/#tag/Machine-Translation-Engines/operation/api.mts.getMany)。

## 内联标签与机器翻译

根据你的[*HTML 标签显示*设置](/enterprise/online-editor/#appearance)和文件格式，编辑器可能会以简化的编号形式显示内联标签（例如，用 `\<0>Sample\</0>` 代替 `<a href="https://sample.com">Sample</a>`）。这只是编辑器中的显示选项。这不是 Crowdin Enterprise 传递给机器翻译引擎的形式。

当字符串被机器翻译时，Crowdin Enterprise 处理的是来自原始源文件的内联标记，而不是编辑器中显示的简化标签。机器翻译引擎处理此标记的方式各不相同：有些会在翻译句段内重新定位标签，其位置可能因引擎而异。这也可能影响整体翻译质量。

如果机器翻译建议中的标签以意外的顺序或位置出现，这通常反映的是所选引擎处理内联标记的方式，而不是 Crowdin Enterprise 的设置。

## 清除机器翻译引擎缓存

当机器翻译引擎更新了新功能或模型时，Crowdin Enterprise 中的缓存翻译可能不再反映最新的翻译能力。要在编辑器的**自动建议**部分显示更新后的译文，请清除机器翻译引擎缓存。如果您已在编辑器中查看过某些字符串，这一功能尤为有用，因为 Crowdin Enterprise 会为这些字符串存储缓存的机器翻译建议。

缓存的 MT 建议在编辑器中引擎徽标上标有历史 <Icon name="mdi:history" class="inline-icon" /> 图标。将鼠标悬停在图标上可查看其上次刷新的时间（例如*上次更新：7 小时前*）。

要清除已配置的机器翻译引擎的缓存，请按照以下步骤操作：

<Steps>
  1. 打开您组织的**工作区**，然后选择左侧边栏上的**机器翻译**。
  2. 在列表中的所需机器翻译引擎上单击 <Icon name="mdi:dots-vertical" class="inline-icon" />（或右键单击）。
  3. 单击**清除缓存**。
</Steps>

或者，打开所需的机器翻译引擎进行编辑，然后点击面板右下角的**清除缓存**。

## 禁用机器翻译引擎

如果你需要暂停或停止使用任何已配置的机器翻译引擎，请按照以下步骤操作：

<Steps>
  1. 打开您组织的**工作区**，然后选择左侧边栏上的**机器翻译**。
  2. 点击（或右键点击）所需机器翻译引擎的 <Icon name="mdi:dots-vertical" class="inline-icon" />，然后选择**编辑**。
  3. 关闭**机器翻译已启用**切换开关。
  4. 单击**更新**。
</Steps>

该引擎会保留在列表中，其凭据保持不变，因此你可以随时重新开启**机器翻译已启用**切换开关以再次使用该引擎。
