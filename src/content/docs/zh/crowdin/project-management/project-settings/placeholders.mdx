在 **Placeholders** 部分，你可以选择 Crowdin 在你的项目中识别哪些占位符类型。编辑器会在源字符串中高亮显示已识别的占位符，[**Placeholders mismatch**](/project-settings/qa-checks/#qa-check-parameters) QA 检查会在源字符串和翻译之间比较它们。清除项目不使用的类型可以防止仅匹配其语法的文本被高亮显示或报告为不匹配。

## 配置占位符

默认情况下，Crowdin 识别列表中的每种占位符类型。要为你的项目选择占位符类型，请按以下步骤操作：

<Steps>
  1. 打开你的项目，转到 **Settings > Placeholders**。
  2. 选中你希望 Crowdin 识别的占位符类型的复选框，并清除项目不使用的类型的复选框。
  3. 点击**保存**。
</Steps>

保存会在后台对项目现有翻译重新运行 **Placeholders mismatch** 检查，因此报告的问题与更新后的列表匹配。在大型项目中，这可能需要一段时间。

每种占位符类型都附带其语法示例和使用位置的简短描述。要查找类型，请在列表上方的字段中按其名称、描述或示例搜索。要缩小列表范围，请在搜索字段旁边的状态筛选器中选择 **Enabled**、**Disabled** 或 **Unsaved changes**。表头中的复选框会选中或清除当前显示的所有类型。

无论此部分中选择哪些类型，**Unified placeholder mismatch** 检查都会运行。
