每个项目都会自动创建一个项目翻译记忆。默认情况下，每个已审核或最后添加的译文都会保存到项目翻译记忆中。此行为可自定义为仅保存已审核的译文。

* **启用自动替换**：将翻译记忆翻译建议中的不可翻译元素（如标签、HTML 实体、占位符、数字等）替换为源文本中使用的元素。该功能可改进在自动翻译期间应用的翻译记忆建议，以及在编辑器中显示为翻译建议的建议。改进后的建议列入翻译成本报告，可改进的建议列入成本估算报告。
* **方言的翻译记忆建议**：当没有特定于方言的建议时，显示并使用主语言中针对方言的翻译记忆建议。
* **使用全局翻译记忆**：使译员可以访问全局翻译记忆，启用此功能的项目中的所有翻译都存储在其中。
  <Aside>
      启用此选项后，在此项目中完成的翻译也将添加到全局翻译记忆库，Crowdin 上的任何人都可以访问。
  </Aside>
* **仅将已批准的建议保存到翻译记忆**：仅在翻译获得批准后才将其保存到项目默认翻译记忆。此选项对于公开项目或众包项目尤为有用，可确保只有经过审核的翻译才会存储到翻译记忆中。
* **完全匹配（101%）上下文规则**：定义 Crowdin 在建议完全（101%）匹配的翻译记忆建议时，将什么视为字符串上下文。您可以在以下选项中进行选择：
  * **标识符（键）和上下文**：系统在建议完全匹配的翻译记忆建议时同时考虑字符串的键和上下文。此模式对于键值文件格式尤为有用。
  * **自动**：系统对键值文件格式使用**标识符（键）和上下文**，对其他文件格式使用**上一个和下一个片段**。
  * **上一个和下一个片段**：系统将紧邻当前片段之前和之后的片段作为上下文考虑。最适用于基于 HTML 及其他没有明确键值结构的格式。
  <Aside type="caution" title="限制">
      此选项仅适用于[基于文件](/creating-project/#file-based-project)的项目。
  </Aside>

## 匹配惩罚 {#penalties}

在**匹配惩罚**部分中，你可以配置基于特定条件降低翻译记忆建议匹配百分比的惩罚。当您希望根据具体需求微调翻译记忆建议的相关性时，此功能非常有用。

对于以下每种条件，你可以设置百分比形式的惩罚：

* **应用了自动替换**：对应用了自动替换的翻译记忆建议进行惩罚。
* **多个相同的翻译记忆匹配**：对发现多个相同翻译记忆匹配的建议进行惩罚。
* **翻译记忆优先级低于**：对来自优先级低于指定值的翻译记忆的建议进行惩罚。除惩罚值外，您还可以设置首选的翻译记忆优先级阈值。
* **翻译记忆建议上次修改超过**：对上次修改时间超过指定月数的翻译记忆建议进行惩罚。除惩罚值外，您还可以设置以月为单位的阈值。
* **翻译记忆建议上次使用超过**：对上次使用时间超过指定月数的翻译记忆建议进行惩罚。除惩罚值外，您还可以设置以月为单位的阈值。

要应用惩罚，请在**匹配惩罚**部分中单击**保存**。

## 分配翻译记忆

要将翻译记忆分配到您的项目，请在**已分配的翻译记忆**部分，从列表中选择所需的翻译记忆。项目的默认翻译记忆始终处于已分配状态。

<Aside>
  某些 TM 适用于所有项目，无法直接从项目设置中禁用。要将某个 TM 从项目中排除，账号所有者可以点击 **Manage Translation Memories**，编辑该 TM，选择 **Selected**，并选中所有应继续使用它的项目。阅读更多关于[共享 TM](/translation-memory/#sharing-tms) 的内容。
</Aside>

## 调整翻译记忆优先级

当您为项目分配多个翻译记忆时，您可以为每个翻译记忆设置所需的优先级。因此，优先级较高的翻译记忆中的建议将优先显示。

默认翻译记忆优先级值设置为 1。数值越大，优先级越高（例如，5 的优先级高于 1）。例如，如果您为项目分配了四个翻译记忆，可以将优先级 4 设置给最重要的翻译记忆，即应优先使用的那个。并相应地为其他翻译记忆设置较低的优先级。

要设置翻译记忆的优先级，请在**已分配的翻译记忆**部分中，从**优先级**列的下拉列表中为每个已分配的翻译记忆设置首选优先级。

## 更改默认翻译记忆

要更改项目的默认翻译记忆，请在**已分配的翻译记忆**部分，单击列表中所需翻译记忆旁边的 <Icon name="mdi:star-outline" class="inline-icon" /> 图标。
