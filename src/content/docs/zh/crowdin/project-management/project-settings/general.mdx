您可以在**设置**选项卡中根据需要配置项目设置。

在**常规**部分中，你可以编辑项目详情、设置自定义域名、通过状态徽章分享本地化进度、选择项目语言页面的布局，以及删除项目。

## 项目详情 {#name}

在**项目详情**部分中，你可以更改项目名称和描述，并上传项目徽标。

### 项目徽标

使用项目徽标自定义项目主页的外观。要添加或替换徽标，请单击**徽标**下方的**上传**。要移除当前徽标，请单击**删除当前徽标**。

<Aside>
  仅支持 *.jpg、*.png 和 \*.gif 文件格式。新上传的图片将替换当前徽标。
</Aside>

## 自定义域名

自定义域名功能允许你将自有域名指向你的 Crowdin 项目。当访问者打开你的自定义域名时，他们会被重定向到你的项目在 Crowdin 上的页面。

要设置自定义域名，请按以下步骤操作：

<Steps>
  1. 在域名注册商中创建必要的域。
  2. 在您的托管服务中为该域名创建一条指向 `cname.crowdin.com` 的 CNAME DNS 记录。
  3. 打开你的 Crowdin 项目并转到**设置 > 常规**。
  4. 在**自定义域名**部分中，将创建的域名输入到**域名**字段中，然后单击**更新**。
</Steps>

<Aside type="tip">
  您不是负责创建自定义域名的人员？[邀请开发人员](/zh/inviting-people/)。
</Aside>

## 状态徽章 {#badges}

通过状态徽章，你可以将 Crowdin 项目的本地化进度嵌入到网站或 README 中来分享。

要嵌入徽章，请按以下步骤操作：

<Steps>
  1. 打开你的 Crowdin 项目并转到**设置 > 常规**。
  2. 在**状态徽章**部分中，选择**通过徽章图片公开分享项目进度**。
  3. 在**嵌入代码**下，选择 **Markdown**、**HTML** 或**图片 URL**，并复制徽章代码。
  4. 将徽章代码粘贴到你的网站或 README 中。
</Steps>

## 语言页面布局 {#project-language-page-view}

在此部分中，你可以选择译员如何与项目语言页面上的内容进行交互。

* **仅文件**：如果你的项目专注于基于文件的翻译且不需要视觉上下文，此选项很有用。对于文本含义明确或不需要截图的项目，此选项设置简便。
* **文件和截图**：同时显示文件和已标记的截图，使译员可以在文本旁边参考视觉上下文。此选项适用于文本含义可能受其视觉环境影响的项目，有助于提高翻译准确性。
* **仅截图**：如果项目中的每个字符串都与截图关联，请选择此选项。通过为所有文本提供视觉上下文，可以显著提高翻译质量。此方法被视为最佳实践，尤其适用于界面复杂或理解依赖于视觉元素的项目。但是，这需要付出一定努力来维护截图的准确性和相关性。

在基于字符串的项目中，前两个选项是**不显示语言页面**（跳过语言页面并直接打开编辑器）和**显示分支和已标记的截图**（同时显示分支和截图）。

<Aside title="前提条件">
  **文件和截图**及**仅截图**选项仅在[源字符串已在截图上标记](/screenshots/#tag-strings)时有效。
</Aside>

## 项目类型

**项目类型**部分显示你的项目是[基于文件](/creating-project/#file-based-project)还是[基于字符串](/creating-project/#string-based-project)。项目类型在创建时设置，它决定了内容的存储方式以及你使用的 API。

## 删除项目

此选项仅项目所有者可访问。如有必要，你可以删除 Crowdin 项目及其所有翻译和相关本地化资源。

要删除项目，请按以下步骤操作：

<Steps>
  1. 打开你的项目并转到**设置 > 常规**。
  2. 在**删除项目**部分中，单击**删除项目**。
  3. 在打开的对话框中，查看项目摘要：源词数、语言、成员以及项目的创建时间和上次活动时间。
  4. 选择**我了解此操作不可逆，所有项目数据都将丢失。**
  5. 单击**删除项目**。
</Steps>

<Aside type="danger">
  删除项目将永久删除与该项目关联的所有资源，包括上传的文件、翻译、批准等。已删除的项目无法恢复！
</Aside>
