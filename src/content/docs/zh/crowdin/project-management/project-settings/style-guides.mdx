通过使用风格指南，您可以在一个地方创建、存储和管理项目的所有格式和语气规则。风格指南的主要目的是确保译文在语气、风格和术语使用上保持一致，帮助译者准确理解您的品牌在不同语言中应呈现的风格。

<ReadMore>
  阅读更多关于[规范指南](/style-guide/)的内容。
</ReadMore>

## 分配风格指南

要将风格指南分配给您的项目，请在**风格指南**部分中，勾选列表中所需风格指南旁边的复选框。

<Image src={assigning} alt="分配风格指南" />

<Aside>
  某些风格指南适用于所有项目，无法直接从项目设置中禁用。要将某个规范指南从项目中排除，账号所有者可以点击 **Manage Style Guides**，编辑该规范指南，选择 **Selected**，并选中所有应继续使用它的项目。阅读更多关于[编辑规范指南](/style-guide/#editing-style-guides)的内容。
</Aside>
