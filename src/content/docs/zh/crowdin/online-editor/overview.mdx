编辑器是 Crowdin 中项目成员可以处理译文的主要场所。它允许用户在线建议、投票、审阅和批准译文。

通过编辑器顶部的主菜单（**文件**、**编辑**、**视图**、**语言**、**项目**、**帮助**），您可以选择待翻译内容、下载或上传译文、执行各种字符串操作、更改编辑器布局、切换目标语言、访问项目页面和切换项目、获取帮助资料等。

## 核心功能

编辑器为译员和校对员提供了所有必要的工具，包括：

* 可用于翻译的字符串列表，在不同的[编辑器模式](#editor-modes)下可能有所不同。
* 指导工作的语境、标签和附加信息。
* 用于高效翻译管理的字符串搜索和过滤选项。
* [AI 建议](/crowdin-ai/#using-ai-in-the-editor)、[翻译记忆 (TM)](/translation-memory/) 建议和[机器翻译 (MT)](/machine-translation/) 建议。
* [词汇表](/zh/glossary/)术语，确保一致性。
* 用于协作和报告问题的评论区。

### 字符串列表

此区域显示字符串列表，当前选中的字符串会被高亮显示。字符串是指单个字词、短语或句子的文本元素。部分字符串可能包含替换标记（例如 {0}、{1}、%1 等）或 [ICU 消息语法](/icu-message-syntax/)的元素。这些项目本身不应翻译，而是由网站代码用于动态地将某些信息插入字符串。要使用这些字符串，您应该复制源字符串并只翻译真正的单词。

##### 字符串状态

字符串的状态可能为下列之一：

* <Icon name="untranslated" size="24" class="inline-icon align-middle" /> - 未翻译
* <Icon name="partially-translated" size="24" class="inline-icon align-middle" /> - 部分已翻译（部分复数形式未翻译）
* <Icon name="translated" size="24" class="inline-icon align-middle" /> - 已翻译
* <Icon name="partially-approved" size="24" class="inline-icon align-middle" /> - 部分已批准（部分复数形式未批准）
* <Icon name="approved" size="24" class="inline-icon align-middle" /> - 已批准
* <Icon name="hidden" size="24" class="inline-icon align-middle" /> - 隐藏（仅对项目管理员和校对员可见）

##### 字符串标记

除状态图标外，字符串还可以显示以下标记：

| 标记                                                                          | 出现时机                   | 点击操作                                                                      |
| --------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------- |

| <Icon name="mdi:comment-outline" class="inline-icon" /> **评论**              | 该字符串有评论且没有未解决的问题。      | 打开评论对话框。                                                                  |

<Aside>
  * 如果字符串有未解决的问题，则只显示**含问题的评论**标记，而不显示普通的**评论**标记。
  * 一个字符串只能是**主字符串**或**重复字符串**之一，因此这两个标记不会同时出现。
</Aside>

#### 建议译文

要建议译文，请从列表中选择一个字符串，然后在原文旁边的字段中输入您的建议。当字符串有最大长度限制时，工具栏中的字符计数器会在限制旁边显示翻译长度（例如 28/10）。当翻译超过限制时，数值会变红。

为了简化翻译流程，您可以启用自动保存功能。当在[编辑器设置](#general)中启用 **自动保存译文** 设置后，切换到另一个字符串时，您的译文将自动保存。"正在保存..." 指示符将短暂出现，随后显示 "已保存" 确认消息。

默认情况下，自动保存处于禁用状态，这意味着您需要为每个字符串手动点击 <Icon name="mdi:content-save" class="inline-icon" /> **保存译文**。当自动保存禁用时，**保存译文** 按钮作为主要操作并显示为绿色。当自动保存启用时，该按钮变为灰色，因为手动保存是可选的。

保存后，您的建议将添加到该字符串的译文建议列表中。默认情况下，**自动移至下一个字符串** 选项处于启用状态，因此编辑器将移至下一个字符串。

如果您需要放弃当前输入并在保存前恢复到之前的状态，请点击 <Icon name="material-symbols:undo" class="inline-icon" /> **取消**。

#### 选择多个字符串

在**并排**、**多语言**和\*\*多语言（网格）\*\*模式下，你可以选择多个字符串并同时对所有字符串执行操作。选中所需字符串左侧的复选框，或选中列表上方的复选框以包含页面上的每个字符串。

<Aside type="tip">
  在**并排**和**多语言**模式下，你还可以使用常见的选择快捷键来选择字符串：
  * 要选择连续范围，请点击第一个字符串，按住 <KBD>Shift</KBD>，然后点击最后一个字符串。
  * 要在选择中添加或移除单个字符串，请按住 <KBD>Ctrl</KBD> 或 <KBD>Cmd</KBD> 并点击它们。
</Aside>

选中多个字符串后，你可以执行以下操作：

* 使用列表上方工具栏中的 <Icon name="copy-source" class="inline-icon dark:invert" /> 将源文本复制到其翻译字段中。
* 使用[字符串菜单](#string-menu)中的 **Copy Source Skeleton** 将不可翻译元素复制到其翻译字段中。
* 使用[字符串菜单](#string-menu)中的 **Clear Selected Inputs** 清除其翻译字段。
* 使用列表上方工具栏中的 <Icon name="mdi:content-save" class="inline-icon" /> 或 <Icon name="material-symbols:undo" class="inline-icon" /> 保存或撤销其未保存的翻译。当[编辑器设置](#general)中禁用 **Auto-save translations** 时，这些按钮会出现。

其他操作取决于你在项目中的角色。例如，校对员还可以[批准选中的字符串](#proofreading)。

如果匹配当前筛选条件的字符串跨越多页，请选择页面上的所有字符串，然后点击列表上方横幅中的链接以选择其余字符串。保存、撤销和批准随后会应用于所有字符串。

#### 校对

检查翻译以确保它们可以导出，然后点击建议旁边的 <Icon name="mdi:check" class="inline-icon" /> 以分别批准每个翻译。

要一次批准多个字符串，请[选择它们](#selecting-multiple-strings)，然后点击列表上方工具栏中的 <Icon name="material-symbols:done-all" class="inline-icon" />。

<Aside>
  请务必启用 [QA 检查](/project-settings/qa-checks/)，以帮助您找到需要审核的字符串。发现的问题在需要修订的已翻译字符串下方以红色高亮显示，每个问题都附有描述该问题的消息。
</Aside>

#### WYSIWYG 文件预览

翻译 HTML、XML、TXT、DOCX、XLSX、HAML、Web XML、Markdown、MDX、DITA、Wiki、ADOC、Coffee、FTL、JS、TS 和 FTLH 文件格式的内容时，您可以切换底部面板（适用于并排模式和多语言模式）以查看文件预览（即 WYSIWYG）。对于舒适模式，在使用上述格式时，文件预览默认显示。

字符串状态由以下颜色表示：

* 红色 - 未翻译
* 蓝色 - 已翻译
* 浅绿色 - 已批准
* 灰色 - 无需翻译

当前活跃字符串将以黄色高亮显示。

<Image src={htmlPreview} alt="HTML 视图" />

以下选项可以用来管理上述视图：

* <Icon name="mdi:format-list-bulleted" class="inline-icon" /> - *加载基本列表视图*。用于切换到标准模式并查看字符串列表（仅限舒适模式）。
* <Icon name="mdi:pencil" class="inline-icon" /> - *高亮显示未翻译、已翻译和已批准的字符串*。用于开启或关闭字符串的颜色高亮显示。
* <Icon name="mdi:eye" class="inline-icon" /> - *显示译文预览*。用于开启或关闭译文预览模式。
* <Icon name="mdi:magnify-plus" class="inline-icon" /> - *缩放切换*。用于在放大和缩小视图之间切换（仅限舒适模式）。

##### 全屏与双重预览

当您切换到**全屏**或**双重预览**时，预览将显示整个文件，绕过标准[字符串列表](#string-list)的分页限制。

您可以使用内联编辑以上下文方式进行翻译，而无需使用侧面板：

<Steps>
  1. 直接在 WYSIWYG 预览中点击任何高亮显示的文本。
  2. 将出现一个弹出框，您可以在其中输入并保存您的译文。
  3. 如果您需要在翻译时参考原文，请点击弹出框中的**源字符串**将其展开。
</Steps>

在**双重预览**模式下，点击源文件面板中的字符串会自动高亮显示译文面板中对应的字符串（反之亦然），同时打开译文弹出框。

<Image src={wysiwygInlineEditing} alt="内联编辑弹出框" />

<Aside title="预览限制">
  WYSIWYG 预览旨在提供上下文参考，可能不是最终文件的像素级精确展现。出于安全原因，预览不执行 JavaScript。因此，任何依赖脚本显示的动态内容将不会出现在预览中。
</Aside>

#### 字符串搜索

要在编辑器中查找特定字符串，请在字符串列表顶部的搜索字段中输入您的查询内容。使用键盘快捷键（默认为 <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>F</KBD></span> 或 <span class="whitespace-nowrap"><KBD>⌘</KBD>+<KBD>F</KBD></span>）可立即聚焦到搜索字段。

根据您在编辑器中打开的内容，搜索将应用于当前打开的文件、文件夹或项目中的所有字符串。

要细化搜索结果，请点击搜索字段旁边的 <Icon name="mdi:tune" class="inline-icon" />**搜索过滤器**图标。这将打开一个下拉菜单，包含以下过滤器和选项：

<Image src={stringSearch} alt="字符串搜索" />

##### 搜索范围

通过选择以下条件之一来定义搜索范围：

* *全部* – 搜索源文本、译文、语境和标识符。
* *字符串* – 仅搜索源文本。
* *All translations* – 搜索字符串的每个翻译。
* *Final translations* – 仅搜索翻译列表顶部显示且用于下载的翻译。
* *语境* – 仅搜索字符串语境。
* *标识符（键）* – 仅搜索字符串标识符。

编辑器会在所选选项涵盖的字段中高亮显示匹配项。

##### 选项

使用以下选项进一步细化搜索：

* *区分大小写* – 仅查找大小写相同的字符串。例如，搜索 `Work` 将找到 `Work`、`Works` 和 `Working`，但不会找到 `work`。
* *匹配完整短语* – 查找按精确顺序包含搜索短语的字符串。例如，搜索 `Machine Translation` 将找到 `Machine Translation` 或 `machine translation`，但不会找到 `Translation Machine`。
* *精确匹配* – 仅查找与搜索短语完全相同的字符串。例如，搜索 `Work` 将找到 `Work` 或 `work`，但不会找到 `Works` 或 `Working`。

您可以将*区分大小写*与*匹配完整短语*或*精确匹配*结合使用。请注意，*匹配完整短语*和*精确匹配*是互斥选项。将搜索短语括在引号中会自动启用*匹配整个短语*，除非选择了*精确匹配*。

搜索语句最多可以输入 128 个字符。如果您使用超过 128 个字符的搜索短语，它将自动截断到允许的最大长度。

您还可以通过字符串的内部数字标识符（Crowdin 自动分配的数字）查找特定字符串。为此，请在搜索字段中输入数字 ID（例如 `34354`），不要使用引号，以获得精确匹配。字符串 ID 搜索会忽略筛选器和搜索选项。要搜索该数字在文本或上下文中的出现位置，请将其括在引号中（例如 `"34354"`）或选择 **Search as text**。

#### 字符串筛选

要过滤左侧边栏中显示的字符串，请点击 <Icon name="mdi:filter-variant" class="inline-icon" /> 并选择首选的过滤选项。

可用的过滤选项：

* *显示所有* &ndash; 按原始顺序显示打开的文件/文件夹中的所有字符串。
* *全部，未翻译优先* &ndash; 显示打开的文件/文件夹中的所有字符串。未翻译的字符串显示在列表顶部，然后是已翻译的字符串，已批准的字符串显示在列表底部。
* *未翻译* &ndash; 仅显示没有任何译文的字符串。
* *需要投票* &ndash; 显示已翻译的字符串。
* *未批准* &ndash; 显示已翻译但尚未经校对员批准的字符串。
* *已批准* &ndash; 仅显示带有已批准译文的字符串。
* *未保存的译文* &ndash; 显示您已输入但尚未保存的译文字符串。
* *QA 问题* &ndash; 显示当前语言中有或无未解决 QA 问题的字符串，并可按特定错误进行过滤。
* *Auto-Translated* &ndash; 显示最终翻译（翻译列表顶部的翻译）为自动翻译的字符串。选择 *All* 或将结果缩小到 *TM*、*MT* 或 *AI*。
* *有评论* &ndash; 显示有评论的字符串。
* *含未解决问题* &ndash; 以当前语言或所有语言显示含有未解决问题的字符串。
* *隐藏* &ndash; 显示对译员隐藏的字符串。字符串可由项目管理员手动隐藏，或在 Crowdin 将其标记为重复项时自动隐藏。
* [*高级过滤器*](#advanced-filter) &ndash; 允许您配置自定义过滤和排序参数的过滤器。
* *AI/CroQL 过滤器* &ndash; 一种 AI 驱动的过滤器，允许您使用 [Crowdin 查询语言 (CroQL)](/zh/developer/croql/) 创建自定义查询，以实现增强的字符串过滤。

<Aside type="caution" title="权限">
  某些过滤选项可能仅对具有管理员权限（或更高权限）的项目成员可用。
</Aside>

#### 查看上下文的相邻字符串

在翻译时，了解周围的文本对于准确性至关重要。编辑器允许您显示源文件中紧接在当前活跃字符串前后的字符串，即使它们不符合当前的过滤条件。

要打开或关闭此上下文视图，请点击搜索字段旁边的 <Icon name="garden:puzzle-piece-fill-12" class="inline-icon" /> **Show surrounding strings for context** 图标，或在[命令面板](#command-palette)中选择 **Toggle surrounding strings for context**。启用后，编辑器将为当前页面上显示的所有字符串加载并显示最多五个前置和五个后续字符串。

##### 使用上下文字符串

上下文字符串以拼图图标 <Icon name="garden:puzzle-piece-fill-12" class="inline-icon" /> 标记，并以灰色显示，以区别于主过滤视图中的字符串。您与它们的交互方式取决于您进入编辑器的方式：

* **普通编辑器模式：** 当您直接在编辑器中打开源文件时，您可以像与普通字符串一样与上下文字符串进行交互。尽管显示为灰色，您仍然可以选择它们、添加译文、投票并批准它们。
* **任务模式：** 当您在编辑器中打开特定任务时，上下文字符串仅供参考。它们严格为只读状态，其输入字段和操作按钮均被禁用。这确保您在拥有必要上下文的同时，不会意外修改分配任务范围之外的字符串。

#### 查看字符串统计信息

为帮助您估算工作量和追踪成本，编辑器可以显示列表中字符串的详细统计信息。

您可以通过点击字符串列表底部的字符串数量按钮（例如 **10 STRINGS**），然后从菜单中选择**获取信息**来访问这些统计信息。

将出现一个弹出表格，提供**已过滤**（当前视图中的所有字符串）和**已选定**（仅您手动勾选的字符串）字符串的详细分类。

统计信息包括：

* 字符串
* 词数
* 字符数（不含空格）
* 字符数（含空格）

### 品质保证检查

为帮助您保持译文质量并防止常见错误，编辑器会自动执行质量保证 (QA) 检查。这些检查会扫描标点符号不一致、空格不匹配、缺少占位符或术语不一致等问题。

编辑器的行为取决于这些问题是否配置为**错误**或**警告**：

* **错误（阻断性问题）：** 内联的 **审核问题后保存** 横幅出现，**保存译文** 按钮上显示橙色警告标记。保存译文和导航（例如，更改目标语言、打开不同文件或应用过滤器）将被阻止，直到您解决该问题。将鼠标悬停在 **保存译文** 按钮上会显示 "请先解决阻断性问题" 提示。错误会被严格执行，即使您在个人编辑器设置中禁用了 **QA 问题** 选项，也会触发横幅。您仍然可以切换到翻译另一个字符串，但当前字符串的译文将保持未保存状态，直到错误被修复。
* **警告（非阻断性问题）：** 对于不太严重的不一致问题，行为取决于您的[编辑器设置](#general)中是否启用了 **QA 问题** 选项：
  * **设置开启：** 内联的 **审核问题后保存** 横幅显示警告，**保存译文** 按钮上显示橙色警告标记。导航将被阻止，直到您解决问题或点击 **仍然保存**。
  * **设置关闭：** 译文自动保存（如果启用了自动保存），不显示横幅或警告标记，完全跳过这些警告。

<Aside>
  项目管理员定义特定 QA 检查是作为错误还是警告。但是，某些关键检查（例如语法错误）被永久锁定为错误，以防止严重的译文问题。
</Aside>

如果在您手动保存译文时或在切换字符串时自动保存触发时检测到 QA 问题，这些问题将显示在内联横幅中。以下是标点符号不匹配的示例（默认配置为警告）：

<Image src={qaInlineBanner} alt="QA 问题内联横幅" />

在翻译字段中，编辑器会勾勒出问题所涉及的文本。将鼠标悬停在横幅中的某个问题上，以仅勾勒出该问题。

#### 自动修复 QA 问题

对于许多常见错误，内联 QA 横幅提供自动快速修复：

* 点击单个问题旁边的 <Icon name="mdi:magic-staff" class="inline-icon" /> **自动修复** 图标以自动应用修正。
* 点击横幅标题中的 **修复 (N)** 以立即应用当前字符串的所有可用自动修复。

一旦问题解决，译文将自动保存并允许您继续。

点击右上角的 <Icon name="mdi:dots-vertical" class="inline-icon" />，打开包含以下选项的菜单：

* **Remove Translation**：清除所选字符串的翻译以及关联的 TM 记录。来自主字符串的重复译文不受影响。
* **Hide String** / **Make String Visible**：切换字符串对译员的可见性。隐藏的字符串只对项目管理员或更高权限成员可见。

* **Copy String URL**：使用其唯一链接访问特定字符串，或与同事分享。
* **Copy Source Skeleton**：将不可翻译元素复制到翻译部分。此操作可应用于一个或多个选定的字符串。在翻译包含 ICU 消息语法或 HTML 标签的字符串时非常有用。
* **Clear Selected Input**：清除所选字符串的翻译字段。
* **字符串译文历史**：打开[历史](#history)部分，查看该字符串及其当前语言译文所做的更改。
* **View Master String** / **View duplicate strings**：在新选项卡中打开重复项的主字符串，或主字符串的重复项。
* **Labels**：添加或管理分配给字符串的标签，帮助为特定目的分类或识别它。
* **最大。 Length**：查看并编辑字符串翻译允许的最大字符长度。点击此选项将打开一个包含以下设置的模态框：
  * **Proportional to source texts**：将最大长度设置为源文本长度的百分比。使用滑块或手动输入百分比（例如 100%、150%、200%）来定义限制。
  * **Fixed max. length**：为字符串翻译指定绝对字符限制。
  * **Unlimited**：允许任意长度的翻译，不受限制。
* **Delete String**：从项目中永久移除该字符串。（适用于具有管理员权限或更高权限的项目成员。）

<Aside type="caution" title="权限">
  某些字符串菜单选项可能仅对具有管理员权限（或更高权限）的项目成员可用。
</Aside>

* 语境、标签、屏幕截图和用于指导工作的附加信息。
* 其他项目成员的翻译

由 [Crowdin Assistant](https://store.crowdin.com/crowdin-assistant) 应用或连接到 [Crowdin MCP Server](/developer/crowdin-mcp-server/) 的其他 AI 助手代表成员添加的翻译，会显示在该成员的名字下，并以应用徽标或 AI 图标作为头像上的标记。将鼠标悬停在标记上可查看应用名称。

#### 截图查看器

标记了该字符串的截图会以预览卡片的形式显示在**上下文与译文**部分中。每张卡片显示整个截图，并在使用该字符串的位置周围显示红色轮廓。将鼠标悬停在卡片上可查看放大的预览。

点击卡片打开截图查看器，这是一个可以在编辑器上方拖动和调整大小的对话框。截图打开时会适应对话框大小，下次打开时对话框会保持其大小和位置。

<Image src={screenshotsInEditor} alt="截图查看器" />

查看器工具栏中提供以下选项：

* <Icon name="mdi:minus" class="inline-icon" /> **缩小**（<KBD>-</KBD>）和 <Icon name="mdi:plus" class="inline-icon" /> **放大**（<KBD>+</KBD>）：逐步更改缩放级别。当前级别显示在它们之间。
* <Icon name="mdi:fit-to-screen-outline" class="inline-icon" /> **适应屏幕**（<KBD>Space</KBD>）：将整个截图适应到对话框中。
* **1:1**（<KBD>1</KBD>）：以实际大小显示截图。
* <Icon name="mdi:crosshairs-gps" class="inline-icon" /> **居中到字符串**（<KBD>C</KBD>）：放大到使用该字符串的位置。当字符串在同一截图的多个位置被标记时，每次点击都会移动到下一个位置，计数器会显示你当前所在的位置。
* <Icon name="mdi:chevron-left" class="inline-icon" /> **上一张截图**（<KBD>←</KBD>）和 <Icon name="mdi:chevron-right" class="inline-icon" /> **下一张截图**（<KBD>→</KBD>）：浏览附加到该字符串的所有截图。计数器显示你在列表中的位置。
* <Icon name="mdi:close" class="inline-icon" /> **关闭**（<KBD>Esc</KBD>）：关闭查看器。

滚动以在截图中移动，滚动时按住 <KBD>Ctrl</KBD>（或 <KBD>⌘</KBD>）进行缩放。点击截图可放大到该位置的 200%，按住 <KBD>Alt</KBD>（或 <KBD>⌥</KBD>）点击可缩小回来。对话框处于活动状态时，键盘快捷键可用。

截图上标记的每个字符串都有轮廓。你正在处理的字符串显示为实线轮廓，其他字符串显示为虚线轮廓。点击虚线轮廓可切换到该字符串，查看器会停留在同一张截图上。

当你在列表中选择另一个字符串时，打开的查看器会跟随它。如果新字符串出现在同一张截图上，实线轮廓会移动到它上面。否则，查看器会切换到该字符串的截图。

#### 编辑译文

要在不添加新翻译的情况下更改已保存的翻译，请在 **Context & Translations** 部分中将其悬停，然后点击 <Icon name="mdi:pencil" class="inline-icon" /> **Edit translation**。在舒适模式下，点击译文旁边的 <Icon name="mdi:dots-vertical" class="inline-icon" />，然后选择**编辑译文**。要编辑所选字符串的最新译文，请按 <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>Shift</KBD>+<KBD>↑</KBD></span>，或在[命令面板](#command-palette)中选择**编辑我的最新译文**。

校对员（或更高权限）可以编辑其语言中的任何译文，包括已批准的译文。译者可以编辑自己的译文，直到其被批准为止。

进行更改后，点击 <Icon name="mdi:content-save" class="inline-icon" /> **保存译文**，或按 <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>Enter</KBD></span> 或 <span class="whitespace-nowrap"><KBD>⌘</KBD>+<KBD>Enter</KBD></span>。要放弃更改，请点击 <Icon name="material-symbols:undo" class="inline-icon" /> **取消**或按 <KBD>Esc</KBD>。编辑后的文本会像新译文一样经过相同的[品质保证检查](#qa-checks)。保存后，点击译文下方的**撤销**可恢复之前的文本。

如果在你编辑译文期间其他人更改了该译文，请选择是使用**使用他们的版本**保留他们的文本，还是使用**用我的覆盖**将你的文本保存覆盖上去。

批准会保留在编辑后的译文上，并标记为“批准后已更改”。如果新文本需要再次审阅，请点击批准旁边的**移除**。

编辑过的译文会在其日期旁边标记为\*\*(已编辑)\*\*。将鼠标悬停在该标记上可查看谁在何时编辑了译文，或点击该标记在[历史](#history)部分查看译文的更改。

#### 自动建议

AI、TM 和 MT 建议会分组在一个可折叠的 **Automated Suggestions** 部分中。

点击其中一条建议，它将自动出现在译文字段中。可以将其作为您自己建议的参考基础。

翻译记忆建议可能包含额外详情，例如翻译记忆名称、匹配百分比、创建日期以及（如果有）最初提交该译文的贡献者姓名（以全名和用户名显示，例如 *by Michael Ross (m.ross)*）。这些信息有助于提供关于每条建议来源和相关性的更多上下文。

部分建议还可能带有**高相关性建议** <Icon name="mdi:check-decagram" class="inline-icon" /> 标签。此标签帮助您识别高度可信的译文。它出现在具有完美匹配（101%）且来自之前已批准译文的翻译记忆建议上。

要快速将翻译记忆或 MT 建议复制到译文字段并保存，请点击所需建议上的**使用并保存** <Icon name="mdi:content-save" class="inline-icon" />。

### 注释

使用**评论**区域，您可以讨论源字符串的含义或其他相关问题。建议使用项目的源语言，以便其他译员能够理解。使用 "@" 字符和用户名，将您的消息定向给特定人员。

### 搜索翻译记忆

使用 *Search TM* 部分，你可以检查来自[翻译记忆](/translation-memory/)的所有可用翻译，翻译记忆是项目经理上传到系统的翻译库。为帮助您快速找到最佳结果，搜索会优先将最相关的匹配项显示在列表顶部。

搜索翻译记忆区域提供以下选项：

* 源语言 &ndash; 在源语言中搜索匹配项。
* 目标语言 &ndash; 在目标语言中搜索匹配项。
* 猜测译文 &ndash; 高亮显示搜索短语的可能译文。
* 数字等效 &ndash; 将搜索短语中的数字与任何其他数字匹配。

此外，为了最大化搜索结果，您可以在搜索短语中使用以下通配符：

输入星号 **(\*)** 查找结尾或开头可能不同的单词。示例：any\* 查找 *any*、*anyway*、*anything*
示例：\*way 查找 *way*、*anyway*、*highway*

输入加号 **(+)** 查找结尾或开头必须不同的单词。示例：any+ 查找 *anyway*、*anything*、*anywhere*，但不包括 *any*
示例：+way 查找 *anyway*、*highway*、*someway*，但不包括 *way*

输入减号 **(-)** 从搜索结果中排除单词。例如：Save -as

使用引号查找精确的单词组合。例如："Save as"

搜索结果中的每条翻译记忆建议还包含详细信息，例如翻译记忆名称、创建日期以及（如果有）最初提交该译文的贡献者姓名。

<Steps>

### 术语

术语区域允许您浏览项目词汇表（如果有）并搜索特定术语。如果在词汇表中找不到某个术语，将显示 Wikipedia 说明作为参考。

部分术语可能已有译文，有助于维护项目的一致性。要复用已翻译的术语，请点击带下划线的文本，其翻译将自动出现在翻译字段中。或者，将鼠标悬停在带下划线的文本上，然后在卡片中悬停在你需要的术语翻译上，并点击 **Insert**。当术语有多个翻译且你需要特定一个时，请使用此功能。

如果术语还没有翻译，点击带下划线的文本会为管理术语库的项目成员打开 **Edit Concept** 对话框。对于其他项目成员，它会打开 Terminology 部分。

每个术语以卡片形式显示。折叠的卡片显示术语、其主题及其翻译及其状态。点击卡片或 <Icon name="mdi:chevron-down" class="inline-icon" /> 以展开它。展开的卡片还会显示概念定义、注释、图片和参考链接。对于每个术语，它显示语言、词性、类型、性别和状态，以及任何描述、注释和参考链接。

要一次展开或折叠所有卡片，请点击列表上方的 <Icon name="mdi:unfold-more-horizontal" class="inline-icon" />。此设置适用于整个部分，并在你下次打开编辑器时被记住。

卡片底部显示该术语来源的术语库。管理该术语库的项目成员可以点击名称打开术语库概念。

## 编辑器模式

编辑器提供多种查看模式以适应不同的翻译工作流。可用模式包括**并排**、**舒适**、**多语言**和**多语言（网格）**，每种模式都提供独特的布局用于呈现和管理译文。**并排**模式默认启用，但您可以根据需要轻松切换。

您可以通过以下方式切换编辑器模式：

* **通过视图菜单** &ndash; 转到主菜单中的**视图**，选择首选模式。
* **通过编辑器视图图标** &ndash; 点击右上角的**编辑器视图**图标，选择首选模式（此图标仅在[编辑器设置](#appearance)中禁用**水平菜单**时可用）。

### 审阅视图

并排模式在[核心功能](#core-features)部分中有详细介绍，适合同时管理多条译文。译员可以同时处理多个字符串，或快速审阅现有译文并投票。管理员和校对员可以在同一视图中高效批准最佳选项。

### 默认视图

舒适模式允许译员和校对员一次专注于一个字符串，确保准确性而不受干扰。它突出显示活跃字符串，使审阅上下文和相关资源更加容易。此模式非常适合处理复杂的翻译或进行详细的校对工作，在这些情况下精确性和全面性至关重要。

主工作区域，源字符串位于顶部，译文区域位于下方。要添加译文，您需要从左侧区域选择一个字符串，它将出现在中上部的*源字符串*字段中。

<Image src={comfortable} alt="舒适编辑器模式" />

### 多语言模式

多语言模式提供与并排模式类似的功能，允许多语言译员和校对员同时处理多种语言。你可以选择任意数量的语言同时处理，最多可达项目中的所有语言。右侧面板显示您正在输入译文的语言的字符串译文，或最后选择的语言的译文。此外，为了以更少的翻页提供更多上下文，编辑器在此模式下每页显示 50 个字符串。

<Image src={multilingualMode} alt="多语言模式" />

切换到多语言模式后，选择您想使用的语言，然后点击**应用**。要一键快速选择所有项目语言，请使用 **Select All** 按钮。要添加新语言或移除之前选择的部分语言，请转到主菜单中的 **Language**，对语言列表进行必要的修改，然后点击 **Apply**。你还可以使用 **Clear** 按钮在做出新选择之前快速取消选择所有语言。

### 多语言模式（网格）

除多语言模式外，还有一个独立的多语言（网格）模式。它提供类似电子表格的布局，每种语言显示在单独的列中，允许您以紧凑的表格格式处理多种语言。与标准多语言模式一样，它支持同时使用无限数量的语言，每页显示 50 个字符串。

要调整此模式中显示的列的顺序和可见性，以及固定特定列，请点击右上角的**排序列**并选择首选列。您也可以通过选择列表底部的**重置为默认**将布局重置为默认列集。

此外，要固定或隐藏单个列，请将鼠标悬停在列标题上以显示下拉箭头。点击箭头并选择 **Pin Column** 或 **Hide Column**。

你可以使用以下功能自定义网格布局并更高效地与单元格交互：

* **Row Sizes** &ndash; 使用右上角的按钮在 <Icon name="material-symbols:table-rows-outline" class="inline-icon" /> **Compact**、<Icon name="mdi:view-stream-outline" class="inline-icon" /> **Medium** 和 <Icon name="material-symbols:square-outline-rounded" class="inline-icon" /> **Large** 模式之间切换表格密度。这使你能够找到最舒适的显示密度。
* **Inline Action Buttons** &ndash; 将鼠标悬停在翻译单元格上时，该单元格中会直接出现一个迷你面板，其中包含快捷操作：**Save**、**Cancel**、**Approve** 和 **Copy Source**。这使你无需将光标移到右侧面板即可高效管理翻译。
* **Inline Statuses and QA Checks** &ndash; 字符串状态和品质保证 (QA) 检查结果直接显示在每个单元格内。如果翻译存在 QA 问题，它会在文本旁边用 <Badge text="QA" variant="danger" /> 指示器清晰高亮显示，提供即时的视觉反馈。

<Image src={multilingualModeGrid} alt="多语言模式网格视图" />

#### 面向校对员

校对流程与并排模式基本相同，区别在于一次批准或移除多个字符串的批准时，系统会对多语言模式下选择的所有语言执行该操作。

#### 在多语言模式中使用过滤器

在多语言模式中使用过滤选项时，系统将显示在所选语言中至少有一种语言满足所选条件的字符串。选择至少一个目标语言后，依赖于翻译的筛选器将变为可用。

此行为适用于以下过滤选项：

* 未翻译
* 未批准
* 已批准
* QA 问题
* 自动翻译
* Advanced Filter > Translations > Translations Updated
* Advanced Filter > Strings > Translation Status > Partially Translated (Plurals)
* Advanced Filter > Translations > Conditions > Translation Equals Source String
* Advanced Filter > Translations > Votes

## 翻译从右向左语言

在 LTR 和 RTL 语言之间进行翻译时，编辑器译文字段中的某些元素可能无法与导出后的显示方式相同。

为确保 RTL 译文在导出文件中正确显示，我们建议按照以下方式进行翻译：

<Steps>
  1. 点击源文本下方的 <Icon name="copy-source" class="inline-icon dark:invert" />（或使用 <KBD>Alt</KBD>+<KBD>C</KBD> 组合键）。
  2. 将原文翻译成目标语言。
  3. 在译文中保持变量、标签等不变，即使它们看起来有误。在导出的文件中，它们会处于正确的位置。
</Steps>

<Image src={rtlLanguages} alt="保存 RTL 语言建议" />

<Aside type="tip">

</Aside>

## 编辑器设置

要打开编辑器设置，请点击右上角的 <Icon name="mdi:cog" class="inline-icon" />。

编辑器设置按选项卡分组，包含用于根据您的偏好配置编辑器的各种选项。

### 概况

* *翻译记忆建议* &ndash; 您可以指定译文字段下方显示的翻译记忆建议的最低相似度匹配（以百分比表示）。
* *Translation alignment* &ndash; 如果启用，项目中已有翻译的源单词会用虚线加下划线。将鼠标悬停在带下划线的单词上，查看其以前的翻译以及每个翻译的使用次数。阅读更多关于[翻译一致性](/translation-consistency/)的内容。
* *自动补全* &ndash; 如果启用，当您输入译文时将出现包含翻译预测和自动完成的弹出窗口。
* *QA issues* &ndash; 如果启用，每次你尝试保存存在某些不准确的翻译（标点/标签/空格不匹配、缺少变量等）时，都会出现带有警告的内联横幅
* *实时拼写检查* &ndash; 在您输入译文时即时查看拼写问题。译文旁边显示的 <Icon name="mdi:spellcheck" class="inline-icon" /> 表示未发现拼写问题。否则，您将看到一个红色标签，显示检测到的拼写问题数量。点击它查看更多详情，或点击带下划线的单词以仅查看该单词的建议。内置拼写检查优先于浏览器扩展（例如 Grammarly 或 LanguageTool）。如果您更喜欢使用第三方工具，请禁用此选项并重新加载页面。
* *自动批准* &ndash; 如果启用，校对员或更高权限成员添加的译文将自动获得批准。
* *自动移至下一个字符串* &ndash; 如果启用，保存新译文或批准现有译文后，您将自动移至下一个字符串。

### 导航与快速访问

编辑器左上角的导航路径显示您在工作区中的当前上下文，提供对文件统计信息、任务信息和项目导航的快速访问。其行为取决于您的[编辑器设置](#appearance)中是否启用了**水平菜单**。

**启用水平菜单时（默认）：**

路径可作为你所在位置（项目名称、目标语言或文件名）的视觉指示器，并在悬停时提供快速参考信息：

* **File Details**：将鼠标悬停在文件名上会打开一个弹出框，显示该文件及其所在文件夹的翻译和批准进度（单词数和百分比）。点击弹出框中的文件名以复制文件链接，或点击文件夹以复制文件的完整路径。
* **Task Details**：当你在编辑器中打开任务时，任务标题会连同其对应的任务类型图标一起出现在路径中。将鼠标悬停在任务标题上会显示一个弹出框，包含额外详情，包括任务的直接可点击链接（在新标签页中打开）、目标语言和任务类型。

**禁用水平菜单时：**

您可以点击导航路径中的各个项目以打开其各自的下拉菜单：

* **Project**：点击当前项目名称以访问项目级选项。
* **Language**：点击当前语言以切换到另一个目标语言。
* **File**：点击当前文件名以打开文件菜单。

### 所选单词的上下文菜单选项

### 切换文件和文件夹

编辑器在可折叠的左侧面板中集成了文件浏览器，允许您在不离开翻译工作区的情况下导航和选择文件或文件夹。这提供了更流畅、更高效的用户体验。

您与文件浏览器的交互方式取决于您当前的编辑器模式：

* **在并排、多语言和多语言（网格）模式下** – 您可以通过点击右上角的 <Icon name="mdi:dock-left" class="inline-icon" /> 图标或使用键盘快捷键 <KBD>Ctrl</KBD>+<KBD>[</KBD> 来显示或隐藏文件浏览器面板。或者，您可以通过从主菜单中选择**文件 > 打开**或使用键盘快捷键 <KBD>Ctrl</KBD>+<KBD>O</KBD> 或 <KBD>Cmd</KBD>+<KBD>O</KBD> 来打开面板。
* **在舒适模式下** – 左侧面板可以在两种视图之间切换：**文件**和**字符串**。当您在**文件**视图中选择一个项目时，**字符串**视图会自动更新以显示相关内容。

在文件浏览器底部，你可以看到所选项目的路径，例如 `/app/src/main/res/values/strings.xml`。如果选择了多个项目，那里会显示所选内容的摘要，例如 `3 files selected`。具有管理员权限的项目成员还可以通过点击文件浏览器工具栏中的 <Icon name="mdi:eye-off-outline" class="inline-icon" /> **隐藏文件**图标来切换树中隐藏文件（如果有）的可见性。

<Aside type="tip">
  您可以使用常见的选择快捷键来选择多个文件和文件夹：
  * 要选择连续范围，请点击第一个项目，按住 <KBD>Shift</KBD>，然后点击最后一个项目。
  * 要选择或取消选择多个单独项目，请按住 <KBD>Ctrl</KBD> 或 <KBD>Cmd</KBD> 并点击您需要的文件或文件夹。
</Aside>

要在不打开项目的情况下对其进行操作，请在文件浏览器中右键点击它。如果你右键点击的项目是你选择的一部分，则该操作应用于所有选中的项目。根据项目类型和你的权限，菜单提供以下选项：

* **Open in new tab**：在新的浏览器选项卡中打开该项目。多个选中的项目会在一个选项卡中一起打开。
* **Copy**：访问子菜单，其中包含复制项目路径、名称或链接的选项。
* **Source File Preview** 和 **Translated File Preview**：在[文件预览](#source-and-translated-file-preview)中打开文件。
* **Download**：以原始格式下载文件。
* **Export as XLIFF**：将项目下载为 XLIFF 文件。文件夹、分支或几个选中的项目会导出到一个 XLIFF 文件。
* **Export Filtered as XLIFF**：仅将符合当前筛选和搜索条件的字符串下载为 XLIFF 文件。
* **Upload Translations**：上传包含该项目翻译的文件。对于文件夹、分支或几个选中的项目，请上传 XLIFF 文件。

<Image src={fileBrowser} alt="编辑器中的文件浏览器面板" />

要复制编辑器中打开文件的路径，请在主菜单中选择 **File > Copy File Path**（在基于字符串的项目中为 **Branch > Copy Branch Path**）。当打开 **All Strings** 或多个文件时，它会复制包含所选字符串的文件的路径。你还可以使用[命令面板](#command-palette)中的 **Copy File Path** 和 **Copy File Link** 命令（在基于字符串的项目中为 **Copy Branch Path** 和 **Copy Branch Link**）复制打开文件的路径或链接。

要查看项目中的所有字符串，请打开文件浏览器并在文件列表顶部选择**所有字符串**。

要快速找到并重新打开您最近处理的文件之一，请转到**文件 > 最近的文件**并选择所需的文件。

### 源文件和已翻译文件预览

除了显示文件渲染效果的 [WYSIWYG 文件预览](#wysiwyg-file-preview)之外，还有**源文件预览**和**已翻译文件预览**模式，允许用户直接在编辑器中查看源文件和已翻译文件的原始内容。这些预览提供了对文件结构、布局和格式的了解，帮助用户确保在正确的上下文中进行准确的翻译。这对于在不离开编辑器的情况下识别差异或格式问题特别有帮助。**已翻译文件预览**对所有用户可用，而**源文件预览**仅限于具有开发者/翻译请求者权限或更高权限的成员。

要在任一预览中打开文件，请转到主菜单中的**文件**，并选择所需的文件预览模式。

### 编辑器中的自动翻译

使用**自动翻译**功能，你可以直接在编辑器中使用 AI、翻译记忆或机器翻译为多个字符串应用译文。它为您提供对流程的精细控制：您可以使用高级过滤器隔离特定字符串，直观地检查您的选择，并专门为该批次运行自动翻译。

要在编辑器中应用自动翻译，请按照以下步骤操作：

<Steps>
  1. 您可以通过两种方式在编辑器中打开自动翻译对话框：
     * **主菜单** – 转到主菜单中的**编辑**，选择**自动翻译**。
     * **字符串菜单**（在**并排**和**多语言**模式下可用）– 点击右上角的 <Icon name="mdi:dots-vertical" class="inline-icon" />，然后选择**自动翻译**。
  2. 在**自动翻译字符串**对话框中，配置以下参数：
     * **自动翻译方式** – 选择您首选的方法（**AI**、**翻译记忆**或**机器翻译**）。
     * **AI 提示词**（特定于通过 AI 自动翻译）– 选择将指导 AI 模型行为的提示词。
     * **自定义指令（可选）**（特定于通过 AI 自动翻译）– 添加任何额外上下文或特定指令来指导 AI。您的输入将与所选提示词一起包含在内。
     * **翻译引擎**（特定于通过机器翻译自动翻译）– 选择要使用的机器翻译引擎。
     * **自动翻译完成时通知我** – 在自动翻译完成、失败或被取消时收到通知。通知会通过你在[通知设置](/account-settings/#notifications)中为 **Auto-Translation** 事件选择的渠道送达。
     * **范围** – 选择要应用自动翻译的字符串范围：
       * **已选字符串**（特定于**并排**和**多语言**模式）– 仅适用于在编辑器中手动选定的字符串。
       * **已过滤字符串** – 适用于与当前过滤器匹配的所有字符串。
       * **文件**（打开多个文件时为**选定的文件**，基于字符串的项目中为**分支**）– 应用于编辑器中当前打开的文件、多个文件或分支。
       * **所有文件**（基于字符串的项目中为**所有分支**）– 应用于项目中的所有字符串，无论编辑器中当前打开的是哪个文件或分支。
     * **要处理的字符串** – 选择**未翻译的字符串**、\*\*已翻译的字符串（重新翻译）\*\*或两者。
       <Aside>
                 以下重新翻译设置仅在选择了\*\*已翻译的字符串（重新翻译）\*\*选项时出现。
       </Aside>
     * **当此字符串已有译文时** – 选择如何处理现有译文：
       * **在现有译文旁添加译文**（默认）
       * **替换自动生成的译文（保留人工译文）**
       * **替换所有现有译文**
     * **跳过已批准的字符串** – 防止覆盖已有已批准译文的字符串。
     * **允许重复译文** – 即使与现有译文重复，也添加译文。在[自动翻译准确度](/project-reports/#auto-translation-accuracy)报告中比较 AI 提示或 MT 引擎时很有用。
     * **重置批准状态以便校对员重新审阅** – 删除所有被替换译文的批准状态，确保可以再次审阅和验证。
       <Aside title="设置依赖关系">
                 某些选择将自动禁用其他选项：
                 * **替换所有现有译文**会禁用**允许重复译文**和**重置批准状态以便校对员重新审阅**选项。
                 * **跳过已批准的字符串**会禁用**重置批准状态以便校对员重新审阅**选项。
       </Aside>
     * **最低匹配率**（特定于通过翻译记忆自动翻译）– 选择翻译记忆匹配所需的最低相似度：**100%** 或**完美**。
       <ReadMore>
                 阅读更多关于[TM 匹配类型](/translation-memory/#tm-match-calculation)的内容。
       </ReadMore>
  3. 展开**高级设置**区域以微调自动翻译流程：
     * **翻译来源** – 选择用作自动翻译源的语言。默认情况下，它预选为项目的源语言，但你可以选择任何其他项目语言。这为你提供了更大的灵活性，并可以提高翻译质量：你可以使用更合适的现有翻译（例如，使用改编的英文版本而不是原始日文），或直接在相关语言之间翻译（例如，西班牙语到葡萄牙语）。
       <Aside>
                 对于通过 AI 的自动翻译，项目的原始源文本也会作为上下文包含在内，以确保更高的准确性。
       </Aside>
     * **批准添加的译文**（特定于通过翻译记忆进行的自动翻译）– 自动批准通过自动翻译添加的译文。选项包括：
       * **完美匹配** – 仅批准具有 101% 匹配度的译文。
       * **完美匹配（之前已批准）** – 仅批准之前已批准的完美匹配译文。
       * **All (skip auto-substituted suggestions)** – 批准除通过自动替换改进的翻译之外的所有内容。
       * **全部** – 批准所有已添加的译文。
  4. 点击**自动翻译**。
</Steps>

在并排和舒适模式下，自动翻译应用于编辑器中当前选定的单一语言。在多语言模式下，译文会应用于所有选定的语言，因为在此模式下你可以同时处理多种语言。

### 高级筛选器

你可以通过点击搜索字段旁边的 **Filter strings** <Icon name="mdi:filter-variant" class="inline-icon" /> 图标并选择 **Advanced Filter** 来为字符串创建自定义筛选器。组合多个筛选参数并定义自定义排序顺序，以更快地定位特定字符串。

#### 过滤参数

筛选对话框将其参数分为以下部分，你可以组合其中任何部分的参数来缩小搜索范围：

##### 搜索

设置搜索的应用范围和搜索内容：

* **Search in**：选择搜索涵盖字符串的哪个部分。选项包括 *Everything*、*Strings*、*Context*、*All translations*、*Final translations* 或 *Identifier (Key)*。
* **Text**：按输入内容搜索文本。
* [**Verbal Expression**](#verbal-expressions)：搜索结构模式而非精确文本。 <Aside>**Text** 和 **Verbal Expression** 是互斥的，因此对话框一次只保留一个查询，并显示 **Filter** 将替换哪一个。</Aside>

##### 字符串

按源字符串的属性筛选：

* **Strings Added**：筛选在特定日期范围内导入到项目中的字符串。
* **Strings Updated**：筛选在特定日期范围内更新的源字符串。
* [**Labels: Include All / Labels: Include Any**](#filtering-by-labels)：包含具有全部或任一所选标签的字符串。
* [**Labels: Exclude All / Labels: Exclude Any**](#filtering-by-labels)：排除具有全部或任一所选标签的字符串。<Aside>这些选项仅在项目使用标签时出现。</Aside>
* **重复状态**：按字符串的重复状态进行筛选。选择一个或多个选项以显示与其中任意一项匹配的字符串：

  * *单次出现*：不是重复项且没有重复项的字符串。
  * *主字符串*：有重复项的字符串。仅选择此选项可列出有重复项的主字符串。
  * *重复项：使用主翻译*：没有自己翻译的重复项。它们显示主字符串的翻译，或者在主字符串未翻译时不显示翻译。
  * *重复项：覆盖主翻译*：拥有自己的翻译而不是主字符串翻译的重复项。

  <Aside>仅当[**重复字符串处理**](/project-settings/import/#duplicate-strings)配置为自动翻译重复项时，此选项才会出现。</Aside>
* **String Type**：按字符串格式筛选。选项包括*简单字符串*、*复数形式*或 *ICU*。
* **Translation Status**：按翻译状态筛选。选项包括 *Untranslated*、*Partially Translated (Plurals)* 和 *Translated*。
* **Approval Status**：按批准状态筛选字符串。选项包括 *Translated, Not Approved*、*Partially Approved (Plurals)* 和 *Approved*。
* **QA Issues**：根据品质保证问题筛选字符串。选项包括 *Without QA Checks*、*QA check in progress*、*All* 问题或特定检查（例如 *Tags mismatch*、*Spelling mistakes*、*Punctuation mismatch*）。<Aside>可用的检查取决于为项目启用的 QA 检查。</Aside>
* **Comments**：按评论或问题筛选字符串。选项包括*没有评论*、*有评论*、*未解决问题*、*一般性问题*、*当前译文有误问题*、*缺乏上下文信息问题*或*源字符串有错误问题*。
* **Screenshots**：筛选 *With Screenshots* 或 *Without Screenshots* 的字符串。
* **Visibility**：按译员是否可以看到字符串来筛选。选项为 *Visible* 或 *Hidden*。<Aside>此选项仅在您有权访问隐藏字符串时出现。</Aside>

##### 译文

按字符串已有的翻译筛选：

* **Scope**：定义筛选器是匹配字符串的任何翻译还是仅匹配最终翻译（显示在翻译列表顶部并用于下载的翻译）。选项为 *All translations* 和 *Final translations*。该范围适用于 **Engine**、**Translation Method**、**Votes**、**Translated By**、**Approved By**、**Translation Equals Source String** 和 **Source Changed After Translation**。设置其中一项后它就会变为可用。
* **Translations Updated**：筛选在特定日期范围内添加或更新了翻译（包括新建议、批准或投票）的字符串。
* **引擎**：筛选具有通过特定引擎自动翻译的译文的字符串。选项包括*机器翻译 (MT)*、*翻译记忆 (TM)*、*AI* 或*任意引擎*。
* **Translation Method**：根据是否应用了自动翻译来筛选字符串。选项包括*自动翻译*或*手动*。选择*手动*时，**引擎**将不可用。
* **Votes**：按净投票数筛选字符串。选项为*大于*或*小于*指定数字。
* **Translated By**：筛选由特定项目成员*翻译*或*未翻译*的字符串。
* **Approved By**：筛选由特定项目成员*批准*或*未批准*的字符串。
* **Conditions**：按条件筛选字符串，这些条件可以相互组合并与状态筛选器组合。选项包括 *Translation Equals Source String*、*Source Changed After Translation* 和 *Translation Added After Approval*。

#### 口头表达式

高级筛选还支持 Verbal Expressions，它按结构模式（例如变量的位置、格式或标点）匹配字符串，而非按精确文本。

在 **Search** 组中，选择 **Verbal Expression**，输入模式，并设置 **Search in** 以定义在哪里查找它。

当 Verbal Expression 处于活动状态时，编辑器工具栏中的搜索字段仍然有效，但在那里搜索会替换该表达式。

#### 按标签过滤

要按单个标签快速过滤，您可以点击字符串语境区域中显示的任何标签标记。将鼠标悬停在标签上会显示提示文本 `按标签过滤：{label-name}`。点击标签会立即应用**高级过滤器**，并选择该特定标签及**标签：包含任意**规则。所有其他过滤参数都将被清除。如果您随后点击另一个标签，它将替换过滤器中的前一个标签。

对于涉及多个标签的更复杂查询，您可以设置规则来包含或排除字符串：

* **Labels: Include All / Labels: Include Any**：选择包含标签的逻辑，然后在相应字段中添加标签。
  * **包含所有**：仅包含具有**所有**选定标签的字符串（AND 逻辑）。
  * **包含任意**：包含具有**至少一个**选定标签的字符串（OR 逻辑）。
* **Labels: Exclude All / Labels: Exclude Any**：选择排除标签的逻辑，然后在相应字段中添加标签。
  * **排除所有**：仅排除具有**所有**选定标签的字符串（AND 逻辑）。
  * **排除任意**：排除具有**至少一个**选定标签的字符串（OR 逻辑）。

组合这些规则以缩小或扩大筛选结果。

以下是一些关于此逻辑在实践中如何工作的示例：

* 包含示例 – 要查找同时标有 `ui` 和 `button` 的字符串，请选择**标签：包含所有**并添加这两个标签。
* 排除示例 – 要排除标有 `marketing` 或 `deprecated` 的所有字符串，请选择**标签：排除任意**并添加这两个标签。

#### 排序选项

设置筛选后字符串的顺序：

* **Sort By**：根据所选条件组织筛选后的字符串。可用选项为：
  * *原始排序顺序*
  * *字符串已添加*
  * *译文已更新*
  * *最后添加评论*
  * *字母顺序（源文本）*
  * *字母顺序（标识符）*
  * *长度*
  * *投票*
* 您还可以将排序顺序设置为**升序**或**降序**。

### AI/CroQL 过滤器

AI/CroQL 过滤器允许您以与高级过滤器类似的方式过滤字符串，但通过 Crowdin 查询语言 (CroQL) 提供更大的灵活性。

#### 使用 AI 生成 CroQL

在**使用 AI 生成 CroQL** 字段中，您可以用纯文本编写查询，然后使用 AI 将其转换为 CroQL 表达式。为了获得最佳结果，请确保您的查询结构清晰。例如，您可以输入：*返回用户 "username" 翻译成乌克兰语的字符串*。指定查询后，按 <KBD>Enter</KBD>，AI 将生成相应的 CroQL 表达式并填充到 **CroQL 表达式**字段中。或者，您可以直接在 **CroQL 表达式**字段中输入预先准备好的 CroQL 表达式。

点击**过滤**将指定的过滤器应用于编辑器中的字符串，或点击**重置过滤器**清除当前过滤器设置。

* 文件、任务和字符串导航选项：**Open File…**（在基于字符串的项目中为 **Open Branch…**）、**Open Task…** 和 **All Strings**
* 文件选项：**Source File Preview**、**Translated File Preview** 和 **Copy File Path**（在基于字符串的项目中为 **Copy Branch Path**）
* [任务状态](#changing-task-status)选项：**To Do**、**In Progress** 和 **Done**

* **Quit Editor**：关闭编辑器并转到项目的 **Tasks** 部分。

### 更改任务状态

要更改你正在处理的任务的状态，请打开 **Task** 菜单，并在 **Status** 下选择 **To Do**、**In Progress** 或 **Done**。相同的选项在[命令面板](#command-palette)中也可用，例如 **Set task status: Done**。

**Status** 选项适用于状态为 To Do、In Progress 或 Done 的 **Translate by own translators** 和 **Proofread by own proofreaders** 任务。它们对可以在项目 **Tasks** 部分更改任务状态的同一批成员可用。对于已关闭的任务，不显示 **Status** 选项。要更改已关闭任务的状态，请在 **Tasks** 部分[重新打开它](/tasks/#closing-task)。

### 在任务之间切换

要在同一项目中打开另一个任务，请在主菜单中选择 **Task > Open Task…**。当你不在处理任务时，此选项位于 **File** 菜单中（在基于字符串的项目中为 **Branch**）。或者，按 <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>Shift</KBD>+<KBD>O</KBD></span> 或 <span class="whitespace-nowrap"><KBD>Shift</KBD>+<KBD>⌘</KBD>+<KBD>O</KBD></span>，或在[命令面板](#command-palette)中选择 **Open task…**。

**Open Task** 对话框列出了你在当前项目中的活动任务（To Do 和 In Progress）。你可以按任务 ID、标题或描述搜索列表。选择一个任务以在编辑器中打开它。要转到项目的 **Tasks** 部分，请点击对话框底部的 **All Tasks**。它会在新选项卡中打开。
