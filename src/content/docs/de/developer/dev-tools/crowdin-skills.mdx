Crowdin Skills sind Anleitungspakete, die einem KI-Coding-Agenten beibringen, mit Crowdin zu arbeiten. Nach der Installation kennt der Agent die Crowdin-CLI-Befehle, das Format der Konfigurationsdatei, den API-Client und die Abfragesprachen. Dadurch kannst du eine Lokalisierungsaufgabe in natürlicher Sprache beschreiben, statt die Syntax selbst nachzuschlagen.

Skills verbinden den Agenten nicht mit deinem Crowdin-Konto. Sie arbeiten innerhalb deiner Entwicklungsumgebung neben deinem Quellcode, im Gegensatz zum [Crowdin MCP Server](/developer/crowdin-mcp-server/).

## Verfügbare Skills

**Den richtigen Ansatz finden**

* **`how-to-crowdin`** &ndash; Beantwortet „Wie mache ich X in Crowdin?“, indem ein Lokalisierungsproblem dem kostengünstigsten bereits vorhandenen Lösungsweg zugeordnet wird: einer integrierten Funktion, einigen Aktionen mit deinen Projektdaten, einer App aus dem [Crowdin Store](https://store.crowdin.com) oder einer benutzerdefinierten App. Die Details werden anschließend an den Skill weitergegeben, der diesen Weg abdeckt.

**Lokalisierung einrichten**

* **`i18n-setup`** &ndash; Überführt ein Projekt von fest im Code hinterlegten Zeichenfolgen zu kontinuierlicher Übersetzung oder verbindet ein bereits internationalisiertes Projekt.

**Inhalte synchronisieren**

* **`crowdin-cli`** &ndash; Synchronisiert Quelldateien und Übersetzungen zwischen deinem Projekt und Crowdin mit Crowdin CLI v5.
* **`github-action`** &ndash; Richtet den Schritt `crowdin/github-action` in einem GitHub-Workflow ein und unterstützt beim Debuggen.

**Inhalte für Übersetzer vorbereiten**

* **`context-extraction`** &ndash; Erstellt Kontext für die Quellzeichenfolgen, die ihn benötigen.
* **`crowdin-context-cli`** &ndash; Arbeitet mit den `crowdin context`-Befehlen und dem dafür verwendeten JSONL-Format.
* **`glossary-generation`** &ndash; Erstellt einen ersten Glossarentwurf aus deinen Quellzeichenfolgen und lädt ihn nach deiner Freigabe in das Projekt hoch.

**Mit Projektdaten arbeiten**

* **`crowdin-api-client`** &ndash; Verwendet den JavaScript- und TypeScript-API-Client einschließlich Paginierung, Uploads und Fehlerbehandlung.
* **`croql`** &ndash; Schreibt und optimiert CroQL-Ausdrücke für Zeichenfolgen, Übersetzungen, TM-Segmente und Glossarbegriffe.
* **`graphql`** &ndash; Schreibt und debuggt Crowdin-GraphQL-Abfragen anhand des tatsächlichen Schemas.

**Apps entwickeln**

* **`create-app`** &ndash; Erstellt das Grundgerüst, entwickelt und veröffentlicht eine Crowdin-App.

## Installation

Skills funktionieren mit Claude Code, Cursor, OpenAI Codex, Gemini CLI, GitHub Copilot, OpenCode, Cline, Windsurf und anderen KI-Coding-Agenten. Jeder Client bindet sie auf eigene Weise ein. Befolge daher die Installationsanweisungen im Repository.

<LinkButton href="https://github.com/crowdin/skills#installation" icon="external" target="_blank">Crowdin Skills installieren</LinkButton>

Nach der Installation stehen die Skills automatisch zur Verfügung, wenn du in einem Projekt arbeitest, das Crowdin verwendet, oder etwas erwähnst, das sie abdecken. Du kannst deinen Agenten auch direkt in einer Anfrage auf sie verweisen.

## Skills und der MCP Server

Skills und der Crowdin MCP Server unterstützen einen KI-Agenten dabei, mit Crowdin zu arbeiten – allerdings an unterschiedlichen Stellen.

* **Crowdin Skills** bringen dem Agenten bei, wie die Entwicklertools von Crowdin funktionieren. Der Agent wendet dieses Wissen in deinem Repository auf deinen Quellcode und deine `crowdin.yml` an.
* **Crowdin MCP Server** verbindet den Agenten mit deinem Crowdin-Konto, sodass er Projektdaten direkt lesen und ändern kann.

Du kannst beides verwenden: Skills, um den richtigen Befehl in deinem Repository auszuführen, und den MCP Server, um das Ergebnis in deinem Projekt zu prüfen. Der Skill `how-to-crowdin` basiert auf dieser Kombination &ndash; er beschreibt jeden Schritt als Aktion auf deinen Zeichenfolgen, Dateien oder Berichten, die der Agent anschließend über den MCP Server ausführen kann.
