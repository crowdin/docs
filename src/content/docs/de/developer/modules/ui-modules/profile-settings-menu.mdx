Das Modul ermöglicht die Erstellung eines neuen Abschnitts in den Profileinstellungen des Benutzers.

<Image src={profileSettings} alt="Profile-Einstellungsmenü-Modul" />

## Access

You can grant access to this module to one of the following user categories:

* Nur ich (d. h. der Profilinhaber)

## Structure

```json title="manifest.json"
{
  "modules": {
    "profile-settings-menu": [
      {
        "key": "your-settings-module-key",
        "name": "Name des Einstellungsmoduls",
        "url": "/profile-settings-page"
      }
    ]
  }
}
```
