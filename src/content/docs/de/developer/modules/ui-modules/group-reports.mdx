Das Modul fügt einen Bericht aus Ihrer App zu den **Berichten** einer Crowdin Enterprise-Organisation hinzu. Im [Modus „Berechtigungsgranularität“](/enterprise/permissions-granularity-mode/) wird der Bericht auch unter **Berichte** der jeweiligen Gruppe angezeigt.

Das Modul ist ausschließlich in Crowdin Enterprise verfügbar. Um einem Projekt einen Bericht hinzuzufügen, verwende das [Modul Berichte](/developer/crowdin-apps-module-project-reports/).

## Zugriff

Du kannst Zugriff auf dieses Modul für eine der folgenden Benutzerkategorien gewähren:

* Nur admins
* Admins, managers und Entwickler / translation Anfrageoders
* Individueller Zugriff

Innerhalb der ausgewählten Kategorie siehst du als Organisationsadministrator den Bericht in der Organisation und in jeder Gruppe. Als Gruppenmanager siehst du ihn in den Gruppen, die du verwaltest.

## Struktur

```json title="manifest.json"
{
  "modules": {
    "group-reports": [
      {
        "key": "your-module-key",
        "name": "Modulname",
        "description": "Modulbeschreibung",
        "logo": "/logo.png",
        "url": "/reports-page"
      }
    ]
  }
}
```

## Organisations- und Gruppenebenen

Crowdin Enterprise öffnet für die Organisation und deren Gruppen jeweils dasselbe Modul `url`. Wenn der Bericht in einer Gruppe geöffnet wird, enthält der Kontext sowohl in der [JWT-Token-Nutzlast](/developer/crowdin-apps-security/#token-payload) als auch in der Antwort von [AP.getContext()](/developer/crowdin-apps-js/#get-context) die `group_id` (die ID dieser Gruppe). Ohne `group_id` wird der Bericht in den **Berichten** der Organisation geöffnet.

Crowdin Enterprise fügt dem Token die `group_id` hinzu, nachdem es die Zugriffsrechte des Benutzers für diese Gruppe überprüft hat. Verwende daher den Wert des Tokens, um zu bestimmen, welche Daten im Bericht angezeigt werden sollen.
