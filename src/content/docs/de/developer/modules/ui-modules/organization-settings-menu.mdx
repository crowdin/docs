Mit dem Modul kann ein neuer Abschnitt auf der Seite „Organisationseinstellungen“ erstellt werden.

<Image src={orgSettingsMenu} alt="Modul für das Organisations-Einstellungsmenü" />

## Zugriff

Du kannst Zugriff auf dieses Modul für eine der folgenden Benutzerkategorien gewähren:

* Nur Organisationsadministratoren
* Ausgewählte Organisationsadministratoren

## Struktur

```json title="manifest.json"
{
  "modules": {
    "organization-settings-menu": [
      {
        "key": "your-settings-module-key",
        "name": "Settings Module name",
        "url": "/organization-settings-page",
        "icon": "/images/settings-icon.png"
      }
    ]
  }
}
```
