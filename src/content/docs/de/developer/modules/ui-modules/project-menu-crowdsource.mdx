Das Modul ermöglicht die Erstellung zusätzlicher Tabs auf der öffentlichen Crowdsourcing-Seite des Projekts in Crowdin Enterprise. Um damit zu arbeiten, stelle sicher, dass dein Projekt die folgenden Anforderungen erfüllt:

* Der Workflow des Projekts enthält den Schritt „Crowdsourcing“.
* Das Projekt ist auf der Seite mit den Crowdsourcing-Einstellungen veröffentlicht.

## Zugriff

Du kannst Zugriff auf dieses Modul für eine der folgenden Benutzerkategorien gewähren:

Für Crowdin:

* Nur ich (also der Projektinhaber)
* Alle Projektmitglieder
* Ausgewählte Benutzer
* Gäste (nicht authentifizierte Benutzer)

Für Crowdin Enterprise:

* Nur Organisationsadministratoren
* Alle Benutzer in den Projekten der Organisation
* Ausgewählte Benutzer
* Gäste (nicht authentifizierte Benutzer)

## Struktur

```json title="manifest.json"
{
  "modules": {
    "project-menu-crowdsource": [
      {
        "key": "your-module-key",
        "name": "Modulname",
        "url": "/crowdsource-page"
      }
    ]
  }
}
```
