Mit dem Modul zur Verarbeitung nach dem Import kannst du die aus deinen Dateien geparsten Strings nach dem Dateiimport ändern. Dieses Modul arbeitet sowohl mit den Source-Strings als auch mit den dazugehörigen Übersetzungen. Das Modul zur Verarbeitung vor dem Import ist besonders nützlich, wenn du die ursprüngliche Dateistruktur beibehalten und die Datei unverändert parsen möchtest, aber Änderungen an Source-Strings, Kontext, String-Übersetzungen oder z. B. Labels und maximalen Längen für Übersetzungen vornehmen möchtest.

Mit dem Modul zur Verarbeitung nach dem Import erhältst du einen Payload mit dem Dateiinhalt und den daraus geparsten Strings. Mit dem Modul zur Verarbeitung nach dem Import kannst du die geparsten Strings auf verschiedene Arten ändern (z. B. aufteilen, zusammenführen oder neue Strings hinzufügen) und die geänderten Strings zurückgeben. So kannst du die Strings anpassen, ohne den Dateiinhalt direkt zu verändern.

## Zugriff

Du kannst Zugriff auf dieses Modul für eine der folgenden Benutzerkategorien gewähren:

Für Crowdin:

* Nur ich (also der Projektinhaber)
* Alle Projektmitglieder
* Ausgewählte Benutzer

Für Crowdin Enterprise:

* Nur Organisationsadministratoren
* Alle Benutzer in den Projekten der Organisation
* Ausgewählte Benutzer

## Struktur

```json title="manifest.json"
{
  "modules": {
    "file-post-import": [
      {
        "key": "your-post-import-module-key",
        "url": "/import-strings",
        "signaturePatterns": {
          "fileName": "^.+\.xml$",
          "fileContent": "<properties>\s*<property\s+name=.*value=.*/>"
        }
      }
    ]
  }
}
```

## Kommunikation zwischen der File-Processing-App und Crowdin

Beim Import einer Datei erkennt das System anhand des Parameters `signaturePatterns` ein geeignetes Modul zur Verarbeitung nach dem Import und sendet zur weiteren Verarbeitung eine HTTP-Anfrage an die URL der App (`$baseUrl`. `$url`) mit den extrahierten Strings.

Die App zur Dateiverarbeitung ändert die empfangenen Strings entsprechend deinen Anforderungen. Mit dem Modul zur Verarbeitung nach dem Import kannst du neue Strings aufteilen, zusammenführen oder hinzufügen bzw. die Attribute vorhandener Strings bearbeiten. Nachdem die geänderten Strings vom Modul zur Verarbeitung nach dem Import zurückgegeben wurden, werden sie dem Crowdin-Projekt hinzugefügt und stehen zur Übersetzung zur Verfügung.

## HTML-Vorschau der Datei

Die HTML-Vorschau rendert im Editor eine [WYSIWYG-Ansicht der Datei](/online-editor/#wysiwyg-file-preview). Umschließe jeden übersetzbaren String mit einem Element, das beide folgenden Attribute enthält:

* `id="crowdin_phrase_index_{N}"`, wobei `{N}` die nullbasierte Position der Zeichenfolge in der Antwort der App angibt (in `data.strings` oder in der Datei unter `data.stringsUrl`). Verwende doppelte Anführungszeichen und stelle sicher, dass der Wert exakt übereinstimmt.
* `class="crowdin_phrase"`, damit du die Zeichenfolge in der Vorschau durch Anklicken auswählen und direkt bearbeiten kannst.

Zähle die Positionen in den Zeichenketten, die die App zurückgibt, nachdem sie Zeichenketten aufgeteilt, zusammengeführt oder hinzugefügt hat. Wenn die App die Anzahl oder Reihenfolge der Zeichenfolgen ändert, gib eine Vorschau zurück, die mit den zurückgegebenen Zeichenfolgen übereinstimmt.

Wenn die zurückgegebenen Zeichenfolgen `attributes.crowdinType` enthalten, gib die Vorschau in beiden Antworten zurück. Crowdin sendet erst dann eine zweite Anfrage, wenn die erste Antwort eine Vorschau enthält, und in dieser Anfrage sind die verschachtelten Inhalte bereits in separate Zeichenfolgen aufgeteilt. Crowdin verwendet ausschließlich die Vorschau aus der zweiten Antwort, und `{N}` zählt die Zeichenfolgen in dieser Antwort.

Crowdin verwendet die HTML-Vorschau nur, wenn du eine Quelldatei importierst oder aktualisierst, und ignoriert sie, wenn du Übersetzungen hochlädst.

Die Vorschau wird auch für Dateien angezeigt, die Pluralformen enthalten. Es wird dir jeweils eine Form jeder Pluralzeichenfolge angezeigt. Um ein anderes Formular anzuzeigen, wähle es im Übersetzungsfeld aus. Wir empfehlen dir, Pluralformen dort zu übersetzen und nicht direkt in der Vorschau.

Beispiel für die HTML-Vorschau der Datei:

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>HTML-Vorschau der Datei</h1>
    <p><span id="crowdin_phrase_index_0" class="crowdin_phrase">Quelltext 1</span></p> <!-- erste Zeichenfolge in „data.strings“ -->
    <p><span id="crowdin_phrase_index_1" class="crowdin_phrase">Quelltext 2</span></p> <!-- zweite Zeichenfolge in „data.strings“ -->
  </body>
</html>
```
