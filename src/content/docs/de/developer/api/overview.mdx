Die Crowdin-API ist eine umfassende RESTful-API, mit der du die Lokalisierung in deinen Entwicklungsprozess integrieren kannst. Mit den von uns verwendeten Endpunkten kannst du ganz einfach Anfragen senden, um Informationen abzurufen und erforderliche Aktionen auszuführen.

Der größte Teil der Crowdin-Funktionalität ist über die API verfügbar. Damit kannst du Projekte für Übersetzungen erstellen, Dateien hinzufügen und aktualisieren, Übersetzungen herunterladen und vieles mehr. So kannst du die komplexen Aktionen, die für deine Situation erforderlich sind, per Skript automatisieren.

## KI-Agenten und API

KI-Agenten können über die REST-API oder MCP (Model Context Protocol) mit Crowdin integriert werden. Zu den Integrationsmöglichkeiten für KI gehören KI-freundliche API-Spezifikationen (`llms.txt`) und der Zugriff auf MCP-Tools für Crowdin-Funktionen.
