Crowdin Query Language (CroQL) ist ein Tool für den Crowdin Editor, den Crowdin Enterprise Editor sowie die Crowdin- und Crowdin Enterprise-API, mit dem du anhand bestimmter Bedingungen benötigte Lokalisierungsressourcen abrufen kannst. Mit CroQL kannst du Quell-Strings und ihre Übersetzungen für eine bestimmte Zielsprache sowie TM-Segmente und Glossarbegriffe filtern.

Du kannst CroQL mit den folgenden API-Methoden verwenden:

## Operatoren

Die wichtigsten CroQL-Operatoren sind unten aufgeführt. Verwende und kombiniere sie, um bestimmte Bedingungen für das Abrufen der benötigten Inhalte aus Crowdin festzulegen. Um deine CroQL-Abfrage zu erstellen, kannst du die Elemente aus den folgenden Tabellen verwenden.

### Arithmetische Operatoren

Arithmetische Operatoren werden verwendet, um mathematische Operationen mit beliebigen numerischen Datentypen durchzuführen.

| Name           | Symbol | Beispiel |
| -------------- | ------ | -------- |
| Addition       | *      | 1 + 9    |
| Subtraktion    | -      | 11 - 1   |
| Division       | /      | 20 / 2   |
| Multiplikation | *      | 2 \* 5   |
| Negation       | -      | -10      |

### Vergleichsoperatoren

Vergleichsoperatoren werden verwendet, um Werte zu vergleichen und `true` oder `false` zurückzugeben.

| Name                | Symbol                                                     | Aliase | Beispiel                                                                                                                |
| ------------------- | ---------------------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------- |
| Zwischen            | `{{expression}} between {{expression}} and {{expression}}` |        | 5 between 1 and 10                                                                                                      |
| Gleich              | =                                                          |        | 10 = 10                                                                                                                 |
| Ungleich            | !=                                                         | ≠      | 1 != 10; 1 ≠ 10                                                                                                         |
| Größer              | &gt;                                                       |        | 10 &gt; 1                                                                                                               |
| Größer oder gleich  | &gt;=                                                      | ≥      | 10 &gt;= 1; 10 ≥ 1                                                                                                      |
| Kleiner             | &lt;                                                       |        | 1 &lt; 10                                                                                                               |
| Kleiner oder gleich | &lt;=                                                      | ≤      | 1 &lt;= 10; 1 ≤ 10                                                                                                      |
| Enthält             | `{{string}}` enthält `{{string}}`                          |        | `"Hello World" contains "Hello"`; `"Hello World" contains text`; `text contains "Hello World"`; `context contains text` |

### Logische Operatoren

Logische Operatoren werden verwendet, um mehrere boolesche Ausdrücke oder Werte zu kombinieren und ein einzelnes boolesches Ergebnis zurückzugeben.

| Name  | Symbol | Beispiel                            |
| ----- | ------ | ----------------------------------- |
| Und   | und    | 1 \< 10 and 10 > 1 |
| Oder  | oder   | 1 \< 10 or 10 > 1  |
| Xor   | xor    | 1 \< 10 xor 10 > 1 |
| Nicht | nicht  | nicht 1 \< 10      |

### Filteroperatoren

Filteroperatoren werden verwendet, um Objekte anhand der angegebenen Bedingung zu filtern.

| Name       | Symbol                               | Beispiel                                  |
| ---------- | ------------------------------------ | ----------------------------------------- |
| Filtern    | `{{collection}}` mit `{{predicate}}` | `translations where (count of votes > 0)` |
| Abgleichen | `{{object}} with {{predicate}}`      | `user with (login = "crowdin")`           |

### Bedingter Operator (ternär)

Der ternäre Operator wird verwendet, um eine im ersten Wert angegebene Bedingung zu prüfen. Ist sie `true`, wird der zweite Wert zurückgegeben; ist sie `false`, wird der dritte Wert zurückgegeben.

| Name   | Symbol                                                     | Beispiel                                                 |
| ------ | ---------------------------------------------------------- | -------------------------------------------------------- |
| Ternär | `If {{condition}} then {{expression}} else {{expression}}` | `If 1 \< 10 then "less" else "greater"` |

### Abrufoperatoren

Abrufoperatoren

| Name       | Symbol                                     | Beispiel                            |
| ---------- | ------------------------------------------ | ----------------------------------- |
| Erwähnung  | `@user:{{string}}`; `@language:{{string}}` | `@user:"crowdin"`; `@language:"en"` |
| Mitglied   | `{{member}} of {{object}}`                 | `count of translations`             |
| Bezeichner | `{{identifier}}`                           | `text`; `identifier`                |

### Skalaroperatoren

Skalaroperatoren werden verwendet, um Werte zur weiteren Verarbeitung zu deklarieren.

| Name           | Symbol         | Beispiel                       |
| -------------- | -------------- | ------------------------------ |
| Ganzzahl       | `{{integer}}`  | 10                             |
| Fließkommazahl | `{{float}}`    | 10.01                          |
| Zeichenkette   | `{{string}}`   | "crowdin"                      |
| Datum/Uhrzeit  | `{{datetime}}` | 'today'; '2021-03-16 00:00:00' |

### Gruppenoperator

Der Gruppenoperator wird verwendet, um die Ausführungsreihenfolge der Operatoren festzulegen.

| Name   | Symbol | Beispiel                                         |
| ------ | ------ | ------------------------------------------------ |
| Gruppe | ( )    | 1 \< 10 and (20 > 10 or 10 > 5) |

## CroQL-Abfragebeispiele

In diesem Abschnitt findest du praktische Beispiele für CroQL-Abfragen, die dir helfen, die Abfragefunktionen in Crowdin zu verstehen und zu verwenden. Diese Beispiele helfen dir dabei, eigene Abfragen zu erstellen, um bestimmte Datensätze anhand verschiedener Kriterien abzurufen, etwa Übersetzungsstatus, Benutzeraktivität und String-Eigenschaften.

<LinkCard title="CroQL Tester – Editor und Tester für CroQL-Ausdrücke" description="Teste deine CroQL-Abfragen im CroQL Tester." href="https://store.crowdin.com/croql-tester" target="_blank" />

### String-Abfragen

Diese Abfragen werden verwendet, um Informationen über Quell-Strings abzurufen.

* Strings, für die keine ukrainischen Übersetzungen mit Freigaben oder Stimmen vorhanden sind:
  ```graphql wrap
  count of translations where ( language = @language:"uk" and ( count of approvals > 0 or count of votes > 0 ) ) = 0
  ```

* Strings, die nur eine Übersetzung haben:
  ```graphql
  count of translations = 1
  ```

* Strings, die nur Übersetzungen von einem bestimmten Benutzer haben:
  ```graphql wrap
  count of translations > 0 and count of translations = count of translations where (user = @user:"crowdin")
  ```

* Strings, die mindestens eine Übersetzung von einem anderen als den angegebenen Benutzern haben:
  ```graphql
  count of translations where (user != @user:"crowdin") > 0
  ```

* Strings, deren Übersetzungen ausschließlich von anderen als den angegebenen Benutzern stammen:
  ```graphql wrap
  count of translations > 0 and count of translations = count of translations where (user != @user:"crowdin")
  ```

* Strings, gefiltert nach Bezeichner und numerischer ID einer Datei in deinem Crowdin-Projekt:
  ```graphql
  identifier = "key" and id of file = 777
  ```

* Strings mit nicht gelösten Problemen, gefiltert nach der numerischen ID einer Datei in deinem Crowdin-Projekt:
  ```graphql
  id of file = 777 and count of comments where (has unresolved issue) > 0
  ```

* Ausgeblendete Strings, die keine Duplikate sind und eine oder mehrere Übersetzungen haben:
  ```graphql
  is hidden and not is duplicate and count of translations > 0
  ```

* Strings mit einer oder mehreren Freigaben:
  ```graphql
  count of languages summary where (approvalsCount >= 1) > 0
  ```

* Strings mit Kommentaren des Benutzers mit dem Benutzernamen `crowdin`:
  ```graphql
  count of comments where (user = @user:"crowdin") > 0
  ```

* Strings, die im Quelltext „ABC“ enthalten, aber in ihren Übersetzungen nicht „ABC“ enthalten:
  ```graphql
  text contains "ABC" and (count of translations where (text contains "ABC") = 0)
  ```

#### Feldabfragen

Diese Abfragen werden verwendet, um Informationen über Quell-Strings anhand der ihnen zugewiesenen [Felder](/enterprise/fields/) abzurufen.

* Strings mit einem bestimmten Feldnamen und einem exakten Feldwert:

  *Anwendungsfall: Finde Strings, bei denen das Feld „Priority“ auf „High“ gesetzt ist.*

  ```graphql wrap
  count of fields where (name = "Priority" and value = "High") > 0
  ```

* Strings mit einem bestimmten Feld-Slug und einem Wert, der ein bestimmtes Wort enthält:

  *Anwendungsfall: Finde Strings, bei denen der Slug „category“ das Wort „mobile“ enthält.*

  ```graphql wrap
  count of fields where (slug = "field-category" and value contains "mobile") > 0
  ```

* Strings, denen anhand ihres Namens ein bestimmtes Feld zugewiesen wurde:

  *Anwendungsfall: Finde alle Strings, denen ein Feld „Department“ zugewiesen ist, unabhängig vom Wert.*

  ```graphql wrap
  count of fields where (name = "Department") > 0
  ```

* Strings, denen anhand ihres Slugs ein bestimmtes Feld zugewiesen wurde:

  *Anwendungsfall: Finde Strings, die einen bestimmten Systembezeichner für ein Feld „Owner“ verwenden.*

  ```graphql wrap
  count of fields where (slug = "field-internal-owner") > 0
  ```

* Strings mit einem Feld, dessen Name ein bestimmtes Wort enthält:

  *Anwendungsfall: Finde Strings mit beliebigen „Status“-bezogenen Feldern (z. B. Legal Status, Review Status).*

  ```graphql wrap
  count of fields where (name contains "Status") > 0
  ```

* Strings mit einem beliebigen Feld mit einem nicht leeren Wert:

  *Anwendungsfall: Finde Strings, bei denen Metadaten ausgefüllt sind.*

  ```graphql wrap
  count of fields where (value != "") > 0
  ```

* Strings mit einem Textfeld mit einem nicht leeren Wert:

  *Anwendungsfall: Nützlich, um sicherzustellen, dass Metadaten-Kommentare oder -Beschreibungen tatsächlich ausgefüllt sind.*

  ```graphql wrap
  count of fields where (type = "text" and value != "") > 0
  ```

* Strings, die mehreren bestimmten Feldnamen entsprechen, bei denen der Wert ein bestimmtes Wort enthält:

  *Anwendungsfall: Prüfe, ob das Feld „Platform“ oder „Environment“ das Wort „Production“ enthält.*

  ```graphql wrap
  count of fields where ((name = "Platform" or name = "Environment") and value contains "Production") > 0
  ```

### Abfragen für Translation-Memory-Segmente

Diese Abfragen werden verwendet, um Informationen über TM-Segmente abzurufen.

* Translation-Memory-Segmente, die mindestens einen Datensatz enthalten, der mindestens einmal verwendet wurde:
  ```graphql
  count of records where (usageCount > 0) > 0
  ```

* Translation-Memory-Segmente, die mindestens einen vom Benutzer mit dem Benutzernamen `crowdin` erstellten Datensatz enthalten:
  ```graphql
  count of records where (createdBy = @user:"crowdin") > 0
  ```

### Abfragen für Glossarbegriffe

Diese Abfragen werden verwendet, um Informationen über Glossarbegriffe abzurufen.

* Von einem Benutzer mit dem Benutzernamen `crowdin` für Ukrainisch erstellte Begriffe:
  ```graphql
  user = @user:"crowdin" and language = @language:"uk"
  ```

* Begriffe, die „ABC“ enthalten und als Wortart Substantiv haben:
  ```graphql
  text contains "ABC" and partOfSpeech = "noun"
  ```

* Begriffe, die als nicht empfohlen oder veraltet markiert sind:
  ```graphql
  status = "not_recommended" or status = "obsolete"
  ```

* Begriffe vom Typ Abkürzung, die eine Notiz enthalten:
  ```graphql
  type = "abbreviation" and note contains "tooltip"
  ```

* Nach einem bestimmten Datum hinzugefügte Begriffe:
  ```graphql
  createdAt > '2024-12-01 00:00:00'
  ```

* Begriffe mit dem Lemma „cancel“ und in Englisch:
  ```graphql
  lemma = "cancel" and language = @language:"en"
  ```

* Begriffe, die eine Referenz-URL enthalten:
  ```graphql
  url contains "https://"
  ```

### Beispiele auf Grundlage der erweiterten Filteroptionen des Editors

<Aside>
  Um die folgenden Abfragen in der Crowdin API zu verwenden, musst du die benötigte Zielsprache angeben (z. B. `count of languages summary where (language = @language:"uk" and is translated) > 0`) in deiner CroQL-Abfrage.
</Aside>

#### Zeichenketten

* Hinzugefügte Strings:
  ```graphql
  added between '2023-12-06 13:44:14' and '2023-12-07 13:44:14'
  ```
* Aktualisierte Strings:
  ```graphql
  updated between '2023-12-06 13:44:14' and '2023-12-07 13:44:14'
  ```
* String-Typ:
  ```graphql
  type is plain or type is icu
  ```
* Comments:
  ```graphql
  Kommentare:
  ```
* Screenshots:
  ```graphql
  count of screenshots > 0
  ```
* QA-Probleme:
  ```graphql
  count of languages summary where (has qa issues) > 0
  ```

#### Übersetzungen

* Nicht übersetzt:
  ```graphql
  count of languages summary = 0
  ```
* Teilweise übersetzt (Pluralformen):
  ```graphql
  count of languages summary where (is partially translated) > 0
  ```
* Übersetzt:
  ```graphql
  count of languages summary where (is translated) > 0
  ```
* Übersetzt von:
  ```graphql
  count of translations where (user = @user:"crowdin") > 0
  ```
* Nicht übersetzt von:
  ```graphql
  count of translations where (user != @user:"crowdin") > 0
  ```
* Identisch mit dem Quell-String:
  ```graphql
  count of languages summary where (has translation as source) > 0
  ```
* Geänderter Quell-String:
  ```graphql
  count of languages summary where (is source changed after translation) > 0
  ```
* Übersetzungen aktualisiert:
  ```graphql wrap
  count of languages summary where ( translation updated between '2023-12-06 13:44:14' and '2023-12-07 13:44:14') > 0
  ```
* Stimmen:
  ```graphql
  count of languages summary where (rating > 0) > 0
  ```

#### Dubletten

* Master-Strings:
  ```graphql
  not is duplicate
  ```
* Nur Duplikate:
  ```graphql
  is duplicate
  ```
* Duplikate mit gemeinsam genutzten Übersetzungen:
  ```graphql wrap
  is duplicate and count of languages summary where (has shared translation) > 0
  ```
* Duplikate mit eigenen Übersetzungen:
  ```graphql wrap
  is duplicate and count of languages summary where (not has shared translation and is translated) > 0
  ```

#### Freigaben

* Übersetzt, nicht freigegeben:
  ```graphql
  count of languages summary where (is translated and not is approved) > 0
  ```
* Teilweise freigegeben (Pluralformen):
  ```graphql
  count of languages summary where (is partially approved) > 0
  ```
* Freigegeben:
  ```graphql
  count of languages summary where (is approved) > 0
  ```
* Freigegeben von:
  ```graphql wrap
  count of translations where (count of approvals where (user = @user:"crowdin") > 0) > 0
  ```
* Nicht freigegeben von:
  ```graphql wrap
  count of translations where (count of approvals where (user != @user:"crowdin") > 0) > 0
  ```
* Hat Übersetzungen nach der Freigabe:
  ```graphql
  count of languages summary where (has translation after approval) > 0
  ```

#### KI, MT und TM

* Von KI übersetzt:
  ```graphql
  count of languages summary where (is translated by ai) > 0
  ```
* Von MT übersetzt:
  ```graphql
  count of languages summary where (is translated by mt) > 0
  ```
* Von TM übersetzt:
  ```graphql
  count of languages summary where (is translated by tm) > 0
  ```
* Von KI, MT oder TM übersetzt:
  ```graphql
  count of languages summary where (is auto translated) > 0
  ```

#### Sonstiges

* Vorübersetzung:
  * Verwendet: Nicht verfügbar
  * Nicht verwendet: Nicht verfügbar
* Sortieren nach: Nicht verfügbar
* Verbale Ausdrücke: Nicht verfügbar
* Geltungsbereich des verbalen Ausdrucks: Nicht verfügbar
