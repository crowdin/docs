Crowdin Query Language (CroQL) ist ein Tool für den Crowdin Editor, den Crowdin Enterprise Editor sowie die Crowdin- und Crowdin-Enterprise-APIs. Damit kannst du benötigte Lokalisierungsressourcen anhand bestimmter Bedingungen abrufen. Mit CroQL kannst du Quellzeichenfolgen und ihre Übersetzungen für eine bestimmte Zielsprache sowie Translation-Memory-Segmente (TM-Segmente) und Glossarbegriffe filtern.

Du kannst CroQL mit den folgenden API-Methoden verwenden:

## Operatoren

Die wichtigsten CroQL-Operatoren sind unten aufgeführt. Verwende und kombiniere sie, um bestimmte Bedingungen festzulegen, nach denen Crowdin die benötigten Inhalte abruft. Zum Erstellen deiner CroQL-Abfrage kannst du die Elemente aus den folgenden Tabellen verwenden.

### Arithmetische Operatoren

Mit arithmetischen Operatoren kannst du mathematische Operationen mit numerischen Datentypen ausführen.

| Name           | Symbol | Beispiel |
| -------------- | ------ | -------- |
| Addition       | *      | 1 + 9    |
| Subtraktion    | -      | 11 - 1   |
| Division       | /      | 20 / 2   |
| Multiplikation | *      | 2 \* 5   |
| Verneinung     | -      | -10      |

### Vergleichsoperatoren

Mit Vergleichsoperatoren kannst du Werte vergleichen. Das Ergebnis ist jeweils `true` oder `false`.

| Name                | Symbol                                                     | Aliase | Beispiel                                                                                                                |
| ------------------- | ---------------------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------- |
| Zwischen            | `{{expression}} between {{expression}} and {{expression}}` |        | 5 between 1 and 10                                                                                                      |
| Gleich              | =                                                          |        | 10 = 10                                                                                                                 |
| Ungleich            | !=                                                         | ≠      | 1 != 10; 1 ≠ 10                                                                                                         |
| Größer              | &gt;                                                       |        | 10 &gt; 1                                                                                                               |
| Größer oder gleich  | &gt;=                                                      | ≥      | 10 &gt;= 1; 10 ≥ 1                                                                                                      |
| Kleiner             | &lt;                                                       |        | 1 &lt; 10                                                                                                               |
| Kleiner oder gleich | &lt;=                                                      | ≤      | 1 &lt;= 10; 1 ≤ 10                                                                                                      |
| Enthält             | `{{string}}` enthält `{{string}}`                          |        | `"Hello World" contains "Hello"`; `"Hello World" contains text`; `text contains "Hello World"`; `context contains text` |

### Logische Operatoren

Mit logischen Operatoren kannst du mehrere boolesche Ausdrücke oder Werte kombinieren und ein einzelnes boolesches Ergebnis erhalten.

| Name                  | Symbol | Beispiel                            |
| --------------------- | ------ | ----------------------------------- |
| Und                   | und    | 1 \< 10 and 10 > 1 |
| Oder                  | oder   | 1 \< 10 or 10 > 1  |
| Exklusives Oder (XOR) | xor    | 1 \< 10 xor 10 > 1 |
| Nicht                 | nicht  | not 1 \< 10        |

### Filteroperatoren

Filteroperatoren werden verwendet, um Objekte anhand der angegebenen Bedingung zu filtern.

| Name       | Symbol                               | Beispiel                                  |
| ---------- | ------------------------------------ | ----------------------------------------- |
| Filter     | `{{collection}}` mit `{{predicate}}` | `translations where (count of votes > 0)` |
| Abgleichen | `{{object}} with {{predicate}}`      | `user with (login = "crowdin")`           |

### Bedingter Operator (ternär)

Mit dem ternären Operator prüfst du eine Bedingung im ersten Wert. Ist sie `true`, gibt der Operator den zweiten Wert zurück; ist sie `false`, den dritten.

| Name   | Symbol                                                     | Beispiel                                                 |
| ------ | ---------------------------------------------------------- | -------------------------------------------------------- |
| Ternär | `If {{condition}} then {{expression}} else {{expression}}` | `If 1 \< 10 then "less" else "greater"` |

### Abrufoperatoren

Mit Abrufoperatoren kannst du Daten aus Objekten abrufen.

| Name                     | Symbol                                     | Beispiel                            |
| ------------------------ | ------------------------------------------ | ----------------------------------- |
| Erwähnung                | `@user:{{string}}`; `@language:{{string}}` | `@user:"crowdin"`; `@language:"en"` |
| Mitglied                 | `{{member}} of {{object}}`                 | `count of translations`             |
| Anzahl der Übersetzungen | `{{identifier}}`                           | `text`; `identifier`                |

### Skalaroperatoren

Mit Skalaroperatoren kannst du Werte für die weitere Verarbeitung festlegen.

| Name           | Symbol         | Beispiel                       |
| -------------- | -------------- | ------------------------------ |
| Ganzzahl       | `{{integer}}`  | 10                             |
| Fließkommazahl | `{{float}}`    | 10.01                          |
| Zeichenfolge   | `{{string}}`   | "crowdin"                      |
| Zeichenfolge   | `{{datetime}}` | 'today'; '2021-03-16 00:00:00' |

### Gruppenoperator

Der Gruppenoperator wird verwendet, um die Ausführungsreihenfolge der Operatoren festzulegen.

| Name   | Symbol | Beispiel                                         |
| ------ | ------ | ------------------------------------------------ |
| Gruppe | ( )    | 1 \< 10 and (20 > 10 or 10 > 5) |

## CroQL-Abfragebeispiele

In diesem Abschnitt findest du praktische Beispiele für CroQL-Abfragen. Sie zeigen dir, wie du die Abfragefunktionen in Crowdin nutzen kannst. Mit diesen Beispielen lernst du, eigene Abfragen zu erstellen, um anhand verschiedener Kriterien wie Übersetzungsstatus, Benutzeraktivität und Eigenschaften von Zeichenfolgen bestimmte Datensätze abzurufen.

<LinkCard title="CroQL-Tester – Editor und Testwerkzeug für CroQL-Ausdrücke" description="Probiere deine CroQL-Abfragen im CroQL-Tester aus." href="https://store.crowdin.com/croql-tester" target="_blank" />

### Abfragen zu Zeichenfolgen

Mit diesen Abfragen kannst du Informationen zu Quellzeichenfolgen abrufen.

* Zeichenfolgen, für die keine ukrainischen Übersetzungen mit Freigaben oder Stimmen vorliegen:
  ```graphql wrap
  count of translations where ( language = @language:"uk" and ( count of approvals > 0 or count of votes > 0 ) ) = 0
  ```

* Zeichenfolgen, für die nur eine Übersetzung vorliegt:
  ```graphql
  count of translations = 1
  ```

* Zeichenfolgen, deren Übersetzungen ausschließlich von einem bestimmten Benutzer stammen:
  ```graphql wrap
  count of translations > 0 and count of translations = count of translations where (user = @user:"crowdin")
  ```

* Zeichenfolgen, für die mindestens eine Übersetzung nicht von den angegebenen Benutzern stammt:
  ```graphql
  count of translations where (user != @user:"crowdin") > 0
  ```

* Zeichenfolgen, deren Übersetzungen alle von anderen Benutzern als den angegebenen stammen:
  ```graphql wrap
  count of translations > 0 and count of translations = count of translations where (user != @user:"crowdin")
  ```

* Zeichenfolgen, gefiltert nach Bezeichner und numerischer ID einer Datei in deinem Crowdin-Projekt:
  ```graphql
  identifier = "key" and id of file = 777
  ```

* Zeichenfolgen mit ungelösten Problemen, gefiltert nach der numerischen ID einer Datei in deinem Crowdin-Projekt:
  ```graphql
  id of file = 777 and count of comments where (has unresolved issue) > 0
  ```

* Ausgeblendete Zeichenfolgen, die keine Duplikate sind und mindestens eine Übersetzung haben:
  ```graphql
  is hidden and not is duplicate and count of translations > 0
  ```

* Zeichenfolgen mit mindestens einer Freigabe:
  ```graphql
  count of languages summary where (approvalsCount >= 1) > 0
  ```

* Zeichenfolgen mit Kommentaren des Benutzers mit dem Benutzernamen `crowdin`:
  ```graphql
  count of comments where (user = @user:"crowdin") > 0
  ```

* Zeichenfolgen, deren Quelltext „ABC“ enthält, deren Übersetzungen „ABC“ jedoch nicht enthalten:
  ```graphql
  text contains "ABC" and (count of translations where (text contains "ABC") = 0)
  ```

#### Feldabfragen

Mit diesen Abfragen kannst du Informationen zu Quellzeichenfolgen anhand der ihnen zugewiesenen [Felder](/enterprise/fields/) abrufen.

* Zeichenfolgen mit einem bestimmten Feldnamen und einem exakten Feldwert:

  *Anwendungsfall: Finde Zeichenfolgen, bei denen das Feld „Priority“ auf „High“ gesetzt ist.*

  ```graphql wrap
  count of fields where (name = "Priority" and value = "High") > 0
  ```

* Zeichenfolgen mit einem bestimmten Feld-Slug und einem Wert, der ein bestimmtes Wort enthält:

  *Anwendungsfall: Finde Zeichenfolgen, bei denen der Slug „category“ das Wort „mobile“ enthält.*

  ```graphql wrap
  count of fields where (slug = "field-category" and value contains "mobile") > 0
  ```

* Zeichenfolgen, denen ein bestimmtes Feld anhand seines Namens zugewiesen wurde:

  *Anwendungsfall: Finde alle Zeichenfolgen, denen das Feld „Department“ zugewiesen ist – unabhängig vom Feldwert.*

  ```graphql wrap
  count of fields where (name = "Department") > 0
  ```

* Zeichenfolgen, denen ein bestimmtes Feld anhand seines Slugs zugewiesen wurde:

  *Anwendungsfall: Finde Zeichenfolgen, die einen bestimmten Systembezeichner für das Feld „Owner“ verwenden.*

  ```graphql wrap
  count of fields where (slug = "field-internal-owner") > 0
  ```

* Zeichenfolgen mit einem Feld, dessen Name ein bestimmtes Wort enthält:

  *Anwendungsfall: Finde Zeichenfolgen mit beliebigen Feldern, deren Name „Status“ enthält (z. B. „Legal Status“ oder „Review Status“).*

  ```graphql wrap
  count of fields where (name contains "Status") > 0
  ```

* Zeichenfolgen mit einem beliebigen Feld, dessen Wert nicht leer ist:

  *Anwendungsfall: Finde Zeichenfolgen, für die Metadaten hinterlegt sind.*

  ```graphql wrap
  count of fields where (value != "") > 0
  ```

* Zeichenfolgen mit einem Textfeld, dessen Wert nicht leer ist:

  *Anwendungsfall: Damit kannst du sicherstellen, dass Kommentare oder Beschreibungen in den Metadaten tatsächlich ausgefüllt sind.*

  ```graphql wrap
  count of fields where (type = "text" and value != "") > 0
  ```

* Zeichenfolgen, bei denen der Wert eines von mehreren bestimmten Feldern ein bestimmtes Wort enthält:

  *Anwendungsfall: Prüfe, ob das Feld „Platform“ oder „Environment“ das Wort „Production“ enthält.*

  ```graphql wrap
  count of fields where ((name = "Platform" or name = "Environment") and value contains "Production") > 0
  ```

### Abfragen für Glossarbegriffe

Mit diesen Abfragen kannst du Informationen zu Glossarbegriffen abrufen.

* Begriffe für Ukrainisch, die von einem Benutzer mit dem Benutzernamen `crowdin` erstellt wurden:
  ```graphql
  user = @user:"crowdin" and language = @language:"uk"
  ```

* Begriffe, die „ABC“ enthalten und deren Wortart auf Substantiv gesetzt ist:
  ```graphql
  text contains "ABC" and partOfSpeech = "noun"
  ```

* Begriffe, die als nicht empfohlen oder veraltet gekennzeichnet sind:
  ```graphql
  status = "not_recommended" or status = "obsolete"
  ```

* Begriffe vom Typ „Abkürzung“, zu denen eine Notiz hinterlegt ist:
  ```graphql
  type = "abbreviation" and note contains "tooltip"
  ```

* Begriffe, die nach einem bestimmten Datum hinzugefügt wurden:
  ```graphql
  createdAt > '2024-12-01 00:00:00'
  ```

* Begriffe mit dem Lemma „cancel“, deren Sprache Englisch ist:
  ```graphql
  lemma = "cancel" and language = @language:"en"
  ```

* Begriffe, die eine Referenz-URL enthalten:
  ```graphql
  url contains "https://"
  ```

* Begriffe, deren Wert im Feld `review-priority` [Feld](/enterprise/fields/) den Text „Urgent“ enthält (nur Crowdin Enterprise):
  ```graphql
  count of fields where (slug = "review-priority" and value contains "Urgent") > 0
  ```

### Beispiele auf Grundlage der erweiterten Filteroptionen des Editors

<Aside>
  Um die folgenden Abfragen in der Crowdin-API zu verwenden, musst du in deiner CroQL-Abfrage die gewünschte Zielsprache angeben (z. B. `count of languages summary where (language = @language:"uk" and is translated) > 0`).
</Aside>

#### Strings

* Hinzugefügte Zeichenfolgen:
  ```graphql
  added between '2023-12-06 13:44:14' and '2023-12-07 13:44:14'
  ```
* Aktualisierte Zeichenfolgen:
  ```graphql
  updated between '2023-12-06 13:44:14' and '2023-12-07 13:44:14'
  ```
* Typ der Zeichenfolge:
  ```graphql
  type is plain or type is icu
  ```
* Kommentare:
  ```graphql
  count of comments > 0
  ```
* Screenshots:
  ```graphql
  count of screenshots > 0
  ```
* QA-Probleme:
  ```graphql
  count of languages summary where (has qa issues) > 0
  ```

#### Übersetzungen

* Nicht übersetzt:
  ```graphql
  count of languages summary = 0
  ```
* Teilweise übersetzt (Pluralformen):
  ```graphql
  count of languages summary where (is partially translated) > 0
  ```
* Übersetzt:
  ```graphql
  count of languages summary where (is translated) > 0
  ```
* Übersetzt von:
  ```graphql
  count of translations where (user = @user:"crowdin") > 0
  ```
* Nicht übersetzt von:
  ```graphql
  count of translations where (user != @user:"crowdin") > 0
  ```
* Übersetzung entspricht der Quellzeichenfolge:
  ```graphql
  count of languages summary where (has translation as source) > 0
  ```
* Quelltext nach der Übersetzung geändert:
  ```graphql
  count of languages summary where (is source changed after translation) > 0
  ```
* Aktualisierte Übersetzungen:
  ```graphql wrap
  count of languages summary where ( translation updated between '2023-12-06 13:44:14' and '2023-12-07 13:44:14') > 0
  ```
* Stimmen:
  ```graphql
  count of languages summary where (rating > 0) > 0
  ```

#### Duplikate

* Keine Duplikate:
  ```graphql
  not is duplicate
  ```
* Duplikate:
  ```graphql
  is duplicate
  ```
* Duplikate mit Übersetzung aus der Master-Zeichenkette:
  ```graphql wrap
  is duplicate and count of languages summary where (has shared translation) > 0
  ```
* Duplikate mit eigener Übersetzung:
  ```graphql wrap
  is duplicate and count of languages summary where (not has shared translation and is translated) > 0
  ```

#### Freigaben

* Übersetzt, aber nicht freigegeben:
  ```graphql
  count of languages summary where (is translated and not is approved) > 0
  ```
* Teilweise freigegeben (Pluralformen):
  ```graphql
  count of languages summary where (is partially approved) > 0
  ```
* Freigegeben:
  ```graphql
  count of languages summary where (is approved) > 0
  ```
* Freigegeben von:
  ```graphql wrap
  count of translations where (count of approvals where (user = @user:"crowdin") > 0) > 0
  ```
* Nicht freigegeben von:
  ```graphql wrap
  count of translations where (count of approvals where (user != @user:"crowdin") > 0) > 0
  ```
* Übersetzung nach der Freigabe hinzugefügt:
  ```graphql
  count of languages summary where (has translation after approval) > 0
  ```

#### KI, maschinelle Übersetzung (MT) und Translation Memory (TM)

* Mit KI übersetzt:
  ```graphql
  count of languages summary where (is translated by ai) > 0
  ```
* Mit maschineller Übersetzung (MT) übersetzt:
  ```graphql
  count of languages summary where (is translated by mt) > 0
  ```
* Mit Translation Memory (TM) übersetzt:
  ```graphql
  count of languages summary where (is translated by tm) > 0
  ```
* Mit KI, maschineller Übersetzung (MT) oder Translation Memory (TM) übersetzt:
  ```graphql
  count of languages summary where (is auto translated) > 0
  ```

#### Sonstiges

* Vorübersetzung:
  * Verwendet: Nicht verfügbar
  * Nicht verwendet: Nicht verfügbar
* Sortieren nach: Nicht verfügbar
* Verbale Ausdrücke: Nicht verfügbar
* Suche in: Nicht verfügbar

## Kontext

CroQL kann in folgenden Kontexten verwendet werden: Kontext der Quellzeichenfolge, Übersetzungskontext und Kontext eines Translation-Memory-(TM-)Segments. Verwende die folgenden Beispiele als Grundlage für deine CroQL-Abfragen.

### Kontext der Quellzeichenfolge

```json collapse={37-56,62-92}
{
  "type is plain": true,
  "type is plural": false,
  "type is icu": false,
  "type is asset": false,
  "text": "Quick Start",
  "identifier": "quick_start",
  "context": "quick_start",
  "max length": 0,
  "is visible": true,
  "is hidden": false,
  "is duplicate": false,
  "isPassedWorkflow": true,
  "fields": {
    "priority": "High",
    "legal-status": "approved"
  },
  "file": {
    "id": 32,
    "name": "sample.csv",
    "title": "Sample",
    "type": "csv",
    "context": "Some useful context information"
  },
  "branch": {
    "id": 7,
    "name": "main",
    "title": "Main"
  },
  "comments": [
    {
      "has issue": false,
      "has unresolved issue": false,
      "user": 1
    }
  ],
  "screenshots": [],
  "translations": [
```
