Das Crowdin Apps SDK ist ein Node.js-Framework zum Erstellen von Self-Hosted-Apps. Du beschreibst die App in einem Konfigurationsobjekt, und das SDK erstellt darauf basierend die Express-Anwendung mit den bereits eingerichteten Endpunkten, die Crowdin aufruft. Es meldet die App außerdem bei Crowdin an und überprüft die von Crowdin gesendeten Anfragen, sodass du dich auf die Funktionen der App konzentrieren kannst, anstatt die notwendige Infrastruktur dafür zu implementieren.

## Was du erstellen kannst

Mit dem Crowdin Apps SDK kannst du eine App rund um jeden von Crowdin unterstützten Modultyp erstellen:

* **UI-Module**: Panels, Dashboards, Menüs und Dialoge innerhalb von Crowdin.
* **KI-Module**: Benutzerdefinierte KI-Anbieter und Prompt-Anbieter.
* **Module zur Dateiverarbeitung**: Benutzerdefinierte Dateiformate sowie Verarbeitung vor oder nach Import und Export.
* **Andere Module**: Benutzerdefinierte maschinelle Übersetzungs-Engines, Webhooks, Workflow-Schritte und QA-Prüfungen.

## Eine Self-Hosted-App erstellen

Installiere das Paket:

```bash
npm install @crowdin/app-project-module
```

Für die Benutzeroberfläche der App erstellst du sie anhand der [Crowdin UI Registry](https://github.com/crowdin/ui-registry), einer shadcn-Registry, die die Design-Tokens und Komponenten von Crowdin bereitstellt.

Mit dem Crowdin Apps SDK erstellte Apps können überall gehostet werden, wo Node.js ausgeführt werden kann (z. B. Vercel, AWS Lambda oder Cloudflare Workers).

## Wann du stattdessen eine Serverless-App erstellen solltest

Wenn deine App ausschließlich aus einer Benutzeroberfläche besteht (z. B. ein Dashboard, ein Editor-Panel oder eine Menüerweiterung), kannst du sie als Serverless-App erstellen: Crowdin hostet und betreibt sie, und du musst keinen Server bereitstellen oder warten.
