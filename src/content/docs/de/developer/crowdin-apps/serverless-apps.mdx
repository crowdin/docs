Das Crowdin Serverless Apps SDK ist ein TypeScript-Toolkit zum Erstellen von Apps, die auf der Crowdin-Infrastruktur laufen. Du erstellst die Benutzeroberfläche und registrierst die Module, in denen die App erscheint. Die CLI erstellt, zeigt eine Vorschau an und veröffentlicht das Bundle. Es enthält ein UI-Kit, das auf der [Crowdin UI Registry](https://github.com/crowdin/ui-registry) basiert und aus Crowdin-Komponenten im shadcn-Stil besteht, eine i18n-Laufzeitumgebung für die eigenen Übersetzungen der App sowie einen API-Client, der Crowdin im Namen der Person aufruft, die die App verwendet – ohne dass Tokens verwaltet werden müssen.

## Was du erstellen kannst

Mit dem Crowdin Serverless Apps SDK kannst du eine App rund um die UI-Module von Crowdin erstellen:

* **Projektmodule**: Dashboards, Tools, Berichte und Menüelemente innerhalb eines Projekts.
* **Editormodule**: Panels neben dem Übersetzungseditor.
* **Organisations- und Profilmodule**: Seiten in den Organisations- und Profilmenüs.
* **Dialoge**: Modale Fenster, Kontextmenüs und Chat-Panels.

## Eine Serverless-App erstellen

Ein KI-Coding-Agent kann [die App für dich erstellen](/developer/crowdin-apps-about/), oder du kannst die CLI selbst ausführen. Die CLI erstellt das Grundgerüst der App, führt sie lokal aus und veröffentlicht sie.

```bash
npm install --global @crowdin/serverless-apps-cli
crowdin-serverless-apps login
crowdin-serverless-apps create my-app
crowdin-serverless-apps dev
crowdin-serverless-apps preview
crowdin-serverless-apps publish
```

Crowdin hostet und betreibt die veröffentlichte App, sodass du keinen eigenen Server bereitstellen oder warten musst.

## Wann du stattdessen eine Self-Hosted-App erstellen solltest

Serverless-Apps decken die UI-Seite von Crowdin ab. Wenn deine App serverseitige Logik benötigt (z. B. Dateiverarbeitung, KI-Anbieter, benutzerdefinierte MT-Engines oder Webhook-Verarbeitung), erstelle sie als Self-Hosted-App. Dasselbe gilt, wenn deine App eine Benutzeroberfläche mit serverseitiger Logik kombiniert: Self-Hosted-Apps können ebenfalls UI-Module enthalten.

Eine Self-Hosted-App arbeitet außerdem anders mit der Crowdin-API: Sie führt Aufrufe im Namen des Kontos aus, das sie installiert hat, und nicht im Namen der Person, die sie verwendet.
