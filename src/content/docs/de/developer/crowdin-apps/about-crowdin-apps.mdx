Erstelle eine Crowdin-App mit deinem KI-Coding-Agenten:

```text wrap
Hilf mir beim Erstellen einer Crowdin-App. Führe Folgendes aus:
1. Installiere das Crowdin-Plugin mit npx plugins add crowdin/skills.
2. Frage mich, was die App tun soll, und verwende anschließend den create-app-Skill, um sie zu erstellen, zu entwickeln und zu veröffentlichen.
3. Öffne nach der Veröffentlichung eine Vorschau, damit ich die App in Crowdin sehen kann.
```

Der Agent meldet dich in deinem Browser bei Crowdin an und bittet dich um Bestätigung, bevor er die App in deiner Organisation registriert. Die veröffentlichte App wird in deinem Konto installiert, und das Manifest legt fest, wer sie sonst noch verwenden kann. Das kannst du später unter [Crowdin Apps – Berechtigungskonfiguration](/developer/crowdin-apps-installation/#crowdin-apps-permission-configuration) ändern.

Für Endbenutzer erscheint eine installierte App als vollständig integrierter Bestandteil von Crowdin, dessen Funktionen direkt in der Benutzeroberfläche bereitgestellt werden.

## Wähle aus, wie du die App erstellen möchtest

Es gibt zwei Möglichkeiten, eine Crowdin-App zu erstellen. Serverless-Apps laufen auf der Crowdin-Infrastruktur: Du erstellst die Benutzeroberfläche und Crowdin hostet und betreibt die App. Self-Hosted-Apps laufen auf einem von dir betriebenen Server. Dadurch können sie jeden Modultyp verwenden, einschließlich solcher mit serverseitiger Logik. Keine der beiden Möglichkeiten ersetzt die andere. Wähle die Variante, die zu den Anforderungen deiner App passt.

<CardGrid>
  <Card title="Serverless-Apps" icon="rocket">
    Erstelle Dashboards, Panels und andere UI-Module, die auf der Crowdin-Infrastruktur ausgeführt werden. Du erstellst das Grundgerüst, die Vorschau und die Veröffentlichung der App über die CLI – ohne Server, den du bereitstellen oder warten musst.

    Wähle diesen Weg, wenn deine App ausschließlich aus einer Benutzeroberfläche besteht: Sie zeigt Daten an, erweitert die Crowdin-Benutzeroberfläche und ruft die Crowdin-API im Namen der Person auf, die sie verwendet.

    [Mit dem Serverless Apps SDK starten](/developer/crowdin-apps-serverless/)
  </Card>
  <Card title="Self-Hosted-Apps" icon="setting">
    Erstelle eine App, die von deinem eigenen Server unterstützt wird, und verwende dafür eine beliebige Sprache und ein beliebiges Framework. Dieser Weg unterstützt jeden Modultyp, einschließlich Dateiverarbeitung, KI-Anbieter und benutzerdefinierter MT-Engines.

    Wähle diesen Weg, wenn deine App serverseitige Logik benötigt: Sie verarbeitet Dateien, reagiert auf Webhooks, verbindet externe Dienste oder arbeitet mit den Berechtigungen des Kontos, das die App installiert hat.

    [Mit dem Crowdin Apps SDK starten](/developer/crowdin-apps-sdk/)
  </Card>
</CardGrid>

|                   | Serverless-Apps                                              | Self-Hosted-Apps                                 |
| ----------------- | ------------------------------------------------------------ | ------------------------------------------------ |
| Hosting           | Crowdin führt deine App aus                                  | Du stellst deine App bereit und führst sie aus   |
| Modul             | UI-Module                                                    | Alle Modultypen                                  |
| API-Aufrufe       | Im Namen des Benutzers, der in der App arbeitet              | Im Namen des Kontos, das die App installiert hat |
| Technologie-Stack | TypeScript mit vorab konfiguriertem React und Crowdin UI Kit | Beliebige Sprache und beliebiges Framework       |

Wenn deine App eine Benutzeroberfläche mit serverseitiger Logik kombiniert, erstelle sie als Self-Hosted-App. Self-Hosted-Apps können ebenfalls UI-Module enthalten.

Um eine Self-Hosted-App in einer anderen Sprache als JavaScript oder TypeScript zu erstellen, folge den Referenzen [App Descriptor](/developer/crowdin-apps-app-descriptor/) und [Security for Crowdin Apps](/developer/crowdin-apps-security/).

## Beispiele für Crowdin Apps

Starte mit einer Vorlage statt mit einem leeren Projekt:

* [Serverless Apps Starter Kit](https://github.com/crowdin-community/serverless-apps-starter-kit): Die Vorlagen, die die Serverless-CLI als Grundgerüst erstellt, sowie eine vollständige Serverless-App zum Durchlesen von Anfang bis Ende.
* [Crowdin AI Provider Template](https://github.com/crowdin-community/crowdin-ai-provider-template): Eine Self-Hosted-App, die einen benutzerdefinierten KI-Anbieter hinzufügt und mit dem Crowdin Apps SDK erstellt wurde.
* [Crowdin Custom MT Template](https://github.com/crowdin-community/crowdin-custom-mt-template): Eine Self-Hosted-App, die eine benutzerdefinierte maschinelle Übersetzungs-Engine hinzufügt.
* [Crowdin Custom File Format Boilerplate](https://github.com/crowdin-community/crowdin-file-format-template): Eine App zur Dateiverarbeitung, die Unterstützung für INI, CONF und CFG hinzufügt, mit einer Vorschau für Übersetzer.

## Veröffentlichen im Crowdin Store
