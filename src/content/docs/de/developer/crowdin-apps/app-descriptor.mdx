Der App-Deskriptor ist eine JSON-Datei, normalerweise `manifest.json`, die Crowdin mitteilt, was die App ist und welche Module sie hinzufügt.

<Image src={integratingCrowdinApps} alt="Crowdin App integration" class="no-shadow" />

<Aside type="tip" title="Du möchtest Crowdin-Apps entwickeln?">
  Beginne mit einem der SDKs: dem [Serverless Apps SDK](/developer/crowdin-apps-serverless/) oder dem [Crowdin Apps SDK](/developer/crowdin-apps-sdk/).
</Aside>

## Struktur des App-Deskriptors

Der App-Deskriptor ist ein JSON-Objekt. Eine selbst gehostete App stellt sie über ihren eigenen Server bereit, während eine serverlose App sie im Projekt speichert und mit der CLI an Crowdin überträgt.

### Self-Hosted App

```json title="manifest.json"
{
  "identifier": "deine-anwendungskennung",
  "name": "Deine Anwendung",
  "description": "Beschreibung der Anwendung",
  "logo": "/assets/logos/app-logo.png",
  "baseUrl": "https://example.com",
  "authentication": {
    "type": "crowdin_app",
    "clientId": "deine-client-id"
  },
  "events": {
    "installed": "/hooks/installed"
  },
  "scopes": [
    "project"
  ],
  "modules": {
    "project-integrations": [
      {
        "key": "dein-modulschlüssel",
        "name": "Modulname",
        "description": "Modulbeschreibung",
        "logo": "/assets/logos/module-logo.png",
        "url": "/page/integration",
        "environments": [
          "crowdin", "crowdin-enterprise"
        ]
      }
    ]
  }
}
```

### Serverless App

Ein serverloser Deskriptor enthält kein `baseUrl`, deklariert UI-Module ohne `url` und lässt `events` weg, die auf URLs auf einem eigenen Server verweisen.

```json title="manifest.json"
{
  "identifier": "your-application-identifier",
  "name": "Your Application",
  "description": "Application description",
  "bundle": {
    "mode": "internal"
  },
  "scopes": [
    "project"
  ],
  "modules": {
    "project-menu": [
      {
        "key": "your-module-key",
        "name": "Module name"
      }
    ]
  }
}
```

<Aside>
  Jede App muss über ein eindeutiges `baseUrl` verfügen. Wenn du mehrere Apps über denselben Host bereitstellen möchtest, solltest du ein Pfadpräfix in `baseUrl` aufnehmen.
</Aside>

`baseUrl` muss mit `https://` beginnen und kann nach der Installation der App nicht geändert werden, ohne die App zuvor zu deinstallieren. Wähle ihn daher, bevor du die App veröffentlichst.

Alle anderen URLs im Manifest, wie beispielsweise `logo`, `events` und Modul-URLs, beziehen sich relativ auf `baseUrl`. Beginne jeden Eintrag mit `/`. Crowdin entfernt ein abschließendes „/“ aus „baseUrl“, sodass „https://example.com/“ und „https://example.com“ gleich funktionieren.

## Authentication

Gibt den Authentifizierungstyp an, den Crowdin zum Signieren von Anfragen an die App verwendet:

* **`crowdin_app`**: Through an OAuth App. Verwende ihn, wenn die App die Crowdin API jederzeit selbst aufruft.
* **`none`**: Ohne OAuth-App. Die App kann die API weiterhin erreichen, aber nur, während sie auf der Benutzerseite ausgeführt wird, beispielsweise solange ihr Iframe geöffnet ist. Serverlose Anwendungen verwenden diesen Typ.
* **`crowdin_agent`**: Über einen speziellen Bot-Benutzer, den Crowdin bei der Installation der App anlegt, damit die App anschließend weiterhin in deinen Projekten funktioniert, beispielsweise in einem benutzerdefinierten Workflow-Schritt. Die API-Aufrufe deiner App werden als dieser Benutzer authentifiziert. Wird vom Modul [Workflow-Schritt-Typ](/developer/crowdin-apps-module-workflow-step-type/#authentication) benötigt.

<ReadMore>
  Erfahre mehr über [Sicherheit für Crowdin-Apps](/developer/crowdin-apps-security/).
</ReadMore>

Beispiel:

```json title="manifest.json"
{
  "authentication": {
    "type": "crowdin_app",
    "clientId": "your-client-id"
  }
}
```

| Feld       | Typ      | Beschreibung                                                                                               |
| ---------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `type`     | `string` | Die Authentifizierungsart, die du verwenden kannst: `none` (Standard), `crowdin_app` oder `crowdin_agent`. |
| `clientId` | `string` | OAuth-Client-ID für die Autorisierung über den Typ `crowdin_app`.                                          |

## Module

Über Module kannst du Crowdin um App-Funktionen erweitern. Jeder Typ legt fest, wo die App in der Benutzeroberfläche angezeigt wird oder was sie verarbeitet:

* **UI-Module**: Panels, Dashboards, Menüs und Dialoge innerhalb von Crowdin.
* **KI-Module**: Benutzerdefinierte KI-Anbieter, Prompt-Anbieter und Prozessoren für KI-Anfragen.
* **Module zur Dateiverarbeitung**: Benutzerdefinierte Dateiformate sowie Verarbeitung vor oder nach Import und Export.
* **Weitere Module**: Benutzerdefinierte maschinelle Übersetzungsengines, Webhooks, Workflow-Schritte, Qualitätssicherungsprüfungen und Rechtschreibprüfungen.

<ReadMore>
  Erfahre mehr über [UI-Module](/developer/crowdin-apps-modules-ui/), [KI-Module](/developer/crowdin-apps-modules-ai/) und [Dateiverarbeitungsmodule](/developer/crowdin-apps-modules-file-processing/).
</ReadMore>

## Events

Eine selbst gehostete App registriert Callbacks für Ereignisse, die in deinem Arbeitsbereich auftreten. Jede Eigenschaft in diesem Objekt ist eine URL, die relativ zur `baseUrl` deiner App ist, und Crowdin sendet eine POST-Anfrage an diese URL, sobald das Ereignis ausgelöst wird. Der Callback `installed` ist Teil der Installation selbst, während sich die übrigen wie Webhooks verhalten.

Beispiel:

```json title="manifest.json"
{
  "events": {
    "installed": "/hooks/installed",
    "uninstall": "/hooks/uninstall"
  }
}
```

| Event       | Typ      | Beschreibung                                                                                                                                                             |
| ----------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `installed` | `string` | Wird an die App gesendet, nachdem du sie in Crowdin installiert hast. Erforderlich bei den [Authentifizierungstypen](#authentication) `crowdin_app` und `crowdin_agent`. |
| `uninstall` | `string` | Wird an die App gesendet, bevor diese aus Crowdin deinstalliert wird.                                                                                                    |

### Installierte Ereignis-Nutzdaten

Crowdin sendet das `installed`-Ereignis an die App, wenn du sie installierst. Die Nutzlast beschreibt den Arbeitsbereich oder das Profil, in dem die App installiert wurde, die App selbst sowie die Anmeldedaten, die die App benötigt, um ein API-Token abzurufen.

<ReadMore>
  Erfahre mehr über den [Ablauf bei installierten Events](/developer/crowdin-apps-installation/#installed-event-communication-flow).
</ReadMore>

Payload Beispiel:

```json
{
  "appId": "your-application-identifier",
  "appSecret": "dbfg....asdffgg",
  "clientId": "your-client-id",
  "userId": 1,
  "organizationId": 1,
  "domain": null,
  "baseUrl": "https://crowdin.com"
}
```

```json
{
  "appId": "your-application-identifier",
  "appSecret": "dbfg....asdffgg",
  "clientId": "your-client-id",
  "userId": 1,
  "organizationId": 1,
  "domain": "{domain}",
  "baseUrl": "https://{domain}.crowdin.com"
}
```

Eigenschaften:

| Feld             | Typ       | Beschreibung                                                                                                                                                  |
| ---------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appId`          | `string`  | Die Kennung deiner App, die in der App-Deskriptordatei angegeben ist.                                                                                         |
| `appSecret`      | `string`  | Der eindeutige Schlüssel, der für die Autorisierung deiner Crowdin-App verwendet wird.                                                                        |
| `clientId`       | `string`  | Die OAuth-Client-ID, die in der App-Deskriptordatei deklariert ist.                                                                                           |
| `userId`         | `integer` | Die numerische Kennung des Benutzers, der die App installiert hat.                                                                                            |
| `organizationId` | `integer` | Die numerische Kennung der Organisation, in der die App installiert wurde.                                                                                    |
| `domain`         | `string`  | Der Name der Organisation in Crowdin Enterprise, in der die App installiert wurde. In Crowdin ist der Wert immer `null`.                                      |
| `baseUrl`        | `string`  | Die `baseUrl` deiner Organisation in Crowdin Enterprise, in der du die App installiert hast. In Crowdin lautet der Wert für dich immer `https://crowdin.com`. |
| `agentId`        | `integer` | Die numerische Kennung des für die App angelegten Agentenbenutzers. Wird nur für Apps mit dem Authentifizierungstyp `crowdin_agent` gesendet.                 |

### Nutzdaten für die Deinstallation

Crowdin sendet das `uninstall`-Ereignis an die App, bevor diese entfernt wird. Ähnlich wie beim `installed`-Ereignis beschreibt die Nutzlast den Arbeitsbereich oder das Konto, in dem die App installiert wurde, sowie die App selbst. Verwende diese Funktion, um die Daten zu löschen, die du für diesen Arbeitsbereich oder dieses Konto gespeichert hast.

Payload Beispiel:

```json
{
  "appId": "your-application-identifier",
  "clientId": "your-client-id",
  "organizationId": 1,
  "domain": null,
  "baseUrl": "https://crowdin.com"
}
```

```json
{
  "appId": "your-application-identifier",
  "clientId": "your-client-id",
  "organizationId": 1,
  "domain": "{domain}",
  "baseUrl": "https://{domain}.crowdin.com"
}
```

Eigenschaften:

| Feld             | Typ       | Beschreibung                                                                                                                                                  |
| ---------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appId`          | `string`  | Die Kennung deiner App, die in der App-Deskriptordatei angegeben ist.                                                                                         |
| `clientId`       | `string`  | Die OAuth-Client-ID, die in der App-Deskriptordatei deklariert ist.                                                                                           |
| `organizationId` | `integer` | Die numerische Kennung der Organisation, aus der du die App deinstalliert hast.                                                                               |
| `domain`         | `string`  | Der Name der Organisation in Crowdin Enterprise, aus der du die App deinstalliert hast. In Crowdin ist der Wert immer `null`.                                 |
| `baseUrl`        | `string`  | Die `baseUrl` der Organisation in Crowdin Enterprise, aus der du die App deinstalliert hast. In Crowdin lautet der Wert für dich immer `https://crowdin.com`. |
