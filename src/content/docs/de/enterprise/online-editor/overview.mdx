Der Editor ist der zentrale Bereich in Crowdin Enterprise, in dem Projektmitglieder an Übersetzungen arbeiten können. Du kannst damit online Übersetzungen vorschlagen, bewerten, überprüfen und freigeben.

Über das Hauptmenü oben im Editor (**Datei**, **Bearbeiten**, **Ansicht**, **Workflow** (nur in [Projekten mit einem Workflow](/enterprise/creating-project/#projects-with-a-workflow)), **Sprache**, **Projekt**, **Hilfe**) kannst du Inhalte zur Übersetzung auswählen, Übersetzungen herunterladen oder hochladen, verschiedene Aktionen für Strings ausführen, das Layout des Editors ändern, Zielsprachen wechseln, Projektseiten aufrufen, zwischen Projekten wechseln, Hilfethemen öffnen und vieles mehr.

## Kernfunktionen

Der Editor bietet Übersetzern und Korrekturlesern alle erforderlichen Werkzeuge, darunter:

* Eine Liste der verfügbaren Strings, die je nach [Editor-Modus](#editor-modes) variieren kann.
* Kontext, Labels und zusätzliche Informationen, die dich bei der Arbeit unterstützen.
* Such- und Filteroptionen für Strings, damit du Übersetzungen effizient verwalten kannst.
* [KI-gestützte Vorschläge](/enterprise/crowdin-ai/#using-ai-in-the-editor), Vorschläge aus dem [Translation Memory (TM)](/enterprise/translation-memory/) und Vorschläge aus der [maschinellen Übersetzung (MT)](/enterprise/machine-translation/).
* Begriffe aus dem [Glossar](/enterprise/glossary/), um eine einheitliche Terminologie sicherzustellen.
* Ein Kommentarbereich für die Zusammenarbeit und zum Melden von Problemen.

### Zeichenfolgenliste

In diesem Bereich wird die Liste der Strings angezeigt; der aktuell ausgewählte String ist hervorgehoben. Strings sind Textelemente, die aus einzelnen Wörtern, Ausdrücken oder Sätzen bestehen können. Einige Strings können Platzhalter enthalten (z. B. {0}, {1}, %1 usw.). oder Elemente der [ICU-Nachrichtensyntax](/enterprise/icu-message-syntax/). Diese Elemente selbst dürfen nicht übersetzt werden. Der Website-Code verwendet sie, um dynamisch Informationen in Strings einzufügen. Um mit solchen Zeichenfolgen zu arbeiten, kopiere die Quellzeichenfolge und übersetze nur die eigentlichen Wörter.

##### Status von Zeichenfolgen

Zeichenfolgen können die folgenden Status haben:

* <Icon name="untranslated" size="24" class="inline-icon align-middle" /> – nicht übersetzt
* <Icon name="partially-translated" size="24" class="inline-icon align-middle" /> – teilweise übersetzt (wenn einige Pluralformen noch nicht übersetzt sind)
* <Icon name="translated" size="24" class="inline-icon align-middle" /> – übersetzt
* <Icon name="partially-approved" size="24" class="inline-icon align-middle" /> – teilweise freigegeben (wenn einige Pluralformen noch nicht freigegeben sind)
* <Icon name="approved" size="24" class="inline-icon align-middle" /> – freigegeben
* <Icon name="hidden" size="24" class="inline-icon align-middle" /> – ausgeblendet (nur für Projektmanager und Korrekturleser sichtbar)

##### Workflow-Status

In [Projekten mit einem Workflow](/enterprise/creating-project/#projects-with-a-workflow) können Zeichenketten zusätzlich die folgenden Workflow-Status haben:

* <Icon name="todo" size="24" class="inline-icon align-middle" /> **Todo** – Zeigt an, dass für die Zeichenfolge im aktuellen Workflow-Schritt eine Aktion aussteht. In einem **Übersetzungs**-Schritt bedeutet dies beispielsweise, dass die Zeichenfolge noch nicht übersetzt ist. Im Schritt **Korrekturlesen** bedeutet dies, dass die Zeichenfolge noch nicht freigegeben ist.
* <Icon name="pending" size="24" class="inline-icon align-middle" /> **Ausstehend** – Dieser Status gilt speziell für den Schritt [**Quelltextprüfung**](/enterprise/source-text-review/). Er zeigt an, dass eine Korrektur für den String freigegeben wurde, deren Text vom ursprünglichen Quelltext abweicht.
* <Icon name="done" size="24" class="inline-icon align-middle" /> **Erledigt** – Zeigt an, dass die Hauptaktion für den aktuellen Workflow-Schritt abgeschlossen ist. Im Schritt **Übersetzung** bedeutet dies beispielsweise, dass der String übersetzt wurde. Im Schritt **Korrekturlesen** bedeutet es, dass der String freigegeben wurde.

#### Übersetzungen vorschlagen

Um eine Übersetzung vorzuschlagen, wähle eine Zeichenfolge aus der Liste aus und gebe deinen Vorschlag in das Feld neben dem Originaltext ein. Wenn ein String eine maximale Länge hat, zeigt der Zeichenzähler in der Symbolleiste die Übersetzungslänge neben dem Limit an (z. B. 28/10). Die Werte werden rot angezeigt, wenn die Übersetzung das Limit überschreitet.

Um den Übersetzungsprozess zu vereinfachen, kannst du die Funktion zum automatischen Speichern aktivieren. Wenn die Einstellung **Übersetzungen automatisch speichern** in den [Editor-Einstellungen](#general) aktiviert ist, werden deine Übersetzungen automatisch gespeichert, wenn du zu einem anderen String wechselst. Kurz wird ein Indikator „Wird gespeichert …“ angezeigt, gefolgt von der Bestätigung „Gespeichert“.

Standardmäßig ist das automatische Speichern deaktiviert. Du musst daher für jeden String manuell auf <Icon name="mdi:content-save" class="inline-icon" /> **Übersetzung speichern** klicken. Wenn das automatische Speichern deaktiviert ist, dient die Schaltfläche **Übersetzung speichern** als primäre Aktion und wird grün angezeigt. Wenn das automatische Speichern aktiviert ist, wird die Schaltfläche grau, da manuelles Speichern optional ist.

Nach dem Speichern wird dein Vorschlag zur Liste der Übersetzungsvorschläge des Strings hinzugefügt. Standardmäßig ist die Option **Automatisch zum nächsten String wechseln** aktiviert, sodass der Editor anschließend zum nächsten String wechselt.

Wenn du deine aktuelle Eingabe verwerfen und vor dem Speichern zum vorherigen Zustand zurückkehren möchtest, klicke auf <Icon name="material-symbols:undo" class="inline-icon" /> **Abbrechen**.

#### Mehrere Strings auswählen

In den Modi **Side-by-Side**, **Mehrsprachig** und **Mehrsprachig (Raster)** kannst du mehrere Strings auswählen und alle gleichzeitig bearbeiten. Aktiviere die Kontrollkästchen links neben den gewünschten Strings oder das Kontrollkästchen oberhalb der Liste, um alle Strings auf der Seite auszuwählen.

<Aside type="tip">
  In den Modi **Side-by-Side** und **Mehrsprachig** kannst du Strings auch mit den üblichen Auswahl-Tastenkombinationen auswählen:
  * Um einen zusammenhängenden Bereich auszuwählen, klicke auf den ersten String, halte <KBD>Shift</KBD> gedrückt und klicke dann auf den letzten String.
  * Um einzelne Strings zur Auswahl hinzuzufügen oder daraus zu entfernen, halte <KBD>Ctrl</KBD> oder <KBD>Cmd</KBD> gedrückt und klicke auf die entsprechenden Strings.
</Aside>

Wenn mehrere Strings ausgewählt sind, kannst du Folgendes tun:

* Kopiere den Quelltext mit <Icon name="copy-source" class="inline-icon dark:invert" /> in der Symbolleiste oberhalb der Liste in die entsprechenden Übersetzungsfelder.
* Kopiere die nicht übersetzbaren Elemente mit **Quelltext-Gerüst kopieren** aus dem [String-Menü](#string-menu) in die entsprechenden Übersetzungsfelder.
* Leere die Übersetzungsfelder mit **Ausgewählte Eingaben löschen** aus dem [String-Menü](#string-menu).
* Speichere nicht gespeicherte Übersetzungen oder mache sie mit <Icon name="mdi:content-save" class="inline-icon" /> bzw. <Icon name="material-symbols:undo" class="inline-icon" /> in der Symbolleiste oberhalb der Liste rückgängig. Diese Schaltflächen werden angezeigt, wenn **Übersetzungen automatisch speichern** in den [Editor-Einstellungen](#general) deaktiviert ist.

Andere Aktionen hängen von deiner Rolle im Projekt ab. Korrekturleser können beispielsweise auch [die ausgewählten Strings genehmigen](#proofreading).

Wenn sich die Strings, die dem aktuellen Filter entsprechen, über mehrere Seiten erstrecken, wähle alle Strings auf der Seite aus und klicke dann auf den Link im Banner oberhalb der Liste, um die restlichen auszuwählen. Speichern, Rückgängigmachen und Genehmigen gilt dann für alle.

#### Korrekturlesen

Überprüfe die Übersetzungen, um sicherzustellen, dass sie für den Export bereit sind, und klicke neben dem Vorschlag auf <Icon name="mdi:check" class="inline-icon" />, um jede Übersetzung einzeln zu genehmigen.

Um mehrere Strings gleichzeitig zu genehmigen, [wähle sie aus](#selecting-multiple-strings) und klicke in der Symbolleiste oberhalb der Liste auf <Icon name="material-symbols:done-all" class="inline-icon" />.

<Aside>
  Stelle sicher, dass du die [QA-Prüfungen](/enterprise/project-settings/qa-checks/) aktivierst, damit du Zeichenfolgen finden kannst, die einer Überprüfung bedürfen. Gefundene Probleme werden unter den zu überarbeitenden Übersetzungen rot hervorgehoben; jede Meldung beschreibt das Problem.
</Aside>

##### Freigaben verwalten

Jede Übersetzung kann von mehreren Korrekturlesern und Projektmitgliedern mit Managerberechtigungen oder höherer Berechtigungsstufe einmal oder mehrmals freigegeben werden. Sobald eine Übersetzung mindestens einmal freigegeben wurde, wird sie in allen Workflow-Schritten des Projekts als freigegeben angezeigt.

Bei Bedarf kann ein Korrekturleser oder ein Projektmitglied mit Managerberechtigungen oder höher die Freigaben für Übersetzungen bearbeiten, die mindestens zweimal freigegeben wurden. Dazu kann er einzelne Freigaben oder alle auf einmal entfernen.

So entfernst du Freigaben einzeln:

<Steps>
  1. Öffne den gewünschten String im Editor.
  2. Klicke im Bereich **Kontext und Übersetzungen** neben den Profilbildern der Korrekturleser, die die Übersetzung freigegeben haben, auf **Details**.
  3. Klicke neben der Freigabe, die du entfernen möchtest, auf **Entfernen**.
</Steps>

Um alle Freigaben auf einmal zu entfernen, klicke oben rechts auf <Icon name="mdi:dots-vertical" class="inline-icon" /> und wähle **Alle Freigaben entfernen**. Um nur deine eigenen Freigaben zu entfernen, wähle stattdessen **Meine Freigaben entfernen**.

##### Übersetzungspriorität

Übersetzungen mit den meisten Freigaben haben die höchste Priorität. Sie werden im Editor oben in der Übersetzungsliste angezeigt und beim Herunterladen der Übersetzungen verwendet.

Wenn für einen String mehrere Übersetzungen vorhanden sind, wird die Übersetzungsliste nach folgenden Prioritäten sortiert:

1. **Übersetzung mit den meisten Freigaben**: Die Übersetzung mit den meisten Freigaben hat höchste Priorität.
2. **Am häufigsten bewertete Übersetzung**: Haben mehrere Übersetzungen gleich viele Freigaben – einschließlich Übersetzungen ohne Freigaben –, hat die Übersetzung mit der höchsten Bewertung durch Stimmen Vorrang.
3. **Zuletzt freigegebene Übersetzung**: Haben freigegebene Übersetzungen gleich viele Freigaben und dieselbe Bewertung, hat die zuletzt freigegebene Übersetzung Vorrang.
4. **Zuletzt hinzugefügte Übersetzung**: Haben nicht freigegebene Übersetzungen dieselbe Bewertung, hat die zuletzt hinzugefügte Übersetzung Vorrang.

#### WYSIWYG-Dateivorschau

Wenn du Inhalte in den Formaten HTML, XML, TXT, DOCX, XLSX, HAML, Web XML, Markdown, MDX, DITA, Wiki, ADOC, Coffee, FTL, JS, TS oder FTLH übersetzt, kannst du eine untere Leiste ein- oder ausblenden (in den Modi Side-by-Side und Mehrsprachig), um eine Dateivorschau (WYSIWYG) anzuzeigen. Im Komfortmodus wird bei der Arbeit mit den oben genannten Formaten standardmäßig eine Dateivorschau angezeigt.

Der Status der Zeichenfolge wird durch die folgenden Farben angezeigt:

* rot – nicht übersetzt
* Blau – übersetzt
* Hellgrün – freigegeben
* Grau – nicht zur Übersetzung vorgesehen

##### Vollbild und doppelte Vorschau

Wenn du zu **Vollbild** oder **Doppelte Vorschau** wechselst, zeigt die Vorschau die gesamte Datei an und umgeht die Seitenbegrenzung der standardmäßigen [String-Liste](#string-list).

Statt das Seitenpanel zu verwenden, kannst du den Text auch direkt im Kontext über die Inline-Bearbeitung übersetzen:

<Steps>
  1. Klicke direkt in der WYSIWYG-Vorschau auf einen beliebigen hervorgehobenen Text.
  2. Daraufhin öffnet sich ein Popover, in das du deine Übersetzung eingeben und speichern kannst.
  3. Wenn du beim Übersetzen den Originaltext sehen möchtest, klicke im Popover auf **Quell-String**, um ihn auszuklappen.
</Steps>

Wenn du im Modus **Doppelte Vorschau** im Quelltextbereich auf einen String klickst, wird der entsprechende String im Übersetzungsbereich automatisch hervorgehoben (und umgekehrt) und zugleich das Übersetzungs-Popover geöffnet.

<Aside title="Einschränkungen der Vorschau">

#### Strings suchen

Um bestimmte Strings im Editor zu finden, gib deine Suchanfrage in das Suchfeld oben in der String-Liste ein. Mit der Tastenkombination (standardmäßig <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>F</KBD></span> oder <span class="whitespace-nowrap"><KBD>⌘</KBD>+<KBD>F</KBD></span>) springst du direkt zum Suchfeld.

Je nachdem, welchen Inhalt du im Editor geöffnet hast, wird in der aktuell geöffneten Datei, im Ordner oder in allen Strings des Projekts gesucht.

Um die Suchergebnisse einzugrenzen, klicke neben dem Suchfeld auf das Symbol <Icon name="mdi:tune" class="inline-icon" /> **Suchfilter**. Daraufhin öffnet sich ein Dropdown-Menü mit den folgenden Filtern und Optionen:

<Image src={stringSearch} alt="Strings suchen" />

##### Suchen in

Lege den Suchbereich fest, indem du eines der folgenden Kriterien auswählst:

* *Alles* – durchsucht Quelltexte, Übersetzungen, Kontext und Bezeichner.
* *Strings* – durchsucht nur Quelltexte.
* *Alle Übersetzungen* – Durchsuche alle Übersetzungen einer Zeichenfolge.
* *Endgültige Übersetzungen* – Es wird nur nach der Übersetzung gesucht, die oben in der Übersetzungsliste angezeigt und beim Herunterladen verwendet wurde.
* *Kontext* – durchsucht nur den Kontext der Strings.
* *Bezeichner (Schlüssel)* – durchsucht nur die String-Bezeichner.

Der Editor hebt Übereinstimmungen in den von der ausgewählten Option abgedeckten Feldern hervor.

##### Optionen

Mit diesen Optionen kannst du die Suche weiter eingrenzen:

* *Groß-/Kleinschreibung beachten* – findet nur Strings mit derselben Groß- und Kleinschreibung. Eine Suche nach `Work` findet beispielsweise `Work`, `Works` und `Working`, aber nicht `work`.
* *Ganze Wortfolge* – findet Strings, die die Suchphrase in genau derselben Reihenfolge enthalten. Eine Suche nach `Machine Translation` findet beispielsweise `Machine Translation` oder `machine translation`, aber nicht `Translation Machine`.
* *Exakte Übereinstimmung* – findet nur Strings, die exakt der Suchphrase entsprechen. Eine Suche nach `Work` findet beispielsweise `Work` oder `work`, aber nicht `Works` oder `Working`.

Du kannst *Groß-/Kleinschreibung beachten* mit *Ganze Wortfolge* oder *Exakte Übereinstimmung* kombinieren. Beachte, dass *Ganze Wortfolge* und *Exakte Übereinstimmung* nicht gleichzeitig verwendet werden können. Wenn du den Suchbegriff in Anführungszeichen setzt, wird *Ganze Phrase abgleichen* automatisch aktiviert, sofern nicht *Exakte Übereinstimmung* ausgewählt ist.

Die Suchphrase darf höchstens 128 Zeichen lang sein. Wenn du eine längere Suchphrase eingibst, wird sie automatisch auf die zulässige Höchstlänge gekürzt.

Du kannst einen bestimmten String auch über seine interne numerische ID finden. Diese Nummer wird automatisch von Crowdin vergeben. Gebe dazu die numerische ID (zum Beispiel `34354`) ohne Anführungszeichen in das Suchfeld ein, um eine exakte Übereinstimmung zu erhalten. Bei einer Suche nach einer Zeichenfolgen-ID werden die Filter und Suchoptionen ignoriert.
Um nach Vorkommen der Zahl im Text oder Kontext zu suchen, setze es in Anführungszeichen (zum Beispiel `„34354“`) oder wähle **Als Text suchen**.

#### Strings filtern

Um die in der linken Seitenleiste angezeigten Strings zu filtern, klicke auf <Icon name="mdi:filter-variant" class="inline-icon" /> und wähle die gewünschte Filteroption aus.

Verfügbare Filteroptionen:

* *Alle anzeigen* &ndash; Zeigt alle Strings aus der geöffneten Datei bzw. dem geöffneten Ordner in ihrer ursprünglichen Reihenfolge an.
* *Alle, nicht übersetzte zuerst* &ndash; Zeigt alle Strings aus der geöffneten Datei bzw. dem geöffneten Ordner an. Nicht übersetzte Strings werden oben in der Liste angezeigt, danach folgen die übersetzten Strings. Freigegebene Strings stehen am Ende der Liste.
* *Nicht übersetzt* &ndash; Zeigt nur Strings an, für die noch keine Übersetzung vorhanden ist.
* *Zur Abstimmung* &ndash; Zeigt bereits übersetzte Strings an, für die noch abgestimmt werden muss.
* *Nicht freigegeben* &ndash; Zeigt bereits übersetzte Strings an, die noch nicht von einem Korrekturleser freigegeben wurden.
* *Freigegeben* &ndash; Zeigt nur Strings mit freigegebenen Übersetzungen an.
* *Ungespeicherte Übersetzungen* &ndash; Zeigt Strings mit Übersetzungen an, die du eingegeben, aber noch nicht gespeichert hast.
* *QA-Probleme* &ndash; Zeigt Strings mit oder ohne ungelöste QA-Probleme in der aktuellen Sprache an. Du kannst dabei nach bestimmten Fehlern filtern.
* *Automatisch übersetzt* &ndash; Zeigt Zeichenfolgen an, deren endgültige Übersetzung (die ganz oben in der Übersetzungsliste steht) automatisch übersetzt wurde. Wähle *Alle* aus oder schränke die Ergebnisse auf *TM*, *MT* oder *AI* ein.
* *Mit Kommentaren* &ndash; Zeigt Strings an, für die Kommentare vorhanden sind.
* *Mit ungelösten Problemen* &ndash; Zeigt Strings mit ungelösten Problemen in der aktuellen Sprache oder in allen Sprachen an.
* *Ausgeblendet* &ndash; Zeigt Strings an, die für Übersetzer ausgeblendet sind. Projektmanager können Strings ausblenden. Crowdin Enterprise blendet Strings außerdem automatisch aus, wenn sie als Duplikate markiert sind.

##### Mit Kontext-Strings arbeiten

Kontext-Strings sind durch ein Puzzle-Symbol <Icon name="garden:puzzle-piece-fill-12" class="inline-icon" /> gekennzeichnet und ausgegraut, damit sie sich von den Strings in deiner primären gefilterten Ansicht unterscheiden. Wie du mit ihnen interagieren kannst, hängt davon ab, wie du den Editor geöffnet hast:

* **Normaler Editor-Modus:** Wenn du eine Quelldatei direkt im Editor öffnest, kannst du mit Kontext-Strings genauso arbeiten wie mit normalen Strings. Auch wenn sie ausgegraut sind, kannst du sie auswählen, Übersetzungen hinzufügen, über sie abstimmen und sie freigeben.
* **Aufgabenmodus:** Wenn du im Editor eine bestimmte Aufgabe öffnest, dienen Kontext-Strings ausschließlich als Referenz. Sie sind schreibgeschützt; ihre Eingabefelder und Aktionsschaltflächen sind deaktiviert. So steht dir der notwendige Kontext zur Verfügung, ohne dass du versehentlich Strings außerhalb deiner zugewiesenen Aufgabe änderst.

### QA-Prüfungen

Um die Übersetzungsqualität zu erhalten und häufige Fehler zu vermeiden, führt der Editor automatisch Qualitätssicherungsprüfungen (QA) durch. Diese Prüfungen suchen nach Problemen wie abweichender Zeichensetzung, uneinheitlichen Abständen, fehlenden Platzhaltern oder inkonsistenter Terminologie.

Das Verhalten des Editors hängt davon ab, ob diese Probleme als **Fehler** oder **Warnungen** konfiguriert sind:

* **Fehler (blockierende Probleme):** Das Inline-Banner **Probleme zum Speichern überprüfen** wird angezeigt, und auf der Schaltfläche **Übersetzung speichern** erscheint ein orangefarbenes Warnsymbol. Das Speichern der Übersetzung und die Navigation (z. B. das Wechseln der Zielsprache, das Öffnen einer anderen Datei oder das Anwenden von Filtern) werden verhindert, bis du das Problem behoben hast. Wenn du mit dem Mauszeiger über die Schaltfläche **Übersetzung speichern** fährst, wird der Tooltip „Zuerst blockierende Probleme lösen“ angezeigt. Fehler werden strikt durchgesetzt und lösen das Banner auch dann aus, wenn du die Option **QA-Probleme** in deinen persönlichen Editor-Einstellungen deaktiviert hast. Du kannst weiterhin zu einem anderen String wechseln, aber die Übersetzung des aktuellen Strings bleibt ungespeichert, bis der Fehler behoben ist.
* **Warnungen (nicht blockierende Probleme):** Bei weniger kritischen Inkonsistenzen hängt das Verhalten davon ab, ob die Option **QA-Probleme** in deinen [Editor-Einstellungen](#general) aktiviert ist:
  * **Einstellung AN:** Das Inline-Banner **Probleme zum Speichern überprüfen** zeigt die Warnungen an, und auf der Schaltfläche **Übersetzung speichern** erscheint ein orangefarbenes Warnsymbol. Die Navigation ist blockiert, bis du die Probleme behebst oder auf **Trotzdem speichern** klickst.
  * **Einstellung AUS:** Die Übersetzung wird automatisch gespeichert (wenn das automatische Speichern aktiviert ist), ohne dass das Banner oder das Warnsymbol angezeigt wird, wodurch diese Warnungen vollständig umgangen werden.

<Aside>
  Projektmanager legen fest, ob eine bestimmte QA-Prüfung als Fehler oder Warnung behandelt wird. Einige kritische Prüfungen (z. B. Syntaxfehler) sind jedoch dauerhaft als Fehler festgelegt, um schwerwiegende Übersetzungsprobleme zu verhindern.
</Aside>

Wenn beim manuellen Speichern einer Übersetzung oder beim automatischen Speichern nach dem Wechsel zwischen Strings QA-Probleme erkannt werden, werden sie im Inline-Banner angezeigt. Unten siehst du ein Beispiel für eine Abweichung bei der Zeichensetzung (standardmäßig als Warnung konfiguriert):

<Image src={qaInlineBanner} alt="Inline-Banner für QA-Probleme" />

Im Übersetzungsfeld umrandet der Editor den Text, auf den sich die Probleme beziehen. Bewege den Mauszeiger im Banner über ein Problem, um nur dieses Problem hervorzuheben.

#### QA-Probleme automatisch beheben

Bei vielen häufigen Fehlern bietet das Inline-QA-Banner automatische Schnellkorrekturen:

* Klicke neben einem einzelnen Problem auf das <Icon name="mdi:magic-staff" class="inline-icon" />-Symbol **Automatisch beheben**, um die Korrektur automatisch anzuwenden.
* Klicke in der Kopfzeile des Banners auf **Beheben (N)**, um alle verfügbaren automatischen Korrekturen für den aktuellen String sofort anzuwenden.

Sobald die Probleme behoben sind, wird die Übersetzung automatisch gespeichert und du kannst fortfahren.

  * **Unbegrenzt**: Erlaube Übersetzungen beliebiger Länge ohne Einschränkungen.
* **String löschen**: Entferne den String dauerhaft aus dem Projekt. (Für Projektmitglieder mit Managerberechtigungen oder höher verfügbar.)

#### Screenshot-Viewer

Screenshots, die mit einem String verknüpft sind, werden im Bereich **Kontext und Übersetzungen** als Vorschaukarten angezeigt. Jede Karte zeigt den gesamten Screenshot mit einer roten Umrandung um die Stelle, an der der String verwendet wird. Bewege den Mauszeiger über eine Karte, um eine vergrößerte Vorschau zu sehen.

Klicke auf eine Karte, um den Screenshot-Viewer zu öffnen. Dabei handelt es sich um einen Dialog, den du über dem Editor verschieben und dessen Größe du ändern kannst. Der Screenshot wird an die Größe des Dialogs angepasst. Größe und Position des Dialogs bleiben gespeichert, wenn du ihn das nächste Mal öffnest.

<Image src={screenshotsInEditor} alt="Screenshot-Viewer" />

In der Symbolleiste des Viewers stehen folgende Optionen zur Verfügung:

* <Icon name="mdi:minus" class="inline-icon" /> **Verkleinern** (<KBD>-</KBD>) und <Icon name="mdi:plus" class="inline-icon" /> **Vergrößern** (<KBD>+</KBD>): Ändert die Zoomstufe schrittweise. Die aktuelle Zoomstufe wird zwischen den beiden Schaltflächen angezeigt.
* <Icon name="mdi:fit-to-screen-outline" class="inline-icon" /> **An Bildschirm anpassen** (<KBD>Space</KBD>): Passt den gesamten Screenshot in den Dialog ein.
* **1:1** (<KBD>1</KBD>): Zeigt den Screenshot in seiner tatsächlichen Größe an.
* <Icon name="mdi:crosshairs-gps" class="inline-icon" /> **String zentrieren** (<KBD>C</KBD>): Vergrößert die Ansicht der Stelle, an der der String verwendet wird. Wenn ein String im selben Screenshot an mehreren Stellen markiert ist, springst du mit jedem Klick zur nächsten Stelle. Ein Zähler zeigt an, welche Stelle gerade ausgewählt ist.
* <Icon name="mdi:chevron-left" class="inline-icon" /> **Vorheriger Screenshot** (<KBD>←</KBD>) und <Icon name="mdi:chevron-right" class="inline-icon" /> **Nächster Screenshot** (<KBD>→</KBD>): Wechselt zwischen allen Screenshots, die dem String angehängt sind. Ein Zähler zeigt deine Position in der Liste an.
* <Icon name="mdi:close" class="inline-icon" /> **Schließen** (<KBD>Esc</KBD>): Schließt den Viewer.

Mit dem Scrollen kannst du dich im Screenshot bewegen. Halte beim Scrollen <KBD>Ctrl</KBD> (oder <KBD>⌘</KBD>) gedrückt, um zu zoomen. Klicke auf den Screenshot, um an dieser Stelle auf 200 % zu zoomen. Halte beim Klicken <KBD>Alt</KBD> (oder <KBD>⌥</KBD>) gedrückt, um wieder herauszuzoomen. Tastenkombinationen funktionieren, solange der Dialog aktiv ist.

Jeder im Screenshot markierte String ist umrandet. Der String, an dem du gerade arbeitest, hat eine durchgezogene Umrandung; die anderen sind gestrichelt umrandet. Klicke auf eine gestrichelte Umrandung, um zu diesem String zu wechseln. Der Viewer bleibt dabei auf demselben Screenshot.

Wenn du einen anderen String in der Liste auswählst, wechselt der geöffnete Viewer automatisch zu diesem String. Wenn der neue String im selben Screenshot vorkommt, verschiebt sich die durchgezogene Umrandung zu seiner Position. Andernfalls wechselt der Viewer zu den Screenshots dieses Strings.

Vorschläge von KI, TM und MT werden in einem einzigen, einklappbaren Bereich **Automatisierte Vorschläge** gruppiert. Im Schritt [Quelltextprüfung](/enterprise/source-text-review/) heißt dieser Bereich **Automatisierte Korrekturen**.

#### Kommentare mit externen Organisationen austauschen

Wenn du mit Teams anderer Organisationen zusammenarbeitest, etwa mit Lokalisierungsdienstleistern, kannst du über gemeinsame Kommentare direkt im Editor kommunizieren.

Aktiviere vor dem Veröffentlichen das Kontrollkästchen **Gemeinsam**, damit alle beteiligten Organisationen den Kommentar sehen können. Es erscheint ein Hinweis mit den Organisationen, die deinen Kommentar sehen können. So bleibt die Diskussion transparent.

Alle Kommentare, sowohl private als auch gemeinsame, werden zur einfacheren Nachverfolgung in einem chronologischen Verlauf angezeigt. Gemeinsame Kommentare sind deutlich mit dem Label **Gemeinsam** gekennzeichnet und lassen sich so leicht von rein internen Diskussionen unterscheiden.

So stellst du sicher, dass die richtigen Personen benachrichtigt werden:

* Wenn du ein gemeinsames **Problem** meldest (z. B. einen Tippfehler im Quelltext), werden die Projektmanager aller beteiligten Organisationen benachrichtigt.
* Du kannst ein Team mit `@` erwähnen (z. B. `@YourVendorTeam`), um alle Teammitglieder zu benachrichtigen. Einzelne Benutzer aus anderen Organisationen kannst du nicht mit `@` erwähnen, sondern nur Benutzer aus deiner eigenen Organisation. So kannst du Fragen dennoch an das zuständige Team richten.

<Aside type="tip">
  Um direkt auf einen Kommentar eines Benutzers einer anderen Organisation zu antworten, bewege den Mauszeiger über dessen Nachricht und klicke auf <Icon name="material-symbols:reply" class="inline-icon" /> **Antworten**.

  Durch diese Aktion wird das Kontrollkästchen **Gemeinsam** automatisch aktiviert und deiner Nachricht eine eindeutige Erwähnung des ursprünglichen Kommentators hinzugefügt (z. B. `@username:123456789:123`). So wird eine reibungslose Unterhaltung sichergestellt und die richtige Person in den verschiedenen Organisationen benachrichtigt.
</Aside>

Kommentare, die ohne aktivierte Option **Gemeinsam** erstellt werden, bleiben privat und sind nur für Mitglieder deiner Organisation sichtbar.

### TM durchsuchen

Im Bereich *TM durchsuchen* kannst du alle verfügbaren Übersetzungen aus dem [Translation Memory](/enterprise/translation-memory/) durchsuchen. Dabei handelt es sich um einen Speicher für Übersetzungen, die Projektmanager in das System hochgeladen haben. Damit du schnell passende Ergebnisse findest, priorisiert die Suche die relevantesten Treffer und zeigt sie ganz oben in der Liste an.

Der Bereich „TM durchsuchen“ bietet folgende Optionen:

* Quelle &ndash; Sucht nach Übereinstimmungen in einer Quellsprache.
* Ziel &ndash; Sucht nach Übereinstimmungen in Zielsprachen.
* Übersetzung erraten &ndash; Hebt die wahrscheinliche Übersetzung einer Suchphrase hervor.
* Numerische Entsprechung &ndash; Gleicht Ziffern aus einer Suchphrase mit beliebigen anderen Ziffern ab.

Um möglichst viele Ergebnisse zu erhalten, kannst du außerdem die folgenden Platzhalter in deiner Suchphrase verwenden:

Gib ein Sternchen **(\*)** ein, um Wörter zu finden, deren Anfang oder Ende abweichen kann.
Beispiel: `any*` findet *any*, *anyway* und *anything*.
Beispiel: `*way` findet *way*, *anyway* und *highway*.

Gib ein Pluszeichen **(+)** ein, um Wörter zu finden, deren Anfang oder Ende abweichen muss.
Beispiel: `any+` findet *anyway*, *anything* und *anywhere*, aber nicht *any*.
Beispiel: `+way` findet *anyway*, *highway* und *someway*, aber nicht *way*.

Gib ein Minuszeichen **(-)** ein, um Wörter aus deiner Suche auszuschließen.
Beispiel: `Save -as`

Verwende Anführungszeichen, um nach einer exakten Wortkombination zu suchen.
Beispiel: `"Save as"`

Jeder TM-Vorschlag in den Suchergebnissen enthält außerdem Angaben wie den Namen des Translation Memory, das Erstellungsdatum und – falls verfügbar – den Namen der Person, die die Übersetzung ursprünglich eingereicht hat.

### TM-Vorschläge im Editor bearbeiten

Im Editor kannst du TM-Vorschläge sowohl im Bereich „Automatisierte Vorschläge“ als auch in der rechten Seitenleiste über den Bereich „TM durchsuchen“ anzeigen. Manchmal enthalten TM-Vorschläge Ungenauigkeiten oder müssen aktualisiert werden.

Projektmitglieder mit Managerberechtigungen oder höher können TM-Einträge direkt im Editor bearbeiten oder löschen – sowohl im Bereich „Automatisierte Vorschläge“ als auch im Bereich „TM durchsuchen“. Dazu müssen sie nicht zur Seite „Translation Memories“ unter „Ressourcen“ oder „Projekteinstellungen“ wechseln. Dadurch lassen sich TM-Vorschläge sicher und schnell aktualisieren und die Gesamtqualität des Translation Memory verbessern.

So bearbeitest du einen TM-Vorschlag:

<Steps>
  1. Klicke im Bereich „Automatisierte Vorschläge“ auf <Icon name="mdi:pencil" class="inline-icon" /> oder im Bereich „TM durchsuchen“ auf **Bearbeiten**. <Image src={editTmSuggestions} alt="TM-Vorschläge bearbeiten" />
  2. Nimm im geöffneten Dialog die erforderlichen Änderungen an den TM-Vorschlägen für jede Sprache des TM-Segments vor oder lösche sie.
  3. Um versehentliche Löschungen oder unerwünschte Änderungen rückgängig zu machen, klicke neben dem TM-Vorschlag auf **Rückgängig** oder auf **Abbrechen**, um alle Änderungen vor dem Speichern zu verwerfen.
  4. Wenn du die gewünschten Änderungen vorgenommen hast, klicke auf **Speichern**, um sie zu bestätigen und auf das TM-Segment anzuwenden.
</Steps>

Um ein TM-Segment vollständig aus dem Translation Memory zu löschen, entferne alle TM-Einträge in sämtlichen Sprachen und klicke auf **Speichern**.

### Terminologie

Unterstrichene Wörter oder Ausdrücke in Strings kennzeichnen projektspezifische Terminologie. Übersetze sie gemäß der bereitgestellten Begriffsbeschreibung. Ausführliche Erläuterungen kannst du dir anzeigen lassen, indem du den Mauszeiger über den unterstrichenen Text bewegst oder den Bereich „Terminologie“ aufrufst.

Im Bereich „Terminologie“ kannst du das Projektglossar durchsuchen (falls verfügbar) und nach bestimmten Begriffen suchen. Wenn ein Begriff nicht im Glossar enthalten ist, werden Erläuterungen aus Wikipedia als Referenz angezeigt.

Für einige Begriffe liegen bereits Übersetzungen vor, die zur einheitlichen Terminologie im gesamten Projekt beitragen. Um einen übersetzten Begriff wiederzuverwenden, klicke auf den unterstrichenen Text. Die Übersetzung wird automatisch im Übersetzungsfeld angezeigt. Alternativ kannst du den Mauszeiger über den unterstrichenen Text bewegen, dann über die benötigte Übersetzung des Begriffs in der Karte und auf **Einfügen** klicken. Verwende dies, wenn der Begriff mehrere Übersetzungen hat und du eine bestimmte davon auswählen möchtest.

Wenn der Begriff noch keine Übersetzung hat, öffnet ein Klick auf den unterstrichenen Text das Dialogfeld **Konzept bearbeiten** für Projektmitglieder, die das Glossar verwalten. Für andere Projektmitglieder wird der Abschnitt Terminologie geöffnet.

Jeder Begriff wird als Karte angezeigt. Eine eingeklappte Karte zeigt den Begriff, sein Thema und seine Übersetzungen mit ihren Status an. Klicke auf die Karte oder <Icon name="mdi:chevron-down" class="inline-icon" />, um sie zu erweitern. Eine aufgeklappte Karte zeigt außerdem die Konzeptdefinition, eine Notiz, ein Bild, einen Referenzlink und alle benutzerdefinierten [Felder](/enterprise/fields/). Für jeden Begriff werden Sprache, Wortart, Typ, Genus und Status sowie gegebenenfalls eine Beschreibung, eine Notiz, ein Referenzlink und benutzerdefinierte Felder angezeigt.

Um alle Karten gleichzeitig zu erweitern oder zu reduzieren, klicke oberhalb der Liste auf <Icon name="mdi:unfold-more-horizontal" class="inline-icon" />. Diese Einstellung gilt für den gesamten Abschnitt und wird gespeichert, sodass sie beim nächsten Öffnen des Editors wieder angewendet wird.

Am unteren Rand der Karte wird das Glossar angezeigt, aus dem der Begriff stammt. Projektmitglieder, die dieses Glossar verwalten, können auf den Namen klicken, um die Glossarbegriffe zu öffnen.

Projektmitglieder mit Zugriff auf das Projektglossar können die Terminologie direkt in diesem Abschnitt verwalten. Klicke neben dem Suchfeld auf <Icon name="mdi:playlist-plus" class="inline-icon" />, um ein Konzept hinzuzufügen. Um einen Begriff zu bearbeiten, bewege den Mauszeiger über seine Karte und klicke auf <Icon name="mdi:pencil" class="inline-icon" />, um das Dialogfeld **Konzept bearbeiten** zu öffnen.

## Editormodi

Der Editor bietet verschiedene Ansichtsmodi für unterschiedliche Übersetzungsabläufe. Zu den verfügbaren Modi gehören **Side-by-Side**, **Komfortmodus**, **Mehrsprachig** und **Mehrsprachig (Raster)**. Jeder Modus bietet ein eigenes Layout zum Anzeigen und Verwalten von Übersetzungen. Standardmäßig ist der Modus **Side-by-Side** aktiviert, du kannst aber jederzeit zu einem anderen Modus wechseln.

Du kannst folgendermaßen zwischen den Editormodi wechseln:

* **Über das Menü „Ansicht“** &ndash; Öffne im Hauptmenü den Eintrag **Ansicht** und wähle den gewünschten Modus.
* **Über das Symbol „Editoransicht“** &ndash; Klicke oben rechts auf das Symbol **Editoransicht** und wähle den gewünschten Modus aus. Das Symbol ist nur verfügbar, wenn das **Horizontale Menü** in den [Editor-Einstellungen](#appearance) deaktiviert ist.

### Side-by-Side-Modus

Der im Abschnitt [Kernfunktionen](#core-features) beschriebene Side-by-Side-Modus eignet sich ideal, um mehrere Übersetzungen gleichzeitig zu verwalten. Übersetzer können mehrere Strings gleichzeitig bearbeiten oder vorhandene Übersetzungen schnell überprüfen und bewerten. Manager und Korrekturleser können in derselben Ansicht effizient die besten Übersetzungen freigeben.

### Komfortmodus

Im Komfortmodus können sich Übersetzer und Korrekturleser auf jeweils einen String konzentrieren und so präzise und ohne Ablenkungen arbeiten. Der aktive String wird besonders hervorgehoben, sodass du den Kontext und zugehörige Ressourcen leichter prüfen kannst. Dieser Modus eignet sich besonders für komplexe Übersetzungen und ausführliches Korrekturlesen, bei denen Genauigkeit und Sorgfalt entscheidend sind.

Der zentrale Arbeitsbereich zeigt oben den Quell-String und darunter den Übersetzungsbereich. Um eine Übersetzung hinzuzufügen, wähle links einen String aus. Er wird dann oben in der Mitte im Feld *Quell-String* angezeigt.

<Image src={comfortable} alt="Komfortmodus des Editors" />

### Mehrsprachiger Modus

Der mehrsprachige Modus bietet ähnliche Funktionen wie der Side-by-Side-Modus und ermöglicht Übersetzern und Korrekturlesern, gleichzeitig mit mehreren Sprachen zu arbeiten. Du kannst beliebig viele Sprachen auswählen, mit denen du gleichzeitig arbeiten möchtest – bis hin zu allen Sprachen deines Projekts. Im rechten Bereich werden die Übersetzungen des Strings in der Sprache angezeigt, für die du gerade eine Übersetzung eingibst, oder in der zuletzt ausgewählten Sprache. Zusätzlich zeigt der Editor in diesem Modus 50 Strings pro Seite an, damit du mit weniger Seitenwechseln mehr Kontext erhältst.

<Image src={multilingualMode} alt="Mehrsprachiger Modus" />

Wechsle zum mehrsprachigen Modus, wähle die gewünschten Sprachen aus und klicke auf **Anwenden**. Um schnell alle Projektsprachen mit einem einzigen Klick auszuwählen, verwende die Schaltfläche **Alle auswählen**. Um neue Sprachen hinzuzufügen oder zuvor ausgewählte zu entfernen, gehe im Hauptmenü zu **Sprache**, nimm die erforderlichen Änderungen an der Sprachenliste vor und klicke auf **Übernehmen**. Du kannst auch die Schaltfläche **Auswahl aufheben** verwenden, um vor einer neuen Auswahl schnell die Auswahl aller Sprachen aufzuheben.

### Mehrsprachiger Modus (Raster)

Zusätzlich zum mehrsprachigen Modus gibt es einen separaten Modus „Mehrsprachig (Raster)“. Er bietet ein tabellenähnliches Layout, in dem jede Sprache in einer eigenen Spalte angezeigt wird. So kannst du kompakt und übersichtlich mit mehreren Sprachen arbeiten. Wie im normalen Modus **Mehrsprachig** unterstützt dieser eine unbegrenzte Anzahl von Sprachen gleichzeitig und zeigt 50 Strings pro Seite an.

Um die Reihenfolge und Sichtbarkeit der Spalten anzupassen oder bestimmte Spalten anzuheften, klicke oben rechts auf **Spalten sortieren** und wähle die gewünschten Spalten aus. Du kannst das Layout auch auf die Standardspalten zurücksetzen, indem du unten in der Liste **Auf Standard zurücksetzen** auswählst.

Um einzelne Spalten anzuheften oder auszublenden, bewege den Mauszeiger über eine Spaltenüberschrift, sodass ein Dropdown-Pfeil angezeigt wird. Klicke auf den Pfeil und wähle entweder **Spalte anheften** oder **Spalte ausblenden**.

Mit den folgenden Funktionen kannst du das Rasterlayout anpassen und effizienter mit den Zellen arbeiten:

* **Zeilengrößen** &ndash; Wechsle mit den Schaltflächen oben rechts die Tabellendichte zwischen <Icon name="material-symbols:table-rows-outline" class="inline-icon" /> **Kompakt**, <Icon name="mdi:view-stream-outline" class="inline-icon" /> **Mittel** und <Icon name="material-symbols:square-outline-rounded" class="inline-icon" /> **Groß**. So findest du die für dich angenehmste Anzeigedichte.
* **Inline-Aktionsschaltflächen** &ndash; Wenn du den Mauszeiger über eine Übersetzungszelle bewegst, erscheint direkt darin ein Mini-Panel mit Schnellaktionen: **Speichern**, **Abbrechen**, **Genehmigen** und **Quelltext kopieren**. So kannst du Übersetzungen effizient verwalten, ohne den Cursor in den rechten Bereich bewegen zu müssen.
* **Inline-Status und QA-Prüfungen** &ndash; String-Status und Ergebnisse der Qualitätssicherung (QA) werden direkt in jeder Zelle angezeigt. Wenn eine Übersetzung ein QA-Problem aufweist, wird dies durch einen <Badge text="QA" variant="danger" />-Hinweis neben dem Text deutlich hervorgehoben, sodass du sofort eine visuelle Rückmeldung erhältst.

<Image src={multilingualModeGrid} alt="Rasteransicht im mehrsprachigen Modus" />

#### Für Korrekturleser

Der Korrekturprozess funktioniert weitgehend wie im Side-by-Side-Modus. Beim gleichzeitigen Genehmigen oder Aufheben der Genehmigung mehrerer Strings führt das System die Aktion jedoch für alle Sprachen aus, die für den Mehrsprachig-Modus ausgewählt sind.

#### Filter im mehrsprachigen Modus verwenden

Wenn du im mehrsprachigen Modus Filteroptionen verwendest, zeigt das System Strings an, die die ausgewählten Kriterien in mindestens einer der ausgewählten Sprachen erfüllen. Filter, die von Übersetzungen abhängen, werden verfügbar, sobald du mindestens eine Zielsprache ausgewählt hast.

Dieses Verhalten gilt für folgende Filteroptionen:

* Nicht übersetzt
* Nicht freigegeben
* Freigegeben
* QA-Probleme
* Automatisch übersetzt
* Erweiterter Filter > Übersetzungen > Übersetzungen aktualisiert
* Erweiterter Filter > Strings > Übersetzungsstatus > Teilweise übersetzt (Pluralformen)
* Erweiterter Filter > Übersetzungen > Bedingungen > Übersetzung entspricht Quelltext
* Erweiterter Filter > Übersetzungen > Stimmen

## RTL-Sprachen übersetzen

Beim Übersetzen zwischen Sprachen mit Schreibrichtung von links nach rechts (LTR) und von rechts nach links (RTL) werden einige Elemente im Übersetzungsfeld des Editors möglicherweise anders angezeigt als in der exportierten Datei.

Damit RTL-Übersetzungen in der exportierten Datei korrekt angezeigt werden, empfehlen wir folgende Vorgehensweise:

<Steps>

  2. Übersetze die Quelltexte in die Zielsprache.
  3. Lasse Variablen, Tags usw. in der Übersetzung unverändert, auch wenn sie falsch aussehen. In der exportierten Datei befinden sie sich dann an den richtigen Positionen.
</Steps>

<Image src={rtlLanguages} alt="Vorschlag für eine RTL-Sprache speichern" />

## Editor-Einstellungen

Um die Editor-Einstellungen zu öffnen, klicke oben rechts auf <Icon name="mdi:cog" class="inline-icon" />.

Die Editor-Einstellungen sind in Tabs unterteilt, die verschiedene Optionen zur individuellen Konfiguration des Editors enthalten.

### Allgemein

* *Vorschläge aus dem Translation Memory* &ndash; Lege die minimale Ähnlichkeit (in Prozent) für Translation-Memory-Vorschläge fest, die unter dem Übersetzungsfeld angezeigt werden.
* *Übersetzungsabgleich* &ndash; Wenn aktiviert, werden Quellwörter, für die bereits Übersetzungen im Projekt vorhanden sind, mit einer gestrichelten Linie unterstrichen. Bewege den Mauszeiger über ein unterstrichenes Wort, um dessen vorherige Übersetzungen und die jeweilige Verwendungshäufigkeit anzuzeigen. Weitere Informationen findest du unter [Übersetzungskonsistenz](/enterprise/translation-consistency/).
* *Automatische Vervollständigung* &ndash; Wenn diese Option aktiviert ist, wird während der Eingabe ein Pop-up mit Übersetzungsvorschlägen und automatischer Vervollständigung angezeigt.
* *QA-Probleme* &ndash; Wenn aktiviert, werden jedes Mal Inline-Banner mit Warnungen angezeigt, wenn du eine Übersetzung mit Ungenauigkeiten speichern willst (Abweichungen bei Zeichensetzung/Tags/Leerzeichen, fehlende Variablen usw.).
* *Rechtschreibprüfung in Echtzeit* &ndash; Zeigt Rechtschreibprobleme sofort während der Eingabe einer Übersetzung an. Wenn neben der Übersetzung <Icon name="mdi:spellcheck" class="inline-icon" /> angezeigt wird, wurden keine Rechtschreibfehler gefunden. Andernfalls siehst du ein rotes Label mit der Anzahl der gefundenen Rechtschreibfehler. Klicke darauf, um weitere Details anzuzeigen, oder klicke auf ein unterstrichenes Wort, um nur für dieses Wort Vorschläge zu sehen. Die integrierte Rechtschreibprüfung hat Vorrang vor Browsererweiterungen (z. B. Grammarly oder LanguageTool). Wenn du lieber ein Drittanbieter-Tool verwenden möchtest, deaktiviere diese Option und lade die Seite neu.
* *Automatische Freigabe* &ndash; Wenn diese Option aktiviert ist, werden Übersetzungen, die von Korrekturlesern oder Mitgliedern mit höheren Berechtigungen hinzugefügt wurden, automatisch freigegeben.
* *Automatisch zum nächsten String wechseln* &ndash; Wenn diese Option aktiviert ist, springst du nach dem Speichern einer neuen Übersetzung oder dem Freigeben einer vorhandenen Übersetzung automatisch zum nächsten String.
* *Übersetzungen automatisch speichern* &ndash; Wenn aktiviert, werden deine Übersetzungen automatisch gespeichert, wenn du zwischen Strings wechselst.

### Darstellung

* *Standardansicht des Editors* &ndash; Lege fest, welche Ansicht beim Öffnen des Editors standardmäßig verwendet wird.
* *Kompakte String-Ansicht* &ndash; Wenn diese Option aktiviert ist, werden in der String-Liste nur die Anfänge längerer Strings angezeigt.
* *Übersetzungsvorschau* &ndash; Wenn diese Option aktiviert ist, wird für übersetzte Strings in der String-Liste eine Übersetzungsvorschau angezeigt.
* *Horizontales Menü* &ndash; Wenn diese Option aktiviert ist, wird das Hauptmenü oben im Editor horizontal angezeigt. Dieses Layout ist standardmäßig aktiviert. Wenn die Option deaktiviert ist, wird das Hauptmenü unter dem Symbol <Icon name="mdi:menu" class="inline-icon" /> oben links eingeklappt.
* *HTML-Tags anzeigen* &ndash; Du kannst zwischen **Anzeigen** und **Ausblenden** wählen. Die Einstellung gilt für alle HTML-Tags. Wenn du **Automatisch** auswählst, werden Tags in HTML-, Haml-, XML-, Web-XML-, Markdown- und DOCX-Dateien ausgeblendet, in anderen Dateiformaten jedoch angezeigt. Wenn Tags ausgeblendet sind, gilt Folgendes:
  ```
  <a href="https://sample.com">Sample</a>
  ```
  wird ersetzt durch
  ```
  <0>Sample</0>
  ```
* *Nicht druckbare Zeichen anzeigen* &ndash; Wenn diese Option aktiviert ist, werden nicht druckbare Zeichen (z. B. Leerzeichen, Tabulatoren und Zeilenumbrüche) angezeigt. Sie werden sowohl in Quelltexten als auch in Übersetzungen angezeigt.
* *Übersetzungsfeld hervorheben* &ndash; Wenn diese Option aktiviert ist, werden Wörter mit möglichen QA-Problemen im Übersetzungsfeld unterstrichen.
* *Rechten Bereich anpassen* &ndash; Ermöglicht dir, das Layout des rechten Bereichs auf den Standardzustand zurückzusetzen. Anpassungen wie das [Anheften von Bereichen](#pinning-sections) oder das [Neuordnen von Bereichen](#customizing-right-panel-section-order) kannst du direkt im rechten Bereich vornehmen. Klicke auf **Auf Standard zurücksetzen**, um diese Änderungen rückgängig zu machen.
* *Sprache der Benutzeroberfläche* &ndash; Wähle deine bevorzugte Sprache für die Crowdin-Enterprise-Benutzeroberfläche aus. Die ausgewählte Sprache wird im Editor und in anderen Bereichen von Crowdin Enterprise verwendet.

### Tastenkombinationen

Mit Tastenkombinationen kannst du Aktionen im Editor schnell ausführen. Die meisten Tastenkombinationen lassen sich an deine persönlichen Vorlieben anpassen. Klicke auf die gewünschte Tastenkombination und ändere sie über deine Tastatur.

### Navigation und Schnellzugriff

Der Navigationspfad oben links im Editor zeigt deinen aktuellen Kontext im Arbeitsbereich an und ermöglicht den schnellen Zugriff auf Dateistatistiken, Aufgabeninformationen und die Projektnavigation. Das Verhalten hängt davon ab, ob das **Horizontale Menü** in deinen [Editor-Einstellungen](#appearance) aktiviert ist.

**Wenn das Horizontale Menü aktiviert ist (Standardeinstellung):**

Der Pfad zeigt visuell an, wo du dich befindest (Projektname, Zielsprache, Dateiname oder Workflow-Schritt – letzterer nur in [Projekten mit einem Workflow](/enterprise/creating-project/#projects-with-a-workflow)) und liefert beim Darüberfahren mit dem Mauszeiger weitere Informationen:

* **Dateidetails**: Wenn du den Mauszeiger über den Dateinamen bewegst, wird ein Popover mit dem Übersetzungs- und Genehmigungsfortschritt (Wortanzahl und Prozentangaben) für diese Datei und den Ordner, in dem sie sich befindet, geöffnet. Klicke im Popover auf den Dateinamen, um einen Link zur Datei zu kopieren, oder auf den Ordner, um den vollständigen Dateipfad zu kopieren.
* **Aufgabendetails**: Wenn du eine Aufgabe im Editor öffnest, wird der Aufgabentitel zusammen mit dem entsprechenden Symbol für den Aufgabentyp im Pfad angezeigt. Wenn du den Mauszeiger über den Aufgabentitel bewegst, erscheint ein Popover mit weiteren Details. Dazu gehören ein direkt anklickbarer Link zur Aufgabe (wird in einem neuen Tab geöffnet), die Zielsprache und der Aufgabentyp.

**Wenn das Horizontale Menü deaktiviert ist:**

Du kannst auf einzelne Elemente im Navigationspfad klicken, um die jeweiligen Dropdown-Menüs zu öffnen:

* **Projekt**: Klicke auf den aktuellen Projektnamen, um auf die Optionen auf Projektebene zuzugreifen.
* **Sprache**: Klicke auf die aktuelle Sprache, um zu einer anderen Zielsprache zu wechseln.
* **Datei**: Klicke auf den aktuellen Dateinamen, um das Menü **Datei** zu öffnen.

### Kontextmenüoptionen für ausgewählte Wörter

* **Kopieren und einfügen**: Kopiere das ausgewählte Wort oder die ausgewählte Wortgruppe und füge sie sofort in das Übersetzungsfeld ein.

### Zwischen Dateien und Ordnern wechseln

Der Editor verfügt über einen integrierten Dateibrowser in einer einklappbaren linken Seitenleiste. Damit kannst du Dateien und Ordner durchsuchen und auswählen, ohne deinen Übersetzungsarbeitsbereich zu verlassen. Dadurch wird die Arbeit flüssiger und effizienter.

Wie du den Dateibrowser verwendest, hängt vom aktuellen Editormodus ab:

* **In den Modi Side-by-Side, Mehrsprachig und Mehrsprachig (Raster)** – Du kannst den Dateibrowser über das Symbol <Icon name="mdi:dock-left" class="inline-icon" /> oben rechts oder mit der Tastenkombination <KBD>Ctrl</KBD>+<KBD>[</KBD> ein- und ausblenden. Alternativ kannst du den Bereich über **Datei > Öffnen** im Hauptmenü oder mit <KBD>Ctrl</KBD>+<KBD>O</KBD> bzw. <KBD>Cmd</KBD>+<KBD>O</KBD> öffnen.
* **Im Komfortmodus** kann die linke Seitenleiste zwischen den Ansichten **Dateien** und **Strings** umgeschaltet werden. Wenn du in der Ansicht **Dateien** ein Element auswählst, wird die Ansicht **Strings** automatisch aktualisiert und zeigt die zugehörigen Inhalte an.

Am unteren Rand des Dateibrowsers siehst du den Pfad des ausgewählten Elements, z. B. `/app/src/main/res/values/strings.xml`. Wenn mehrere Elemente ausgewählt sind, wird stattdessen dort eine Zusammenfassung deiner Auswahl angezeigt, z. B. `3 Dateien ausgewählt`. Projektmitglieder mit Managerberechtigungen können auch ausgeblendete Dateien im Dateibaum ein- oder ausblenden (falls vorhanden), indem sie in der Symbolleiste des Dateibrowsers auf das Symbol <Icon name="mdi:eye-off-outline" class="inline-icon" /> **Ausgeblendete Dateien** klicken.

<Aside type="tip">
  Du kannst mehrere Dateien und Ordner mithilfe der üblichen Tastenkombinationen auswählen:
  * Um einen zusammenhängenden Bereich auszuwählen, klicke auf das erste Element, halte <KBD>Shift</KBD> gedrückt und klicke dann auf das letzte Element.
  * Um mehrere einzelne Elemente auszuwählen oder die Auswahl aufzuheben, halte <KBD>Ctrl</KBD> oder <KBD>Cmd</KBD> gedrückt und klicke auf die gewünschten Dateien oder Ordner.
</Aside>

Um mit einem Element zu arbeiten, ohne es zu öffnen, klicke im Dateibrowser mit der rechten Maustaste darauf. Wenn das Element, auf das du mit der rechten Maustaste klickst, Teil deiner Auswahl ist, wird die Aktion auf alle ausgewählten Elemente angewendet. Je nach Element und deinen Berechtigungen bietet das Menü folgende Optionen:

* **In neuem Tab öffnen**: Öffne das Element in einem neuen Browser-Tab. Mehrere ausgewählte Elemente werden gemeinsam in einem Tab geöffnet.
* **Kopieren**: Öffne ein Untermenü mit Optionen zum Kopieren des Pfads, Namens oder Links des Elements.
* **Quelltextvorschau** und **Vorschau der übersetzten Datei**: Öffne die Datei in einer [Dateivorschau](#source-and-translated-file-preview).
* **Herunterladen**: Lade die Datei im ursprünglichen Format herunter.
* **Als XLIFF exportieren**: Lade das Element als XLIFF-Datei herunter. Ein Ordner, ein Branch oder mehrere ausgewählte Elemente werden in eine einzelne XLIFF-Datei exportiert.
* **Gefilterte Ergebnisse als XLIFF exportieren**: Lade nur die Zeichenfolgen, die den aktuellen Filtern und der Suche entsprechen, als XLIFF-Datei herunter.
* **Übersetzungen hochladen**: Lade eine Datei mit Übersetzungen für das Element hoch. Lade für einen Ordner, einen Branch oder mehrere ausgewählte Elemente eine XLIFF-Datei hoch.

<Image src={fileBrowser} alt="Dateibrowser im Editor" />

Um den Pfad der im Editor geöffneten Datei zu kopieren, wähle im Hauptmenü **Datei > Dateipfad kopieren** (bei Projekten auf Zeichenfolgenbasis **Branch > Branch-Pfad kopieren**). Wenn **Alle Zeichenfolgen** oder mehrere Dateien geöffnet sind, wird der Pfad der Datei kopiert, die die ausgewählte Zeichenfolge enthält. Du kannst den Pfad oder einen Link zur geöffneten Datei auch mit den Befehlen **Dateipfad kopieren** und **Dateilink kopieren** in der [Befehlspalette](#command-palette) kopieren (bei Projekten auf Zeichenfolgenbasis mit **Branch-Pfad kopieren** und **Branch-Link kopieren**).

Um alle Strings im Projekt anzuzeigen, öffne den Dateibrowser und wähle oben in der Dateiliste **Alle Strings** aus.

Um eine Datei, an der du kürzlich gearbeitet hast, schnell zu finden und erneut zu öffnen, gehe zu **Datei > Zuletzt verwendete Dateien** und wähle die gewünschte Datei aus.

### Vorschau von Quell- und übersetzten Dateien

Zusätzlich zur [WYSIWYG-Dateivorschau](#wysiwyg-file-preview), die Dateien so darstellt, wie sie gerendert aussehen würden, gibt es die Modi **Quelltextvorschau** und **Vorschau der übersetzten Datei**. Damit kannst du den Rohinhalt der Quell- und der übersetzten Datei direkt im Editor anzeigen. Diese Vorschauen geben Einblick in Struktur, Layout und Formatierung der Datei und helfen dabei, genaue Übersetzungen im richtigen Kontext sicherzustellen. Das ist besonders hilfreich, um Abweichungen oder Formatierungsprobleme zu erkennen, ohne den Editor verlassen zu müssen. Die **Vorschau der übersetzten Datei** ist für alle Benutzer verfügbar. Die **Quelltextvorschau** ist dagegen nur für Mitglieder mit Entwickler- oder Übersetzungsanfrage-Berechtigungen oder höher verfügbar.

Um eine Datei in einer dieser Ansichten zu öffnen, gehe im Hauptmenü zu **Datei** und wähle den gewünschten Vorschaumodus aus.

### Automatische Übersetzung im Editor

Mit der Funktion **Automatische Übersetzung** kannst du mehrere Strings direkt im Editor mithilfe von KI, Translation Memory (TM) oder maschineller Übersetzung (MT) übersetzen. Damit hast du genaue Kontrolle über den Vorgang: Mit dem erweiterten Filter kannst du bestimmte Strings auswählen, deine Auswahl visuell überprüfen und die automatische Übersetzung gezielt auf diese Gruppe anwenden.

So verwendest du die automatische Übersetzung im Editor:

<Steps>
  1. Du kannst den Dialog für die automatische Übersetzung im Editor auf zwei Arten öffnen:
     * **Hauptmenü** – Öffne im Hauptmenü den Eintrag **Bearbeiten** und wähle **Automatisch übersetzen**.
     * **String-Menü** (verfügbar im **Side-by-Side**- und **Mehrsprachig**-Modus) – Klicke oben rechts auf <Icon name="mdi:dots-vertical" class="inline-icon" /> und wähle **Automatisch übersetzen**.
  2. Konfiguriere im Dialog **Strings automatisch übersetzen** die folgenden Parameter:
     * **Automatische Übersetzung über** – Wähle die gewünschte Methode (**KI**, **Translation Memory** oder **maschinelle Übersetzung**).
     * **KI-Prompt** (nur bei automatischer Übersetzung mit KI) – Wähle den Prompt aus, der das Verhalten des KI-Modells steuert.
     * **Benutzerdefinierte Anweisung (optional)** (nur bei automatischer Übersetzung mit KI) – Füge zusätzlichen Kontext oder konkrete Anweisungen hinzu, um die KI anzuleiten. Deine Eingabe wird zusammen mit dem ausgewählten Prompt verwendet.
     * **Übersetzungs-Engine** (nur bei automatischer Übersetzung mit maschineller Übersetzung) – Wähle die gewünschte Engine für die maschinelle Übersetzung aus.
     * **Benachrichtige mich, wenn die automatische Übersetzung abgeschlossen ist** – Du erhältst eine Benachrichtigung, wenn die automatische Übersetzung abgeschlossen ist, fehlschlägt oder abgebrochen wird. Die Benachrichtigung wird über die Kanäle übermittelt, die du in deinem [Benachrichtigungseinstellungen](/enterprise/account-settings/#notifications) für das Ereignis **„Automatische Übersetzung“** ausgewählt hast.
     * **Umfang** – Wähle aus, auf welche Strings die automatische Übersetzung angewendet werden soll:
       * **Ausgewählte Strings** (nur im **Side-by-Side**- und **Mehrsprachig**-Modus) – Wendet die Übersetzung nur auf Strings an, die du im Editor manuell ausgewählt hast.
       * **Gefilterte Strings** – Wendet die Übersetzung auf alle Strings an, die den aktuellen Filterkriterien entsprechen.
       * **Datei** (**Ausgewählte Dateien**, wenn mehrere Dateien geöffnet sind; **Branch** bei stringbasierten Projekten) – Wendet die Übersetzung auf die Datei, die Dateien oder den Branch an, der aktuell im Editor geöffnet ist.
       * **Alle Dateien** (**Alle Branches** bei stringbasierten Projekten) – Wendet die Übersetzung auf alle Strings des Projekts an, unabhängig davon, welche Datei oder welcher Branch im Editor geöffnet ist.
     * **Zu verarbeitende Strings** – Wähle **Nicht übersetzte Strings**, **Übersetzte Strings (neu übersetzen)** oder beide Optionen aus.
       <Aside>
                 Die folgenden Einstellungen für die Neuübersetzung werden nur angezeigt, wenn **Übersetzte Strings (neu übersetzen)** ausgewählt ist.
       </Aside>
     * **Wenn für diesen String bereits eine Übersetzung vorhanden ist** – Lege fest, wie vorhandene Übersetzungen behandelt werden sollen:
       * **Übersetzung zusätzlich zu vorhandenen Übersetzungen hinzufügen** (Standard)
       * **Automatisch generierte Übersetzungen ersetzen (menschliche Übersetzungen beibehalten)**
       * **Alle vorhandenen Übersetzungen ersetzen**
     * **Freigegebene Strings überspringen** – Verhindert, dass Strings überschrieben werden, für die bereits freigegebene Übersetzungen vorliegen.
     * **Doppelte Übersetzungen zulassen** – Fügt Übersetzungen auch dann hinzu, wenn sie bereits vorhandenen Übersetzungen entsprechen. Diese Option ist nützlich, wenn du KI-Prompts oder MT-Engines im Bericht [Genauigkeit der automatischen Übersetzung](/enterprise/project-reports/#auto-translation-accuracy) vergleichst.
     * **Freigabestatus zurücksetzen, damit Korrekturleser erneut prüfen können** – Entfernt den Freigabestatus aller ersetzten Übersetzungen, damit sie erneut überprüft und bestätigt werden können.
       <Aside title="Abhängigkeiten zwischen Einstellungen">
                 Bestimmte Auswahlen deaktivieren automatisch andere Optionen:
                 * **Alle vorhandenen Übersetzungen ersetzen** deaktiviert die Optionen **Doppelte Übersetzungen zulassen** und **Freigabestatus zurücksetzen, damit Korrekturleser erneut prüfen können**.
                 * **Freigegebene Strings überspringen** deaktiviert die Option **Freigabestatus zurücksetzen, damit Korrekturleser erneut prüfen können**.
       </Aside>
     * **Mindestübereinstimmung** (nur bei automatischer Übersetzung über Translation Memory) – Wähle **100 %** oder **Perfekt** als erforderliche Mindestübereinstimmung für TM-Treffer aus.
       <ReadMore>
                 Weitere Informationen findest du unter [TM-Übereinstimmungstypen](/enterprise/translation-memory/#tm-match-calculation).
       </ReadMore>
  3. Klappe den Bereich **Erweiterte Einstellungen** auf, um den Vorgang der automatischen Übersetzung genauer zu konfigurieren:
     * **Übersetzen aus** – Wähle die Sprache aus, die als Quelle für die automatische Übersetzung verwendet werden soll. Standardmäßig ist die Quellsprache des geöffneten Workflow-Schritts vorausgewählt (bei Projekten ohne Workflow die Quellsprache des Projekts). Du kannst jedoch jede andere Projektsprache auswählen. Dadurch erhältst du mehr Flexibilität und kannst die Übersetzungsqualität verbessern: Du kannst eine besser geeignete vorhandene Übersetzung verwenden (z. B. eine angepasste englische Version statt des japanischen Originals) oder direkt zwischen verwandten Sprachen übersetzen (z. B. aus dem Spanischen ins Portugiesische).
       <Aside>
                 Bei der automatischen Übersetzung mit KI wird zusätzlich der ursprüngliche Quelltext des Projekts als Kontext verwendet, um die Genauigkeit zu erhöhen.
       </Aside>
     * **Hinzugefügte Übersetzungen freigeben** (nur bei automatischer Übersetzung über Translation Memory) – Gibt die durch die automatische Übersetzung hinzugefügten Übersetzungen automatisch frei. Folgende Optionen stehen zur Verfügung:
       * **Bei perfekter Übereinstimmung** – Gibt nur Übersetzungen mit einer Übereinstimmung von 101 % frei.
       * **Bei perfekter Übereinstimmung (zuvor freigegeben)** – Gibt perfekte Übereinstimmungen nur dann frei, wenn sie bereits zuvor freigegeben wurden.
       * **Alle (automatisch ersetzte Vorschläge überspringen)** – Genehmige alles außer Übersetzungen, die durch die automatische Ersetzung verbessert wurden.
       * **Alle** – Gibt alle hinzugefügten Übersetzungen frei.
  4. Klicke auf **Automatisch übersetzen**.
</Steps>

Im Side-by-Side- und Komfortmodus wird die automatische Übersetzung auf die einzelne Sprache angewendet, die aktuell im Editor ausgewählt ist. Im mehrsprachigen Modus werden die Übersetzungen auf alle ausgewählten Sprachen angewendet, da du in diesem Modus mit mehreren Sprachen gleichzeitig arbeitest.

<ReadMore>
  Weitere Informationen findest du unter [Mehrsprachiger Modus](#multilingual-mode).
</ReadMore>

Verwende die Schaltfläche **Warteschlange** unten links im Dialog **Strings automatisch übersetzen**, um alle gestarteten Vorgänge der automatischen Übersetzung zu verfolgen und zu verwalten.

### Erweiterter Filter

Du kannst einen benutzerdefinierten Filter für Strings erstellen, indem du auf das Symbol **Strings filtern** <Icon name="mdi:filter-variant" class="inline-icon" /> neben dem Suchfeld klickst und **Erweiterter Filter** auswählst. Kombiniere mehrere Filterparameter und lege eine benutzerdefinierte Sortierreihenfolge fest, um bestimmte Strings schneller zu finden.

#### Filterparameter

Der Filterdialog gruppiert seine Parameter in die folgenden Abschnitte. Du kannst Parameter aus jedem dieser Abschnitte kombinieren, um deine Suche einzugrenzen:

##### Suche

Lege fest, wo die Suche angewendet wird und wonach sie sucht:

* **Suchen in**: Wähle aus, auf welchen Teil der Strings sich die Suche erstreckt. Zur Auswahl stehen *Alles*, *Strings*, *Kontext*, *Alle Übersetzungen*, *Endgültige Übersetzungen* und *Bezeichner (Schlüssel)*. <Aside>Im Schritt „Quelltextprüfung“ heißen *Alle Übersetzungen* und *Endgültige Übersetzungen* entsprechend *Alle Korrekturen* und *Endgültige Korrekturen*.</Aside>
* **Text**: Suche nach dem eingegebenen Text.
* [**Verbaler Ausdruck**](#verbal-expressions): Suche nach einem strukturellen Muster statt nach dem exakten Text. <Aside>**Text** und **Verbaler Ausdruck** schließen sich gegenseitig aus, daher enthält der Dialog jeweils nur eine Abfrage und zeigt an, welchen **Filter** diese ersetzen wird.</Aside>

##### Strings

Nach den Eigenschaften der Quellstrings filtern:

* **Strings hinzugefügt**: Filtere Strings, die innerhalb eines bestimmten Zeitraums in das Projekt importiert wurden.
* **Strings aktualisiert**: Filtere Quellstrings, die innerhalb eines bestimmten Zeitraums aktualisiert wurden.
* [**Labels: Alle einbeziehen / Labels: Beliebige einbeziehen**](#filtering-by-labels): Beziehe Strings ein, die alle oder beliebige der ausgewählten Labels enthalten.
* [**Labels: Alle ausschließen / Labels: Beliebige ausschließen**](#filtering-by-labels): Schließe Strings aus, die alle oder beliebige der ausgewählten Labels enthalten. <Aside>Diese Optionen werden nur angezeigt, wenn dein Projekt Labels verwendet.</Aside>
* **Duplikate**: Filtere Strings anhand ihres Duplikatstatus. Zu den Optionen gehören *Master-Strings*, *Nur Duplikate*, *Duplikate mit gemeinsamen Übersetzungen* und *Duplikate mit eigenen Übersetzungen*. <Aside>Diese Option wird nur angezeigt, wenn [**Duplikate von Strings**](/enterprise/project-settings/import/#duplicate-strings) so konfiguriert ist, dass Duplikate automatisch übersetzt werden. Gemeinsame Übersetzungen stammen vom Master-String, während eigene Übersetzungen direkt im Duplikat eingegeben werden.</Aside>
* **String-Typ**: Filtere nach String-Format. Zu den Optionen gehören *Einfacher String*, *Pluralformen* und *ICU*.
* **Übersetzungsstatus**: Filtere nach Übersetzungsstatus. Zur Auswahl stehen *Nicht übersetzt*, *Teilweise übersetzt (Pluralformen)* und *Übersetzt*.
* **Genehmigungsstatus**: Filtere Strings nach ihrem Genehmigungsstatus. Zur Auswahl stehen *Übersetzt, nicht genehmigt*, *Teilweise genehmigt (Pluralformen)* und *Genehmigt*.
* **Anzahl der Freigaben**: Filtert Strings nach der Anzahl ihrer Freigaben. Die Optionen lauten *Größer als* oder *Kleiner als* eine angegebene Zahl.
* **QA-Probleme**: Filtere Strings anhand von Qualitätssicherungsproblemen. Zur Auswahl stehen *Ohne QA-Prüfungen*, *QA-Prüfung läuft*, *Alle* Probleme oder eine bestimmte Prüfung (z. B. *Tags stimmen nicht überein*, *Rechtschreibfehler*, *Zeichensetzung stimmt nicht überein*). <Aside>Die verfügbaren Prüfungen hängen davon ab, welche QA-Prüfungen für das Projekt aktiviert sind.</Aside>
* **Kommentare**: Filtere Strings nach Kommentaren oder Problemen. Zu den Optionen gehören *Keine Kommentare*, *Kommentare vorhanden*, *Ungelöste Probleme*, *Probleme mit allgemeinen Fragen*, *Probleme aufgrund einer falschen aktuellen Übersetzung*, *Probleme wegen fehlender Kontextinformationen* und *Probleme aufgrund von Fehlern im Quell-String*.
* **Screenshots**: Filtere Strings, die *Screenshots* haben oder *keine Screenshots* haben.
* **Sichtbarkeit**: Filtere Strings danach, ob Übersetzer sie sehen können. Die Optionen sind *Sichtbar* oder *Ausgeblendet*. <Aside>Diese Option wird nur angezeigt, wenn du Zugriff auf ausgeblendete Strings hast.</Aside>

##### Übersetzungen

Filtere nach den Übersetzungen, die ein String bereits hat:

* **Geltungsbereich**: Lege fest, ob ein Filter zu jeder Übersetzung eines Strings oder nur zur endgültigen passt (der Übersetzung, die oben in der Übersetzungsliste angezeigt und beim Herunterladen verwendet wird). Zur Auswahl stehen *Alle Übersetzungen* und *Endgültige Übersetzungen*. Der Geltungsbereich gilt für **Engine**, **Übersetzungsmethode**, **Stimmen**, **Übersetzt von**, **Genehmigt von**, **Übersetzung entspricht Quelltext** und **Quelltext nach der Übersetzung geändert**. Die Option wird verfügbar, sobald du eine davon festlegst.
* **Übersetzungen aktualisiert**: Filtere Strings, bei denen innerhalb eines bestimmten Zeitraums Übersetzungen hinzugefügt oder aktualisiert wurden (einschließlich neuer Vorschläge, Genehmigungen oder Stimmen).
* **Engine**: Filtereinträge mit Übersetzungen, die mithilfe einer bestimmten Engine automatisch übersetzt wurden. Zu den Optionen gehören *Maschinelle Übersetzung (MT)*, *Translation Memory (TM)*, *KI* und *Beliebige Engine*.
* **Übersetzungsmethode**: Filtere Strings danach, ob eine automatische Übersetzung angewendet wurde. Zu den Optionen gehören *Automatische Übersetzung* und *Manuell*. Wenn *Manuell* ausgewählt ist, ist **Motor** nicht mehr verfügbar.
* **Stimmen**: Filtere Strings nach der Nettostimmenzahl. Die Optionen lauten *Größer als* oder *Kleiner als* eine angegebene Zahl.
* **Übersetzt von**: Filtere nach Strings, die von einem bestimmten Projektmitglied *übersetzt* bzw. *nicht übersetzt* wurden.
* **Genehmigt von**: Filtere nach Strings, die von einem bestimmten Projektmitglied *genehmigt* bzw. *nicht genehmigt* wurden.
* **Bedingungen**: Filtere Strings nach Bedingungen, die du miteinander und mit den Statusfiltern kombinieren kannst. Zur Auswahl stehen *Übersetzung entspricht Quelltext*, *Quelltext nach der Übersetzung geändert* und *Übersetzung nach der Genehmigung hinzugefügt*.

#### Verbale Ausdrücke

Der erweiterte Filter unterstützt auch verbale Ausdrücke, die Strings anhand struktureller Muster wie der Position von Variablen, der Formatierung oder der Zeichensetzung statt anhand des exakten Textes abgleichen.

Wähle in der Gruppe **Suche** **Verbaler Ausdruck** aus, gib das Muster ein und lege unter **Suchen in** fest, wo danach gesucht werden soll.

Das Suchfeld in der Editor-Symbolleiste funktioniert weiter, während ein verbaler Ausdruck aktiv ist; eine Suche dort ersetzt jedoch den Ausdruck.

<LinkCard title="Syntaxelemente für Ausdrücke" description="Erfahre anhand praktischer Beispiele, wie du verbale Ausdrücke erstellst und verwendest." href="/enterprise/expression-syntax-elements/" />

#### Nach Labels filtern

Um schnell nach einem einzelnen Label zu filtern, klicke auf ein beliebiges Label, das im Kontextbereich eines Strings angezeigt wird. Wenn du den Mauszeiger über ein Label bewegst, wird ein Tooltip mit dem Text `Nach Label filtern: {label-name}` angezeigt. Wenn du auf das Label klickst, wird sofort der **Erweiterte Filter** mit diesem Label und der Regel **Labels: Beliebige einbeziehen** angewendet. Alle anderen Filterparameter werden zurückgesetzt. Wenn du anschließend ein anderes Label anklickst, ersetzt es das vorherige im Filter.

Für komplexere Abfragen mit mehreren Labels kannst du Regeln zum Ein- oder Ausschließen von Strings festlegen:

* **Labels: Alle einbeziehen / Labels: Beliebige einbeziehen**: Wähle die Logik zum Einbeziehen von Labels aus und füge die Labels anschließend in das entsprechende Feld ein.
  * **Alle einbeziehen**: Zeigt nur Strings an, denen **alle** ausgewählten Labels zugewiesen sind (UND-Logik).
  * **Beliebige einbeziehen**: Zeigt Strings an, denen **mindestens eines** der ausgewählten Labels zugewiesen ist (ODER-Logik).
* **Labels: Alle ausschließen / Labels: Beliebige ausschließen**: Wähle die Logik zum Ausschließen von Labels aus und füge die Labels anschließend in das entsprechende Feld ein.
  * **Alle ausschließen**: Schließt nur Strings aus, denen **alle** ausgewählten Labels zugewiesen sind (UND-Logik).
  * **Beliebige ausschließen**: Schließt Strings aus, denen **mindestens eines** der ausgewählten Labels zugewiesen ist (ODER-Logik).

Kombiniere diese Regeln, um die gefilterten Ergebnisse einzugrenzen oder zu erweitern.

Hier sind einige Beispiele dafür, wie diese Logik in der Praxis funktioniert:

* Beispiel zum Einbeziehen – Um Strings zu finden, die sowohl mit `ui` als auch mit `button` gekennzeichnet sind, wähle **Labels: Alle einbeziehen** und füge beide Labels hinzu.
* Beispiel zum Ausschließen – Um alle Strings auszuschließen, die entweder mit `marketing` oder mit `deprecated` gekennzeichnet sind, wähle **Labels: Beliebige ausschließen** und füge beide Labels hinzu.

#### Sortieroptionen

Lege die Reihenfolge der gefilterten Strings fest:

* **Sortieren nach**: Ordne die gefilterten Strings nach einem ausgewählten Kriterium. Verfügbare Optionen:
  * *Ursprüngliche Sortierreihenfolge*
  * *Hinzugefügte Strings*
  * *Aktualisierte Übersetzungen*
  * *Zuletzt hinzugefügter Kommentar*
  * *Alphabetisch (Quelltext)*
  * *Alphabetisch (Bezeichner)*
  * *Länge*
  * *Stimmen*
* Du kannst die Sortierreihenfolge auch auf **Aufsteigend** oder **Absteigend** festlegen.

### KI-/CroQL-Filter

Mit dem KI-/CroQL-Filter kannst du Strings ähnlich wie mit dem erweiterten Filter filtern. Durch die Crowdin Query Language (CroQL) bietet er jedoch mehr Flexibilität.

#### CroQL mit KI generieren

Im Feld **CroQL mit KI generieren** kannst du Abfragen in Klartext eingeben, die anschließend mithilfe von KI in einen CroQL-Ausdruck umgewandelt werden. Achte darauf, deine Abfragen klar zu strukturieren, damit du möglichst gute Ergebnisse erhältst. Du kannst beispielsweise Folgendes eingeben: *Zeige Strings an, für die Übersetzungen des Benutzers "username" ins Ukrainische vorhanden sind.* Nachdem du deine Abfrage eingegeben hast, drücke <KBD>Enter</KBD>. Die KI erstellt daraufhin den entsprechenden CroQL-Ausdruck und trägt ihn in das Feld **CroQL-Ausdruck** ein. Alternativ kannst du direkt einen vorbereiteten CroQL-Ausdruck in das Feld **CroQL-Ausdruck** eingeben.

Klicke auf **Filtern**, um den festgelegten Filter auf die Strings im Editor anzuwenden, oder auf **Filter zurücksetzen**, um die aktuellen Filtereinstellungen zu löschen.

<ReadMore>
  Weitere Informationen findest du unter [Crowdin Query Language (CroQL)](/developer/croql/).
</ReadMore>

### Bereiche anheften

Im Side-by-Side- oder Mehrsprachig-Modus kannst du bestimmte Bereiche mit <Icon name="mdi:pin" class="inline-icon" /> anheften, damit sie sichtbar bleiben, während du durch andere Teile der Oberfläche navigierst. So kannst du schnell auf angeheftete Inhalte zugreifen, ohne wichtige Informationen aus dem Blick zu verlieren.

### Reihenfolge der Bereiche im rechten Panel anpassen

Um deinen Arbeitsbereich im Editor anzupassen, kannst du die Bereiche im rechten Panel (z. B. Kontext und Übersetzungen, Kommentare usw.) neu anordnen, indem du ihre Symbole ziehst.

Klicke auf das Symbol des Bereichs, den du verschieben möchtest, halte die Maustaste gedrückt, ziehe das Symbol an die neue Position und lasse die Maustaste los. Die neue Reihenfolge bleibt erhalten, während du im Editor weiterarbeitest.

## Aufgaben im Editor

Sobald einem Übersetzer oder Korrekturleser eine Aufgabe zugewiesen wurde, sind alle zugehörigen Aufgabendetails im Editor verfügbar.

Der Aufgabenname wird oben links im Navigationspfad angezeigt. Wenn du den Mauszeiger über den Aufgabennamen bewegst, wird ein Popover mit zusätzlichen Details angezeigt, darunter die Aufgaben-ID, ein direkter Link zur Aufgabe, der Aufgabenstatus, das Fälligkeitsdatum, die Zielsprache, der Aufgabentyp und die zugewiesene Person.

Filter und Suchvorgänge gelten jeweils nur für die aktuelle Aufgabe.

Bei der Arbeit an einer Aufgabe wird das Standardmenü **Datei** durch das Menü **Aufgabe** ersetzt. Du kannst es öffnen, indem du im Hauptmenü auf **Aufgabe** klickst. Je nach deinen Berechtigungen enthält es folgende Optionen:

* Optionen zur Navigation zu Dateien, Aufgaben und Zeichenfolgen: **Datei öffnen…** (**Branch öffnen…** bei Projekten auf Zeichenfolgenbasis), **Aufgabe öffnen…** und **Alle Zeichenfolgen**

* Optionen für den [Aufgabenstatus](#changing-task-status): **Zu erledigen**, **In Bearbeitung** und **Erledigt**
* Optionen zum Exportieren und Hochladen von Übersetzungen für die jeweilige Aufgabe: **Als XLIFF exportieren**, **Gefilterte Ergebnisse als XLIFF exportieren** und **Übersetzungen hochladen…**
* **Zeichenfolgen des Projekts**: Verlasse die Aufgabe und zeige alle Zeichenfolgen des Projekts an. Wenn nur eine Datei geöffnet ist, heißt die Option **Zeichenfolgen der Datei** und zeigt alle Zeichenfolgen dieser Datei an. Bei Projekten auf Zeichenfolgenbasis heißt die Option **Zeichenfolgen des Branches** und zeigt alle Zeichenfolgen des Branches an.
* **Editor schließen**: Schließe den Editor und wechsle zum Bereich **Aufgaben** des Projekts.

### Aufgabenstatus ändern

Um den Status der Aufgabe zu ändern, an der du gerade arbeitest, öffne das Menü **Aufgabe** und wähle unter **Status** die Option **Zu erledigen**, **In Bearbeitung** oder **Erledigt**. Dieselben Optionen sind auch in der [Befehlspalette](#command-palette) verfügbar, z. B. **Aufgabenstatus festlegen: Erledigt**.

Die Optionen unter **Status** werden für Aufgaben vom Typ **Von eigenen Übersetzern übersetzen lassen** und **Von eigenen Korrekturlesern Korrektur lesen lassen** angezeigt, wenn sie den Status „Zu erledigen“, „In Bearbeitung“ oder „Erledigt“ haben. Sie stehen denselben Mitgliedern zur Verfügung, die den Aufgabenstatus im Bereich **Aufgaben** des Projekts ändern können. Bei geschlossenen Aufgaben werden die Optionen unter **Status** nicht angezeigt. Um den Status einer geschlossenen Aufgabe zu ändern, [öffne sie erneut](/enterprise/tasks/#closing-task) im Bereich **Aufgaben**.

### Zwischen Aufgaben wechseln

Um eine andere Aufgabe im selben Projekt zu öffnen, wähle im Hauptmenü **Aufgabe > Aufgabe öffnen…**. Wenn du gerade an keiner Aufgabe arbeitest, findest du diese Option im Menü **Datei** (bei Projekten auf Zeichenfolgenbasis im Menü **Branch**). Alternativ kannst du <span class="whitespace-nowrap"><KBD>Ctrl</KBD>+<KBD>Shift</KBD>+<KBD>O</KBD></span> oder <span class="whitespace-nowrap"><KBD>Shift</KBD>+<KBD>⌘</KBD>+<KBD>O</KBD></span> drücken oder in der [Befehlspalette](#command-palette) **Aufgabe öffnen…** auswählen.

Im Dialog **Aufgabe öffnen** werden die aktiven Aufgaben des aktuellen Projekts aufgeführt (**Zu erledigen** und **In Bearbeitung**). Organisationsadministratoren, der Projekteigentümer und Manager des Projekts oder der zugehörigen Gruppe sehen alle Aufgaben. Andere Mitglieder sehen nur die ihnen zugewiesenen Aufgaben. Du kannst die Liste nach Aufgaben-ID, Titel oder Beschreibung durchsuchen. Wähle eine Aufgabe aus, um sie im Editor zu öffnen. Um zum Bereich **Aufgaben** des Projekts zu wechseln, klicke unten im Dialogfeld auf **Alle Aufgaben**. Der Bereich **Aufgaben** wird in einem neuen Tab geöffnet.
