Du kannst view alle die Projekt's Strings und verwalten Strings Einstellungen via **Sources > Strings**.

## Sichtbarkeit von Zeichenketten ändern

Wenn einige Zeichenketten Daten enthalten, die nicht übersetzt werden sollen (z. B. Platzhalter oder andere technische Entitäten), kannst du diese vor Übersetzern verbergen. Dafür:

<Steps>
  1. Wechsle zum Tab **Add-ons**.
  2. Wähle die notwendig Strings von clicking die checkbox nächste zu jedes eins.
  3. Klicke auf <Icon name="mdi:eye-off" class="inline-icon" />.
</Steps>

<Image src={stringHide} alt="Zeichenketten ausblenden" />

## Filtering Zeichenfolgen

von Standard, alle Quellstrings von die Projekt sind angezeigt in **Sources > Strings**. Wenn notwendig, du kann filter out Strings verwenden die verfügbar filter Optionen (Probleme: alle, mit unresolved Probleme, ohne unresolved Probleme; Comments: alle, mit comments, ohne comments; Screenshots: alle, mit screenshots, ohne screenshots; Visibility: alle, sichtbar nur und ausgeblendet nur) und Projekt Bezeichnungen.

<Image src={stringFilter} alt="Filtering Zeichenfolgen" />

## Zeichenketten hinzufügen

Du kannst hinzufügen Strings zu dein Projekte direkt in Crowdin Enterprise.

Um... hinzuzufügen ein neu String, folgen diese Schritten:

<Tabs syncKey="projectType">
  <TabItem label="Dateibasiertes Projekt">
    <Steps>
      1. Wechsle zum Tab **Add-ons**.
      2. Klicke auf **hinzufügen String**.
      3. Gib im angezeigten Dialog die erforderlichen Angaben für die Zeichenkette ein:
         * Füge unter **Einstellungen** den folgenden Ausschnitt ein.
         * Nach erfolgreicher Authentifizierung deiner Anmeldedaten wirst du automatisch zu Crowdin Enterprise weitergeleitet.
         * *Identifier* &ndash; gib einen eindeutigen Schlüssel für die Zeichenkette an, der häufig verwendet wird, um im Anwendungscode auf den übersetzten Text zu verweisen.
         * *(Optional)* *Kontext* &ndash; hinzufügen zusätzliche information zu help Übersetzer verstehen die intended meaning.
         * Erstellt von &ndash; der Benutzer, der die Aufgabe erstellt hat.
         * Erstellt &ndash; der Zeitpunkt, zu dem die Aufgabe erstellt wurde.
         * *(Optional)* File-bestimmten identifiers &ndash; specify unique keys für jedes Datei Format wenn adding die String zu multiple Dateien. So wird sichergestellt, dass die Zeichenkette die unterschiedlichen Anforderungen an Identifier erfüllt, die vom jeweiligen Dateiformat abhängen, in dem sie verwendet wird.
         * *Files* &ndash; auswählen die Quelldateien wo dies String sollte sein hinzugefügt.
      4. Klicke auf **hinzufügen** zu hinzufügen die neu String zu dein Projekt.
    </Steps>
    <Aside>
      für dateibasiert Projekte, dies feature ist nur verfügbar für Dateiformate das Support [online editing](#formats-that-support-online-editing).
    </Aside>
  </TabItem>
  <TabItem label="Zeichenfolgenbasiertes Projekt">
    <Steps>
      1. Öffne dein Projekt und go zu die **Strings** Tab.
      2. Klicke auf **hinzufügen String**.
      3. Gib im angezeigten Dialog die erforderlichen Angaben für die Zeichenkette ein:
         * *Branches* &ndash; auswählen die Branches wo dies String sollte sein hinzugefügt.
         * Füge unter **Einstellungen** den folgenden Ausschnitt ein. Du kannst leave dies Feld empty zu Erstelle Platzhalter Strings für future Inhalt oder Entwicklung purposes.
         * Nach erfolgreicher Authentifizierung deiner Anmeldedaten wirst du automatisch zu Crowdin Enterprise weitergeleitet.
         * *Identifier* &ndash; gib einen eindeutigen Schlüssel für die Zeichenkette an, der häufig verwendet wird, um im Anwendungscode auf den übersetzten Text zu verweisen.
         * *(Optional)* *Kontext* &ndash; hinzufügen zusätzliche information zu help Übersetzer verstehen die intended meaning.
         * Erstellt von &ndash; der Benutzer, der die Aufgabe erstellt hat.
         * Erstellt &ndash; der Zeitpunkt, zu dem die Aufgabe erstellt wurde.
         * *(Optional)* File-bestimmten identifiers &ndash; specify unique keys für jedes Branch wenn adding die String zu multiple Branches. So wird sichergestellt, dass die Zeichenkette die unterschiedlichen Anforderungen an Identifier erfüllt, die vom jeweiligen Dateiformat abhängen, in dem sie verwendet wird.
      4. Klicke auf **hinzufügen** zu hinzufügen die neu String zu dein Projekt.
    </Steps>
  </TabItem>
</Tabs>

## Bearbeiten von Zeichenketten

Du kannst hinzufügen Kontext zu die String, hinzufügen oder entfernen Bezeichnungen, festlegen die max. length von die Übersetzung. Sobald die Übersetzung limits sind exceeded, die System notifies die contributor das die Übersetzung sollte sein shorter.

<Image src={stringEdit} alt="Zeichenketten bearbeiten" class="width-lg crowdin-modal" />

<LinkCard title="Kontextanreicherung mit KI-Agenten" description="Verwende Crowdin Skills und Crowdin CLI, damit dein KI-Coding-Agent den Zeichenfolgenkontext direkt aus deiner Codebasis schreibt." href="https://store.crowdin.com/context-enrichment" target="_blank" />

Um edit einige particular word oder phrase das erscheint in multiple Quellstrings, du kann verwenden die <Icon name="mdi:find-replace" class="inline-icon" /> **Find und replace** feature in **Sources > Strings**.

<Aside type="caution">
  Wenn editing die identifier von ein String enthalten in ein Gruppe von Strings (String array für Android XML, segments für XLIFF), die vorhanden Übersetzungen wird sein entfernt für alle Gruppe Strings aber die edited eins.
</Aside>

### Labels

Verwende Bezeichnungen in dein Projekt für ein easy way zu hinzufügen Kontext zu die Strings oder organisieren ihnen von certain topics. Bezeichnungen sind auch nützlich während Erstellen Übersetzung und proofreading tasks oder searching für bestimmten Strings in die Editor mit die help von [erweitert Filter](/enterprise/online-editor/#advanced-filter).

<LinkCard title="Projektlabels verwalten" description="Erfahre, wie du machen dein Crowdin Projekt Bezeichnungen." href="/enterprise/project-settings/labels/" />

Es gibt ein wenige possible ways du kann hinzufügen Bezeichnungen zu die Strings.

##### Füge Bezeichnungen zu eins String at ein time via die *Edit String* Dialog hinzu

<Steps>
  1. Right-klicken auf die String in die Liste und auswählen **Edit**.
  2. Wähle benötigt Bezeichnungen in die *Bezeichnungen* Feld.
  3. Klicke auf **Speichern**. <Image src={labelsAddingToOneString} alt="Adding Labels" class="width-lg crowdin-modal" />
</Steps>

##### Füge Bezeichnungen zu multiple Strings via die *verwalten Strings Bezeichnungen* Dialog hinzu

<Steps>
  1. Wähle ein wenige Strings du möchten zu hinzufügen die gleich Bezeichnungen zu.
  2. Klicke auf <Icon name="mdi:label" class="inline-icon" />.
  3. Wähle benötigt Bezeichnungen von die Liste.
  4. Klicke auf **Apply**. <Image src={labelsAddingToMultipleStrings} alt="Adding Labels" />
</Steps>

##### Füge Bezeichnungen zu die Quellstrings in CSV und XLSX Dateien verwenden ein dedicated column für Bezeichnungen hinzu

<ReadMore>
  Mehr über [Konfiguration Columns für importieren](/enterprise/csv-xlsx-configuration/#columns-configuration).
</ReadMore>

<Aside>
  String Bezeichnungen hinzugefügt zu die Projekt mit ein initial CSV/XLSX Datei hochladen won't sein overwritten oder entfernt mit subsequent Datei updates.
</Aside>
