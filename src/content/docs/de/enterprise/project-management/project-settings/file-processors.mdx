Mit Dateiverarbeitungen kannst du die Verarbeitung unterstützter Dateiformate anpassen. Das ist hilfreich, wenn du den Dateiinhalt bearbeiten möchtest, bevor Crowdin Enterprise ihn importiert.

Dateiverarbeitungen werden als Crowdin-Apps bereitgestellt. Du kannst eigene Dateiverarbeitungen erstellen oder vorhandene verwenden.

## Dateiverarbeitungen verwalten

Um Dateiverarbeitungen zu verwalten, öffne in deinen Projekteinstellungen den Bereich **Dateiverarbeitungen**.

### Verarbeitungsreihenfolge festlegen

Die Verarbeitungsreihenfolge bestimmt, in welcher Reihenfolge Module desselben Typs in deinem Projekt ausgeführt werden. Der Reihenfolgewert legt die Priorität fest: 0 steht für die höchste Priorität; danach steigt der Wert schrittweise an. Die von dir festgelegte Reihenfolge kann das Ergebnis erheblich beeinflussen.

Wenn du beispielsweise eine CSV-Datei übersetzt und zwei Apps mit `file-post-export`-Modulen installiert hast:

* Das erste Modul maskiert HTML-Tags in Zeichenfolgen und wandelt beispielsweise `</h1>` in `\<\/h1\>` um.
* Das zweite Modul prüft, ob alle schließenden Tags vorhanden sind, und ergänzt fehlende Tags.

Je nach Reihenfolge der Module ergeben sich unterschiedliche Ergebnisse:

* Wenn zuerst das Modul zum Maskieren von HTML-Tags und anschließend das Modul zur Überprüfung der Tags ausgeführt wird, kann die Ausgabe so aussehen:
  * `<h1>Hello World!` => `\<h1\>Hello World!` => `\<h1\>Hello World!</h1>`
* Wenn die Reihenfolge umgekehrt ist und zuerst das Modul zur Überprüfung der Tags ausgeführt wird, kann die Ausgabe so aussehen:
  * `<h1>Hello World!` => `<h1>Hello World!</h1>` => `\<h1\>Hello World!\<\/h1\>`

<Aside type="caution">
  Wenn mehrere Dateiverarbeitungsmodule desselben Typs (z. B. `file-post-export`) denselben Reihenfolgewert haben, kann es zu unerwartetem Verhalten kommen.
</Aside>

In solchen Fällen wählt das System anhand des Installationsdatums der Dateiverarbeitungs-Apps aus, welches Modul zuerst ausgeführt wird. Dadurch kann die gewünschte Verarbeitungsreihenfolge gestört werden. Passe daher identische Reihenfolgenwerte an, damit die Dateien in der gewünschten Reihenfolge verarbeitet werden.

### Einstellungen der Dateiverarbeitung bearbeiten

Gehe wie folgt vor, um die Einstellungen der Dateiverarbeitung zu bearbeiten:

<Steps>
  1. Öffne dein Projekt und gehe zu **Einstellungen > Dateiverarbeitungen**.
  2. Klicke neben der gewünschten Dateiverarbeitung auf <Icon name="mdi:dots-vertical" class="inline-icon" /> und wähle **Bearbeiten**.
  3. Nimm die erforderlichen Änderungen vor und klicke auf **Absenden**.
</Steps>

Die Einstellungen können je nach verwendeter Dateiverarbeitung variieren.
