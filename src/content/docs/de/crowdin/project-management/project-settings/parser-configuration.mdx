Standardmäßig verwendet Crowdin für jedes unterstützte Dateiformat einen vordefinierten Satz von Import- und Exportparametern.

Mit der Parserkonfiguration kannst du das für von Crowdin unterstützte Dateiformate vordefinierte Import- und Exportverhalten ändern. Parser Konfiguration in ein bestimmten Projekt ist applied nur zu Dateien gespeichert in dies Projekt.

Du kannst festlegen die parser Konfiguration für alle Dateien von ein certain Format oder single Dateien. Parser configuration in a specific project is applied only to files stored in this project.

Die meisten unterstützten Dateiformate verfügen über konfigurierbares Import- und Exportverhalten.

<Aside type="caution">
  Einige Parsereinstellungen sind in [string-basierten](/creating-project/#string-based-project) Projekten möglicherweise nicht verfügbar.
</Aside>

## Parser Konfiguration für alle Project Files von ein bestimmten Format

Um festlegen die preferred parser Konfiguration für alle Dateien von ein bestimmten Format, folgen diese Schritten:

<Steps>
  1. Öffne dein Projekt und gehe zu **Einstellungen > Parser-Konfiguration**.
  2. Wähle die benötigt Datei Format und klicke auf Edit.
  3. Lege die preferred Einstellungen. fest
  4. Klicke auf **Speichern**.
</Steps>

Alternativ kannst du bei Formaten mit konfigurierbaren Parsereinstellungen dieselben Einstellungen über den Dialog [**Bundle erstellen**](/bundles/#configuring-bundles) oder [**Bundle bearbeiten**](/bundles/#editing-bundles) öffnen, indem du neben dem gewünschten Format auf <Icon name="mdi:cog" class="inline-icon" /> klickst.

Um ein neues Dateiformat hinzuzufügen, klicke oben rechts auf **Apps hinzufügen** und installiere das erforderliche Format.

## Parser Konfiguration für ein Single File

in einige cases, du könnte benötigen zu festlegen die parser Konfiguration nicht für alle Dateien von einige Datei Format aber just für ein single Datei. Um festlegen die parser Konfiguration für ein single Datei, folgen diese Schritten:

<Steps>
  1. Öffne dein Projekt und gehe zu **Quellen > Dateien**.
  2. Double-klicken auf die benötigt Datei.
  3. Wechsle im geöffneten Dialog zum Tab **Parser-Konfiguration**.
  4. Lege die preferred Einstellungen. fest
  5. Klicke auf **Speichern**.
</Steps>

Sobald du die Dateiparserkonfiguration speicherst, importiert Crowdin diese Datei erneut und wendet deine Einstellungen an.

## Post-Verarbeitung Files mit Nested Inhalt

Sometimes, du könnte arbeiten mit Dateien das enthalten Strings in ein unterschiedlich Format. ein common example ist ein JSON Datei wo einige String Werte enthalten HTML Inhalt. die Standard parser Konfiguration isn't designed für diese nested oder cascading scenarios.

Um properly Prozess such Dateien, du benötigen zu implement ein benutzerdefiniert Crowdin App das verwendet die File Post-importieren Verarbeitung Modul. Mit dieser Methode, die manchmal als Kaskadenverarbeitung bezeichnet wird, kann deine App importierte Strings abfangen und Crowdin anweisen, bestimmte Strings mit einem anderen Parser erneut zu verarbeiten. Du kannst Crowdin beispielsweise anweisen, einen String aus einer JSON-Datei als HTML zu parsen, damit HTML-Tags korrekt verarbeitet und Übersetzern nicht als Klartext angezeigt werden.

Um handle Dateien mit nested Inhalt, du kann install die Cascade Importer von die Crowdin Store oder, für mehr benutzerdefiniert scenarios, build dein own.
