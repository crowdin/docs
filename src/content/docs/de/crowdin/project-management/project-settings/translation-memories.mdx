Für jedes Projekt wird automatisch ein eigenes Translation Memory angelegt. Standardmäßig wird jede freigegebene oder zuletzt hinzugefügte Übersetzung im Translation Memory des Projekts gespeichert. Du kannst dieses Verhalten so anpassen, dass nur freigegebene Übersetzungen gespeichert werden.

* **Auto-Substitution aktivieren** &ndash; Mit dieser Funktion werden nicht übersetzbare Elemente (z. B. Tags, HTML-Entitäten, Platzhalter, Zahlen und mehr) in TM-Übersetzungsvorschlägen durch die im Quelltext verwendeten Elemente ersetzt. Diese Funktion verbessert die TM-Vorschläge, die bei der automatischen Übersetzung verwendet und im Editor als Übersetzungsvorschläge angezeigt werden. Verbesserte Vorschläge werden im Bericht zu den Übersetzungskosten berücksichtigt. Vorschläge, bei denen eine Verbesserung möglich ist, fließen in den Kostenschätzungsbericht ein.
* **TM-Vorschläge für Dialekte** &ndash; Mit dieser Funktion kannst du TM-Vorschläge aus der Hauptsprache für Dialekte anzeigen und verwenden, wenn keine dialektspezifischen Vorschläge verfügbar sind.
* **Globales Translation Memory verwenden** &ndash; Übersetzer erhalten Zugriff auf das globale Translation Memory, in dem alle Übersetzungen aus Projekten mit aktivierter Funktion gespeichert werden.
  <Aside>
      Sobald diese Option aktiviert ist, werden in diesem Projekt erstellte Übersetzungen ebenfalls zum globalen Translation Memory hinzugefügt, auf das jeder in Crowdin zugreifen kann.
  </Aside>
* **Nur freigegebene Vorschläge im Translation Memory speichern** &ndash; Wenn diese Option aktiviert ist, werden Übersetzungen erst nach ihrer Freigabe im Standard-Translation-Memory des Projekts gespeichert. Diese Option ist besonders für öffentliche oder Crowdsourcing-Projekte nützlich, bei denen sichergestellt werden soll, dass nur geprüfte Übersetzungen im TM gespeichert werden.
* **Kontexttyp für TM-Treffer** &ndash; Mit dieser Funktion legst du fest, welche Informationen als Kontext einer Zeichenfolge gelten, wenn perfekte (101 %) Translation-Memory-Treffer vorgeschlagen werden. Du kannst zwischen den folgenden Optionen wählen:
  * **Schlüssel und Kontext** &ndash; Wenn diese Option aktiviert ist, berücksichtigt das System sowohl den Schlüssel als auch den Kontext der Zeichenfolgen, um perfekte TM-Treffer vorzuschlagen. Dieser Modus eignet sich besonders für Dateiformate mit Schlüssel-Wert-Struktur.
  * **Automatisch** &ndash; Wenn diese Option aktiviert ist, wählt das System anhand des Dateiformats automatisch den am besten geeigneten Kontextmodus aus.
  * **Vorheriges und nächstes Segment** &ndash; Wenn diese Option aktiviert ist, berücksichtigt das System die unmittelbar vor und nach dem aktuellen Segment stehenden Segmente als Kontext. Diese Option eignet sich besonders für HTML-basierte Formate und andere Formate ohne definierte Schlüssel-Wert-Struktur.

## Abzüge

Im Bereich **Abzüge** kannst du festlegen, unter welchen Bedingungen die Übereinstimmungsrate von TM-Vorschlägen herabgesetzt wird. So kannst du die Relevanz der TM-Vorschläge gezielt an deine Anforderungen anpassen.

<Image src={tmPenalties} alt="Abzüge für Translation Memories" />

Du kannst die Abzüge mit den folgenden Optionen konfigurieren:

* **Automatische Ersetzung angewendet** &ndash; Wertet TM-Vorschläge ab, auf die eine automatische Ersetzung angewendet wurde.
* **Mehrere identische TM-Treffer** &ndash; Wertet TM-Vorschläge ab, wenn mehrere identische TM-Treffer gefunden werden.
* **TM-Priorität kleiner als** &ndash; Wertet TM-Vorschläge ab, die aus einem TM mit einer Priorität unterhalb eines festgelegten Werts stammen. Zusätzlich zum Abzugswert kannst du auch den gewünschten Schwellenwert für die TM-Priorität festlegen.
* **TM-Vorschlag zuletzt geändert vor mehr als** &ndash; Wertet TM-Vorschläge ab, deren letzte Änderung länger als die angegebene Anzahl von Monaten zurückliegt. Zusätzlich zum Abzugswert kannst du den Schwellenwert in Monaten festlegen.
* **TM-Vorschlag zuletzt verwendet vor mehr als** &ndash; Wertet TM-Vorschläge ab, die zuletzt vor mehr als der angegebenen Anzahl von Monaten verwendet wurden. Zusätzlich zum Abzugswert kannst du den Schwellenwert in Monaten festlegen.

## Translation Memories zuweisen

Wähle im Bereich **Zugewiesene Translation Memories** in der Liste die TMs aus, die du deinem Projekt zuweisen möchtest.

<Image src={tmAssigning} alt="Translation Memories zuweisen" />

<Aside>
  Einige TMs gelten für alle Projekte und können nicht direkt in den Projekteinstellungen deaktiviert werden. Um ein Projekt auszuschließen, kann der Kontoinhaber auf **Übersetzungsspeicher verwalten** klicken, den Übersetzungsspeicher bearbeiten, **Ausgewählt** auswählen und alle Projekte auswählen, die ihn weiterhin verwenden sollen. Erfahre mehr über [das Teilen von Übersetzungsspeichern](/translation-memory/#sharing-tms).
</Aside>

## Priorität von Translation Memories festlegen

Wenn du deinem Projekt mehrere TMs zuweist, kannst du für jedes eine Priorität festlegen. Vorschläge aus dem TM mit der höchsten Priorität werden zuerst angezeigt.

Der Standardwert für die TM-Priorität ist 1. Je höher die Zahl, desto höher die Priorität (beispielsweise hat 5 eine höhere Priorität als 1). Wenn du deinem Projekt beispielsweise vier TMs zuweist, kannst du dem wichtigsten TM die Priorität 4 geben, damit seine Vorschläge zuerst verwendet werden. Den übrigen TMs weist du entsprechend niedrigere Prioritäten zu.

Um die Priorität der TMs festzulegen, wähle im Bereich **Zugewiesene Translation Memories** in der jeweiligen Dropdown-Liste die gewünschte Priorität aus.

<Image src={tmPrioritizing} alt="Priorität von Translation Memories festlegen" />

## Standard-Translation-Memory ändern

Um das Standard-Translation-Memory deines Projekts zu ändern, klicke im Bereich **Zugewiesene Translation Memories** neben dem gewünschten TM in der Liste auf das Symbol <Icon name="mdi:star-outline" class="inline-icon" />.
