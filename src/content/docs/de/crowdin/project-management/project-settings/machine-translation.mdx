Im Bereich **Maschinelle Übersetzung** kannst du die folgenden Einstellungen verwalten:

* **Vorschläge für maschinelle Übersetzungen anzeigen** &ndash; Aktiviere diese Option, damit Vorschläge von MT-Engines wie Microsoft Translator, Google Translate und anderen im Editor angezeigt werden.

<Aside>
  Der Projektbesitzer sollte [Maschinenübersetzungs-Engines konfigurieren](/machine-translation/), bevor er sie verwendet.
</Aside>
