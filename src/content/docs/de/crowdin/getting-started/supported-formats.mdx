Crowdin unterstützt eine Vielzahl von Lokalisierungsformaten, darunter unter anderem Dateien für Mobilgeräte, Software, Dokumente, Untertitel und Grafik-Assets.

## Lokalisierungsformate und Dokumente

* Formate für mobile Anwendungen
* Formate für Web- und Desktopsoftware
* Dokumentation und Video-Untertitel

## Grafiken und Assets

Lokalisiere produktbezogene Grafiken, um eine einheitliche Benutzererfahrung über alle Sprachen hinweg zu bieten. Design- und andere Dateien ohne übersetzbaren Text (z. B. `.psd`, `.ai`, `.png`, `.jpeg`) werden als Assets importiert.

  Erfahre mehr über die [Asset-Lokalisierung](/asset-localization/).

## Konvertierte Dateiformate

Beim Import werden einige Dateiformate automatisch in andere Formate konvertiert, um anschließend weiter analysiert und verarbeitet zu werden. In der folgenden Tabelle findest du eine Auflistung der Ausgangsdateiformate und der Dateiformate, in die sie konvertiert werden.

| Ursprüngliches Dateiformat | Konvertiertes Dateiformat |
| -------------------------- | ------------------------- |
| DOC                        | DOCX                      |
| PPT                        | PPTX                      |
| RTF                        | DOCX                      |
| PDF                        | DOCX                      |

## Benutzerdefinierte Datei-Formate

Dateiformate, die nicht offiziell unterstützt werden, können trotzdem hochgeladen werden. Wenn eine Datei extrahierbaren Text enthält, wird sie als einfache Textdatei importiert; andernfalls wird sie als Grafikressource importiert. Um die Dateistruktur zu erhalten und nur übersetzbare Inhalte freizugeben, kannst du die Unterstützung für ein benutzerdefiniertes Format anfordern.

Unser Team kann speziellen Code hinzufügen, um Ihre ursprünglichen Dateiformate zu unterstützen und sicherzustellen, dass Übersetzer nur übersetzbaren Text statt des gesamten Dateiinhalts sehen. Dieser Ansatz ermöglicht Ihnen eine effektivere Verwaltung benutzerdefinierter Dateiformate.

[Kontaktiere uns](https://crowdin.com/contacts) – unser Support-Team hilft dir, in deinem Projekt mit benutzerdefinierten Dateiformaten zu arbeiten.

Alternativ kannst du die Unterstützung für ein benutzerdefiniertes Format selbst implementieren, indem du eine [Crowdin-App](/developer/crowdin-apps-about/) entwickelst, die das Modul [Custom File Format](/developer/crowdin-apps-module-custom-file-format/) enthält.

## Benutzerdefinierter Dateiexport

Standardmäßig exportieren wir die Übersetzungen im gleichen Format wie die Quelldateien. Wenn du beispielsweise eine XML-Datei zu Crowdin hochlädst, wird die XML-Datei exportiert.

Wenn du Übersetzungen in einem anderen Format als dem Quellformat exportieren möchtest, verwende [Target File Bundles](/bundles/).

Unsere Entwickler können einen speziellen Prozessor erstellen, falls du individuelle Einstellungen für deinen Dateiexport konfigurieren möchtest. Du lädst beispielsweise eine Schlüssel-Wert-Datei hoch, die standardmäßig keine [Zeichenfolgenbearbeitung](/string-management/#string-editing) unterstützt, und möchtest sie direkt in Crowdin bearbeiten. Wir können deine Datei vorübergehend in das CSV-Format konvertieren, damit du Zeichenketten online hinzufügen kannst. Die exportierte Datei bleibt im ursprünglichen Format.

[Kontaktiere uns](https://crowdin.com/contacts) – wir helfen dir gerne dabei, individuelle Exportoptionen entsprechend deinen Anforderungen einzurichten.

## Benutzerdefinierte Platzhalter

Crowdin unterstützt alle für die unterstützten Dateiformate typischen Platzhalter. Du wirst im Editor automatisch hervorgehoben, damit die Übersetzer wissen, dass sie nicht übersetzt werden sollen. Um festzulegen, welche Platzhaltertypen ein Projekt erkennt, nutze die [Platzhaltereinstellungen](/project-settings/placeholders/). Auch wenn der Übersetzer versucht, die Übersetzung mit einem geänderten oder fehlenden Platzhalter zu speichern, werden die aktivierten QA-Prüfungen den Übersetzer über den Fehler informieren.

Da verschiedene Dateiformate die Erstellung benutzerdefinierter Platzhalter ermöglichen, können wir auch Unterstützung für die benutzerdefinierten Platzhalter hinzufügen, die du in deinem Projekt verwendest. Um Unterstützung für deine benutzerdefinierten Platzhalter anzufordern, [wende dich bitte](https://crowdin.com/contacts) an unser Support-Team.
