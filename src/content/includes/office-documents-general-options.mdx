  <tr>
    <td>Translate document properties</td>
    <td>Document properties such as title, subject, and creator will be available for translation.</td>
  </tr>
  <tr>
    <td>Translate comments</td>
    <td>Comments left in the document will be available for translation. Enabled by default.</td>
  </tr>
  <tr>
    <td>Clean tags aggressively</td>
    <td>Additional formatting tags related to text spacing will be removed on import. Useful when translating Office documents converted from other formats (for example, PDF), and the conversion introduced lots of unnecessary formatting tags.</td>
  </tr>
  <tr>
    <td>Ignore formatting that differs only in whitespace</td>
    <td>A space with its own formatting will take the formatting of the text next to it, so it no longer adds a tag pair to the string. Available when <strong>Clean tags aggressively</strong> is enabled.</td>
  </tr>
  <tr>
    <td>Show tabs as characters</td>
    <td>A tab inside a line of text will appear in the string as a character instead of a tag.</td>
  </tr>
  <tr>
    <td>Show line breaks as characters</td>
    <td>A line break inside a line of text will appear in the string as the character set in <strong>Line break replacement</strong> instead of a tag.</td>
  </tr>
  <tr>
    <td>Line break replacement</td>
    <td>Defines the single character that replaces a line break, for example a space or a pipe. Available when <strong>Show line breaks as characters</strong> is enabled.</td>
  </tr>
  <tr>
    <td>Show non-breaking hyphens as characters</td>
    <td>A non-breaking hyphen will appear in the string as a character instead of a tag.</td>
  </tr>
  <tr>
    <td>Ignore soft hyphens</td>
    <td>Soft hyphens will be removed instead of appearing as tags.</td>
  </tr>
  <tr>
    <td>Translate hyperlink URLs</td>
    <td>Hyperlink URLs will be available for translation.</td>
