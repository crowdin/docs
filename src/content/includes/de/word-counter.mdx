Nachfolgend findest du die Prinzipien, nach denen Crowdin Wörter zählt:

* Ein Wort ist eine Kombination aus Buchstaben, Satzzeichen und Sonderzeichen (z. B.: @ # $ % ^ & \* – _ \` ‘ “), gefolgt von einem Leerzeichen.
* Eine Abfolge von Satzzeichen oder Sonderzeichen wird nicht als Wort gezählt.
* Standardmäßig werden HTML-Tags für die meisten Formate als separate Wörter betrachtet, außer bei den folgenden: HTML, Front Matter HTML, HAML, MD, Front Matter MD, XML, WEBXML, IDML, XLIFF, XLIFF 2.0, ADOC, DOCX, MIF, DITA. Du kannst die Standardeinstellungen für die Wortzählung in deines Projekts unter **Einstellungen > Import > Wortzählung** ändern.
* URLs (z. B. `https://crowdin.com`) und E-Mails (z. B. `support@crowdin.com`) werden als ein Wort gezählt.
* Schriftzeichen in Chinesisch, Japanisch und anderen Logogramm-Sprachen werden als ein Wort/Schriftzeichen gezählt. Beispielsweise wird „ライフ・イン・トウキョウ。“ als zehn Wörter gezählt.

Andere Beispiele, wie Wörter gezählt werden:

| **Zeichenkette**                              | **Wörter**                                                |
| --------------------------------------------- | --------------------------------------------------------- |
| Number is -123.45                             | 3                                                         |
| `<a href=”{0}” target=”_parent”>hier</a>`     | 1 / 7 (bei Verwendung eines Nicht-HTML-basierten Formats) |
| {0} – {1} bei {2}                             | 4                                                         |
| zwei-in-eins                                  | 1                                                         |
| 2-in-eins                                     | 1                                                         |
| zwei-in-1                                     | 1                                                         |
| `%file_type%`                                 | 1                                                         |
| hallo?Welt                                    | 1                                                         |
| hallo ? Welt                                  | 2                                                         |
| `<span style="color: #333333;">☂ ☃ ☀⚤</span>` | 0                                                         |
| © %company%                                   | 1                                                         |
| 01.01.1980                                    | 3                                                         |
| Montag, 8. August 2011                        | 4                                                         |
| `https://ka-graphie.example.com/6d8b.png`     | 1                                                         |
| Los gehtʼs                                    | 2                                                         |
| Los geht's                                    | 3 (eine andere Art von Apostroph wurde verwendet)         |
| Wort/Wörter                                   | 2                                                         |
