  <tr>
    <td>Dokumenteigenschaften übersetzen</td>
    <td>Dokumenteigenschaften wie Titel, Betreff und Ersteller stehen zur Übersetzung zur Verfügung.</td>
  </tr>
  <tr>
    <td>Kommentare übersetzen</td>
    <td>Im Dokument vorhandene Kommentare stehen zur Übersetzung zur Verfügung. Standardmäßig aktiviert.</td>
  </tr>
  <tr>
    <td>Tags aggressiv bereinigen</td>
    <td>Zusätzliche Formatierungs-Tags zur Textabstandsregelung werden beim Import entfernt. Nützlich beim Übersetzen von Office-Dokumenten, die aus anderen Formaten (zum Beispiel PDF) konvertiert wurden und bei denen durch die Konvertierung viele unnötige Formatierungs-Tags entstanden sind.</td>
  </tr>
  <tr>
    <td>Formatierung ignorieren, die sich nur durch Leerzeichen unterscheidet</td>
    <td>Ein Leerzeichen mit eigener Formatierung übernimmt die Formatierung des angrenzenden Texts, sodass es dem String kein zusätzliches Tag-Paar mehr hinzufügt. Verfügbar, wenn <strong>Tags aggressiv bereinigen</strong> aktiviert ist.</td>
  </tr>
  <tr>
    <td>Tabulatoren als Zeichen anzeigen</td>
    <td>Ein Tabulator innerhalb einer Textzeile wird im String als Zeichen statt als Tag angezeigt.</td>
  </tr>
  <tr>
    <td>Zeilenumbrüche als Zeichen anzeigen</td>
    <td>Ein Zeilenumbruch innerhalb einer Textzeile wird im String als das unter <strong>Ersetzung für Zeilenumbrüche</strong> festgelegte Zeichen statt als Tag angezeigt.</td>
  </tr>
  <tr>
    <td>Ersetzung für Zeilenumbrüche</td>
    <td>Definiert das einzelne Zeichen, das einen Zeilenumbruch ersetzt, zum Beispiel ein Leerzeichen oder einen senkrechten Strich. Verfügbar, wenn <strong>Zeilenumbrüche als Zeichen anzeigen</strong> aktiviert ist.</td>
  </tr>
  <tr>
    <td>Geschützte Bindestriche als Zeichen anzeigen</td>
    <td>Ein geschützter Bindestrich wird im String als Zeichen statt als Tag angezeigt.</td>
  </tr>
  <tr>
    <td>Weiche Trennstriche ignorieren</td>
    <td>Weiche Trennstriche werden entfernt, statt als Tags angezeigt zu werden.</td>
  </tr>
  <tr>
    <td>Hyperlink-URLs übersetzen</td>
    <td>Hyperlink-URLs stehen zur Übersetzung zur Verfügung.</td>
