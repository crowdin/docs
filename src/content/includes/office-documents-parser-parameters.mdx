#### General Options

<table>
  <colgroup>
    <col width="30%" />
    <col width="70%" />
  </colgroup>
  <thead>
  <tr>
    <th>Parameter</th>
    <th>Description</th>
  </tr>
  </thead>
  <tbody>
  <tr>
    <td>Translate document properties</td>
    <td>Document properties such as title, subject, and creator will be available for translation.</td>
  </tr>
  <tr>
    <td>Translate comments</td>
    <td>Comments left in the document will be available for translation. Enabled by default.</td>
  </tr>
  <tr>
    <td>Clean tags aggressively</td>
    <td>Additional formatting tags related to text spacing will be removed on import. Useful when translating Office documents converted from other formats (for example, PDF), and the conversion introduced lots of unnecessary formatting tags.</td>
  </tr>
  <tr>
    <td>Ignore formatting that differs only in whitespace</td>
    <td>A space with its own formatting will take the formatting of the text next to it, so it no longer adds a tag pair to the string. Available when <strong>Clean tags aggressively</strong> is enabled.</td>
  </tr>
  <tr>
    <td>Show tabs as characters</td>
    <td>A tab inside a line of text will appear in the string as a character instead of a tag.</td>
  </tr>
  <tr>
    <td>Show line breaks as characters</td>
    <td>A line break inside a line of text will appear in the string as the character set in <strong>Line break replacement</strong> instead of a tag.</td>
  </tr>
  <tr>
    <td>Line break replacement</td>
    <td>Defines the single character that replaces a line break, for example a space or a pipe. Available when <strong>Show line breaks as characters</strong> is enabled.</td>
  </tr>
  <tr>
    <td>Show non-breaking hyphens as characters</td>
    <td>A non-breaking hyphen will appear in the string as a character instead of a tag.</td>
  </tr>
  <tr>
    <td>Ignore soft hyphens</td>
    <td>Soft hyphens will be removed instead of appearing as tags.</td>
  </tr>
  <tr>
    <td>Translate hyperlink URLs</td>
    <td>Hyperlink URLs will be available for translation.</td>
  </tr>
  </tbody>
</table>

#### Text Documents

<table>
  <colgroup>
    <col width="30%" />
    <col width="70%" />
  </colgroup>
  <thead>
  <tr>
    <th>Parameter</th>
    <th>Description</th>
  </tr>
  </thead>
  <tbody>
  <tr>
    <td>Translate headers and footers</td>
    <td>Headers and footers will be available for translation. Enabled by default.</td>
  </tr>
  <tr>
    <td>Translate hidden text</td>
    <td>The hidden text will be available for translation.</td>
  </tr>
  <tr>
    <td>Translate shape and image names</td>
    <td>The name of a shape or an image will be available for translation. Enabled by default.</td>
  </tr>
  <tr>
    <td>Translate shape and image alternative text</td>
    <td>The alternative text of a shape or an image will be available for translation, which keeps the localized document accessible to screen readers.</td>
  </tr>
  <tr>
    <td>Additional field types to translate</td>
    <td>Defines a list of Word field types whose text will be available for translation. Use the field codes as Word writes them (for example, <code>PAGE</code>). <code>HYPERLINK</code> is translated whether or not it appears in the list.</td>
  </tr>
  <tr>
    <td>Paragraph styles</td>
    <td>Defines a list of paragraph style names, as they appear in the document (for example, <code>Heading1, Quote</code>). Select <strong>Exclude the listed styles</strong> to leave them out, or <strong>Translate only the listed styles</strong> to translate nothing else.</td>
  </tr>
  <tr>
    <td>Highlight colors</td>
    <td>Defines a list of Word highlight colors. Select <strong>Exclude the listed highlight colors</strong> to leave the text they mark out, or <strong>Translate only the listed highlight colors</strong> to translate nothing else. Available colors: <code>black</code>, <code>blue</code>, <code>cyan</code>, <code>green</code>, <code>magenta</code>, <code>red</code>, <code>yellow</code>, <code>white</code>, <code>darkBlue</code>, <code>darkCyan</code>, <code>darkGreen</code>, <code>darkMagenta</code>, <code>darkRed</code>, <code>darkYellow</code>, <code>darkGray</code>, <code>lightGray</code>, <code>none</code>.</td>
  </tr>
  <tr>
    <td>Exclude text in the listed colors</td>
    <td>Text in the listed colors will not be available for translation. Each color is six hexadecimal digits and must match exactly, so a similar shade is still translated.</td>
  </tr>
  </tbody>
</table>
